## 学习目标

本课学习一维数组。重点包括数组声明、下标访问、遍历、初始化。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 先摆一排元素

```c
#include <stdio.h>

int main() {
    int bowls[4] = {10, 20, 30, 40};

    printf("%d\n", bowls[0]);
    printf("%d\n", bowls[3]);
    return 0;
}
```

```text
10
40
```

盯着 `int bowls[4] = {10, 20, 30, 40};` 这一行，它是三块拼起来的：

1. **`int`** —— 这一排每个元素装什么形状的东西。这里写 `int`，就是「每个元素里放一个整数」。
2. **`bowls`** —— 这一排的名字，随你起。
3. **`[4]`** —— **方括号里的数 = 一共摆几个元素**。这一排钉死就是 4 只。
4. **`= {10, 20, 30, 40}`** —— 花括号里按顺序把每个元素里的东西写出来，用逗号隔开。

**这里要跟 Python 那种「列表」分清楚。** Python 的柜子想塞多少塞多少，还有 `append` 这种函数帮你加一格；C 的这一排元素**在你写下 `[4]` 的那一刻就钉死了** —— 只有 4 只，不多不少，也**没有任何「加一格」的函数**。想多一个元素？回去改代码，重新翻译一遍。

还有一件事跟 Python 也完全不同：**C 的元素里不会自己变干净。** 你摆了元素又没往里放东西，元素里就是**别人用剩下的、说不准的玩意儿** —— 不是 0，也不是「什么都没有」。所以我们养成的习惯是：**摆元素的同时就把值填进去**，一个都不落下。

## 报编号取用：编号从 0 开始

一排元素最贴心的地方是：**每个元素都有编号，而且从 0 开始数**。上面那排四个元素，编号是这样的：

| 编号 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 元素里 | 10 | 20 | 30 | 40 |

报编号取用，写法就是**名字后面跟一对方括号，括号里写编号**：`bowls[0]` 是第一个元素（10 条），`bowls[3]` 是最后一个（40 条）。

想换掉其中一个元素里的东西，也报编号：

```c
#include <stdio.h>

int main() {
    int bowls[4] = {10, 20, 30, 40};

    bowls[1] = 99;
    printf("%d\n", bowls[1]);
    return 0;
}
```

```text
99
```

`bowls[1] = 99;` 的意思是「把 1 号元素里的东西倒掉，换成 99」—— 别的元素原封不动。这句和 `bowls = 新的一排` 分得很清楚：**报编号只动一个元素**。

## 让整排自己走一遍

一排元素摆好之后，最常干的活是「挨个看一遍」。上一课的跑圈函数正好用得上：

```c
#include <stdio.h>

int main() {
    int bowls[4] = {10, 20, 30, 40};

    for (int i = 0; i < 4; i++) {
        printf("第 %d 只元素里有 %d 条\n", i, bowls[i]);
    }
    return 0;
}
```

```text
第 0 只元素里有 10 条
第 1 只元素里有 20 条
第 2 只元素里有 30 条
第 3 只元素里有 40 条
```

读法是：「**`i` 从 0 开始，只要还比 4 小就进圈；圈里报一次编号，把那个元素里的东西拿出来用。**」

- `i` 挨个取到 0、1、2、3 —— 正好是这排元素的全部编号。
- `bowls[i]` 里的方括号允许放**一个会变的变量**，所以每一圈拿到的都是不同的元素。
- 眼色写的是 `i < 4`，**不是 `i <= 4`**。这一条是本课最要命的地方，我们下面专门讲。

### 最大编号永远是元素数减一

四个元素，编号是 0、1、2、3；而「几个元素」数出来是 4。所以**最大编号永远是元素数减一**这个差一位，最容易踩。

要是元素数不方便直接写死（比如改动之后忘了同步），C 有一个小办法：让编译器自己量一下。

```c
#include <stdio.h>

int main() {
    int bowls[] = {10, 20, 30};

    printf("一共 %d 只元素\n", (int)(sizeof(bowls) / sizeof(bowls[0])));
    return 0;
}
```

```text
一共 3 只元素
```

这一排的方括号里**空着没写数**，编译器就自己数花括号里写了几个值 —— 写了三个，它就摆三个元素。`sizeof(bowls)` 量出整排一共占多少格，`sizeof(bowls[0])` 量出单只元素占多少格，两者相除就是元素的只数。（外面那个 `(int)` 是告诉编译器「把这个数当成整数印出来」，先照抄着用就好。）

### 把每个元素里的东西攒起来

跑圈配上一个小元素，就能干「求和」这种活了：

```c
#include <stdio.h>

int main() {
    int bowls[4] = {10, 20, 30, 40};
    int total = 0;

    for (int i = 0; i < 4; i++) {
        total = total + bowls[i];
    }
    printf("一共 %d 条\n", total);
    return 0;
}
```

```text
一共 100 条
```

小元素 `total` 先洗成 0，然后每圈把当前那个元素里的东西倒进去：10、加 20、加 30、加 40，四圈跑完正好 100。**「跑圈 + 报编号」是这一排元素最常用的搭法**，我们后面几课会一直用它。

:::

## ⚠️ 越界：C 不拦你

下面这段，我们摆了 3 只元素，却伸手去摸**第 4 只**：

```c
#include <stdio.h>

int main() {
    int bowls[3] = {10, 20, 30};

    int v = bowls[3];
    (void)v;

    printf("跑完了，没人拦我们\n");
    return 0;
}
```

```text
跑完了，没人拦我们
```

**编译器一次不响，程序也一次不响。** 没有报错、没有警告，程序高高兴兴跑完了 —— 因为 C 压根**不做这道检查**：你写 `bowls[3]`，它就老老实实去算「0 号元素的位置再往后挪 3 只元素」，然后伸手摸下去。至于摸到的是什么，谁也说不准。

（我们那句 `(void)v;` 就是「摸到了，但我们不敢印出来」的意思 —— 那格子里到底是什么，C 自己都不知道。）

**这一条和 Python 完全相反。** Python 里越界会当场翻脸，甩你一句 `IndexError: list index out of range`，程序立刻停。C 不会 —— 它连一句警告都不给，该跑还是跑。这听上去像是 C 更宽容，其实是**更危险**：它摸走的那块地方可能是别的变量，把里面写坏之后，出问题的地方和写错的地方往往隔得老远，查起来极费眼神。

::: warn 注意
报编号之前，先在心里数一遍：**这排元素最大编号是几？** 四个元素是 0 到 3，最大编号 = 元素数减一。跑圈遍历的时候，眼色写 `i < 4` 才是把 0、1、2、3 都走一遍；写成 `i <= 4` 就多走一圈，伸手摸到了元素排外面去 —— 而 C **不会**告诉你。
:::

## 几种摆法小抄

```c
#include <stdio.h>

int main() {
    int bowls[4] = {0};

    for (int i = 0; i < 4; i++) {
        printf("%d\n", bowls[i]);
    }
    return 0;
}
```

```text
0
0
0
0
```

- **一个一个写全**：`int bowls[4] = {10, 20, 30, 40};` —— 最常用，值都是我们心里有数的。
- **只想全部清零**：`int bowls[4] = {0};` —— 花括号里只写一个 0，**后面没写的那些也全归 0**。这是 C 的一个贴心小规矩：写到的按写的算，**没写到的补 0**。
- **让编译器自己数元素数**：`int bowls[] = {10, 20, 30};` —— 方括号里空着，摆几个由你写了几个值说了算。

## 两个真实的报错

**报错一：元素数不能空着不写。**

```c
#include <stdio.h>

int main() {
    int bowls[];

    bowls[0] = 1;
    printf("%d\n", bowls[0]);
    return 0;
}
```

```text
main.c:4:9: error: array size missing in 'bowls'
```

编译器说的是：**`bowls` 这一排缺一个元素数。** 方括号里空着是**有条件的** —— 只有你同时用花括号把值都写出来（像上一节那样），它才数得出来；光说「摆一排」却不说几个，它没法给这一排划地方，只好拦下你。

**报错二：整排元素不能整个搬。**

```c
#include <stdio.h>

int main() {
    int a[3] = {1, 2, 3};
    int b[3] = {4, 5, 6};

    a = b;
    printf("%d\n", a[0]);
    return 0;
}
```

```text
main.c:7:7: error: assignment to expression with array type
```

这句话的意思是：**「一整排」这种东西不能放在等号左边被整个换掉。** 一排元素不是一个元素，它是钉在一块板上的三个元素 —— 想把 `b` 那排的内容搬进 `a`，得**一个一个地搬**：

```c
#include <stdio.h>

int main() {
    int a[3] = {1, 2, 3};
    int b[3] = {4, 5, 6};

    for (int i = 0; i < 3; i++) {
        a[i] = b[i];
    }
    printf("%d %d %d\n", a[0], a[1], a[2]);
    return 0;
}
```

```text
4 5 6
```

跑圈里报编号、一个一个搬 —— 搬完印出来，`a` 那排就变成了 4、5、6。这才是 C 里「整排搬家」的正经写法。

::: tip 提示
今天四件事各记一句：

1. **摆元素**：`int bowls[4] = {10, 20, 30, 40};` —— 形状、名字、方括号里的元素数、花括号里的值。
2. **取用**：`bowls[0]` 是第一个，**编号从 0 开始**；最大编号永远等于**元素数减一**。
3. **走一遍**：`for (int i = 0; i < 4; i++)`，圈里用 `bowls[i]` 挨个拿；想自己数元素数就用 `sizeof(bowls) / sizeof(bowls[0])`。
4. **两条和 Python 不一样的脾气**：元素数**钉死**、没有加一格的函数；越界**不报错**，它默默去摸别人的地方。
:::
