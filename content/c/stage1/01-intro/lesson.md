## 学习目标

本课学习认识 C 语言与第一个程序。重点包括C 语言是什么、hello world、程序结构讲解。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 第一份 C 程序：让电脑念一句话

先看成品。这段代码从头到尾一共七行，我们真跑过：

```c
#include <stdio.h>

int main(void) {
    printf("你好，！\n");
    return 0;
}
```

```text
你好，！
```

比别的语言长不少吧？别慌，它不是难，是**规矩多**。一行一行拆开，每一行都有它的用处。

### 第一行：`#include` —— 请档案管理员出场

`stdio.h` 是工作区文件的一位管理员，名字是「标准输入与输出」的缩写。

`#include` 的意思是「把它请出来」。不请它，`printf` 这一个方法就没人认得——这一点我们下面会当面演示给你看。

### 第二行：`int main(void)` —— 主函数，也是大门

`main` 是**主函数**，也是整份程序的大门：电脑一跑你的程序，就直奔 `main` 的第一行，别的句子都得等它调用。

- `main` 前面那个 `int`，说的是这一个方法干完活要**返回一个整数**给工作区；
- `(void)` 是一对空着的输入接口，意思是「这一个方法不用喂东西」；
- 后面那对**花括号 `{ }`** 是它的地盘：凡是属于这一个方法的句子，都得待在花括号里面。

### 第三行：`printf("你好，！\n");` —— 念话

`printf` 是 C 的念话函数：括号里那对引号围住的话，它会**原样念**出来。

末尾那个 `\n` 是**换行的暗号**——它自己不会被输出，只负责让光标跳到下一行。所以屏幕上出现的是「你好，！」外加一个回车，而不是「你好，！\n」这七个怪字符。

顺带认一句：`printf` 里那个 `f` 是「格式」的头一个字母。今天先把它当成名字的一部分，等以后讲到占位符那一课，这个 `f` 才真的要干活。

### 末尾两行：报平安，然后收工

`return 0;` 是函数干完了向工作区报个平安：「一切顺利，零号状况」。最后那半个花括号 `}` 就是收工。

### 每条句子的句号：分号

数一数：`printf(...)` 和 `return 0` 后面，都跟着一个分号 `;`。

**C 的每一条指令都要用分号收尾**，它就像中文里的句号。少了它，编译器读着读着会突然愣住：「你这一句说完了没呀？」然后把报错甩给你。

## 两句一起念：从上往下一句一句来

想让电脑多念一句，就多写一句 `printf`：

```c
#include <stdio.h>

int main(void) {
    printf("数据处理步骤第一条：拿起数据\n");
    printf("数据处理步骤第二条：放进元素里\n");
    return 0;
}
```

```text
数据处理步骤第一条：拿起数据
数据处理步骤第二条：放进元素里
```

顺序就是代码里的顺序：谁写在前面，谁先出声。这一条和你在别处学过的编程一模一样，不用重新记。

## 写坏了会怎样：编译器的原话

C 有个脾气要提前告诉你：**句子翻不通，它一句都不肯让你跑**。

别的语言是「念到哪儿错在哪儿」——前面已经念过的句子照样念完了；C 不是这样，它先把**整份源代码**翻一遍，翻不过去就一份都不给你。我们故意写坏三处，把编译器的原话抄给你看。

### 一、忘了分号

```c
#include <stdio.h>

int main(void) {
    printf("处理完成\n")
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:25: error: expected ';' before 'return'
```

`main.c` 是你这份文件的名字，`4:25` 是「第 4 行、第 25 个字符」——编译器连你漏在哪儿都替你点出来了。

### 二、忘了请档案管理员

```c
int main(void) {
    printf("处理完成\n");
    return 0;
}
```

```text
main.c: In function 'main':
main.c:2:5: error: implicit declaration of function 'printf' [-Wimplicit-function-declaration]
```

`implicit declaration` 这句话的意思就是「这一个方法我们没见过」——因为 `printf` 的来历写在 `stdio.h` 里，而你没请它出场。

### 三、名字写错一个字母

```c
#include <stdio.h>

int main(void) {
    prntf("处理完成\n");
    return 0;
}
```

```text
main.c: In function 'main':
main.c:4:5: error: implicit declaration of function 'prntf'; did you mean 'printf'? [-Wimplicit-function-declaration]
```

看最后那半句：`did you mean 'printf'?` ——编译器还顺手猜了一下你想调用谁，是不是有点像计算机挠你裤脚的样子。

::: warn 注意
上面三段都跑不起来，可这**不是坏事**：错误在开工之前就被拦住了，你不会遇到「程序跑到一半忽然炸掉」那种更难查的场面。

但请记住这个脾气的另一面：**C 拦的是「翻不通」的错，拦不住「翻得通但你想歪了」的错**。比如你把两句 `printf` 的顺序写反，它一句话都不会说，程序老老实实照着你的顺序念完。所以往后每次跑出不对劲的结果，第一件事是回头读自己的代码，别急着怪编译器。
:::

::: tip 提示
今天记住四件事：

1. `#include` 是**请档案管理员出场**，请了它 `printf` 才有人认得；
2. `main` 是**大门**，程序从它的花括号里第一行开始跑；
3. `printf("...")` 是**念话**，引号里的字原样念，`\n` 是换行的暗号；
4. 每条指令末尾都要有**分号**，`return 0;` 是收工时报的平安。
:::

## 小任务

把第一段代码一字不差地敲进编辑器，跑一遍，看看屏幕上是不是那句「你好，！」。然后试着改三处，每改一处先猜结果、再跑：

1. 把引号里的字换成「我们会写 C 啦」；
2. 在花括号里再加一句 `printf("第二句\n");`，看看两行是怎么排的；
3. 把末尾那个 `\n` 删掉，再跑一次——想想屏幕上会变成什么样，为什么。

改完这三处，你就摸到 C 的第一条规矩了。下一课，我们要带你看看那句「翻不通就一句都不给你跑」到底是怎么发生的：从你敲下的字到屏幕上那句你好，中间要过四道工序
