## 学习目标

本课学习二级指针。重点包括为什么需要二级指针、int ** 怎么读、通过参数改指针本身、二维数组与指针数组的区别。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、多一颗星，就多剥一层

先把三样东西摆在一张桌上：一个元素、指着元素的牌、指着牌的牌。

```c
#include <stdio.h>

int main(void) {
    int fish = 7;
    int *p = &fish;
    int **pp = &p;

    printf("%d\n", fish);
    printf("%d\n", *p);
    printf("%d\n", **pp);
    return 0;
}
```

```text
7
7
7
```

三个 `7`，一条路通到底：

- **`fish`** —— 元素里的数据，直接拿。
- **`*p`** —— `p` 上写的是那个元素的地址，**剥一层**就拿到数据。
- **`**pp`** —— `pp` 上写的是 **`p` 这张牌**的地址。剥一层（`*pp`）拿到 `p` 本身，**剥两层**（`**pp`）才到数据。

所以 `int **pp` 的读法是：**一张牌，指着「指着整数的名称」**。括号不用背，记住那句就够 —— **每多一颗星，就多剥一层。**

拿三条等式对一遍更实在：

```c
#include <stdio.h>

int main(void) {
    int fish = 7;
    int *p = &fish;
    int **pp = &p;

    printf("%d\n", pp == &p);
    printf("%d\n", *pp == p);
    printf("%d\n", **pp == *p);
    return 0;
}
```

```text
1
1
1
```

三行都是 `1`，意思是**一模一样，不是约等于**：

- `pp == &p` —— 外层牌上写的就是内层牌自己的地址。
- `*pp == p` —— 剥一层拿到的，就是内层那张牌本身。
- `**pp == *p` —— 剥两层，和「先剥内层再剥一层」，到的是同一个元素。

::: tip 提示
**「挪名称」和「剥名称」是两码事，别搅在一起。**

- **挪**（`p + 1`、`p++`）动的是地址，让名称往后跨一个元素 —— 第二阶段第一课讲的就是它；
- **剥**（`*p`）动的是「顺着名称往里看几层」，名称自己一步没挪。

`**pp` 里那两颗星也**不是乘法**，是「剥两次」。写的时候挨着写就行，别自己加空格也别加括号。
:::

## 二、剥一层拿到的，是「那张牌」

剥两层到数据，这个好懂。真正值钱的是**只剥一层**的时候 —— 拿到的不是数，是**一张牌**。既然是牌，就能换。

```c
#include <stdio.h>

int main(void) {
    int fish = 7;
    int bone = 3;
    int *p = &fish;
    int **pp = &p;

    printf("%d\n", *pp == p);
    *pp = &bone;
    printf("%d\n", *p);
    **pp = 42;
    printf("%d\n", bone);
    printf("%d\n", fish);
    return 0;
}
```

```text
1
3
42
7
```

一行一行看：

- `*pp == p` 印 `1` —— 剥一层拿到的就是 `p` 本人。它是**牌**不是**数**，所以能拿去跟名称比。
- `*pp = &bone;` —— 剥一层之后**往里写**，等于把 `p` 换一个元素指。下一行 `*p` 就印出 `3` 了。
- `**pp = 42;` —— 剥两层往里写，直接改元素里的数。`bone` 那个元素变成 `42`。
- 最后一行 `fish` 还是 `7` —— 从头到尾没人碰过它。

这两句背下来，这一课就成了一半：

> 想换「名称指着哪只元素」，剥一层：`*pp = ...`；
> 想换「元素里的数」，剥两层：`**pp = ...`。

## 三、为什么非要多一层：复印件与真牌

到这儿都还是「读得到」。可这一课真正要治的是**写不回去**。

第二阶段第一课里有过一句规矩：**想改原件，就把原件的地址递进去。** 那时要改的原件是**元素**，所以递的是 `&fish`。今天要改的原件**是一张牌** —— 那要递的就是「**牌的地址**」，也就是 `&p`。接的人呢？得拿一张「指着牌的牌」来接，那就是 `int **`。

先看不多这一层会怎样：

```c
#include <stdio.h>

/* 只拿到名称的一张复印件：改的是复印件，外面那张纹丝不动 */
void pick_wrong(int *a, int *b, int *out) {
    if (*a > *b) {
        out = a;
    } else {
        out = b;
    }
}

/* 拿到「外面那张牌的门牌号」：顺着它就能把外面那张牌换掉 */
void pick_right(int *a, int *b, int **out) {
    if (*a > *b) {
        *out = a;
    } else {
        *out = b;
    }
}

int main(void) {
    int x = 3;
    int y = 9;
    int *p = &x;

    pick_wrong(&x, &y, p);
    printf("复印件版：%d\n", *p);

    pick_right(&x, &y, &p);
    printf("真牌版：%d\n", *p);
    return 0;
}
```

```text
复印件版：3
真牌版：9
```

两招长得几乎一样，差别只在**接料那一格**和**写回去那一行**：

- `pick_wrong` 接的是 `int *out`。递进去的 `p` 是**抄了一份**的牌 —— 函数里 `out = a;` 改的是那份复印件，函数一收工它就没了，外面那张 `p` 一动不动。所以印出来还是 `3`。
- `pick_right` 接的是 `int **out`，递进去的是 `&p`（**牌的地址**）。函数里 `*out = a;` 的意思是「顺着这张地址找到外面那张牌，把它换掉」 —— 换的是真的那一张。所以印出来是 `9`。

::: tip 提示
**C 里递东西进函数，一律是抄一份递进去**，名称也不例外。这句话是这一课的全部要害：

- 递**元素**（`int`）→ 函数里改的是元素的复印件，外面不变；
- 递**元素的地址**（`int *`）→ 外面那个元素能被改；
- 递**牌的地址**（`int **`）→ 外面那张牌能被换掉。

每往上要改一层，就多递一层地址、多写一颗星。这不是什么新规矩，就是那句老话往上套了一层。
:::

## 五、顺着两层写回去

上一站那个「剥两层往里写」，单独拎出来长这样：

```c
#include <stdio.h>

/* 顺着两层把那个元素里的数加上一笔 */
void add_through(int **pp, int amount) {
    **pp = **pp + amount;
}

int main(void) {
    int fish = 20;
    int bone = 5;
    int *p = &fish;
    int **pp = &p;

    add_through(pp, 7);
    printf("%d\n", fish);

    *pp = &bone;
    add_through(pp, 100);
    printf("%d\n", bone);
    printf("%d\n", fish);
    return 0;
}
```

```text
27
105
27
```

- 头一趟：`pp` 指着 `p`，`p` 指着 `fish`。`**pp = **pp + 7` 把 `20` 加成 `27`。
- 中间那一行 `*pp = &bone;` 只剥一层 —— 它换的是**名称**，让 `p` 改指 `bone` 那个元素。所以第二趟加的不是 `fish` 而是 `bone`：`5 + 100 = 105`。
- 最后一行 `fish` 还是 `27`：换名称不会搬走元素里的数。

**这一节最该看出的是**：同一个方法 `add_through`，一个字都没改，第二趟却加到了另一个元素上 —— 因为中间那句 `*pp = &bone;` 把「外层牌下面挂着谁」换掉了。**剥一层改名称，剥两层改数**，这两句在这一段里各出现一次。

## 六、`int **` 和「一排名称」不是一回事

多一颗星的样子有好几种，最容易混的是这两个：

```c
#include <stdio.h>

int main(void) {
    int a = 1;
    int b = 2;
    int c = 3;

    /* 一排格子，每格里保存的是一张名称 */
    int *row[3] = {&a, &b, &c};

    printf("%d\n", *row[0]);
    printf("%d\n", *row[2]);
    return 0;
}
```

```text
1
3
```

- **`int *row[3]`** 是**一排格子**，一共 3 格，每格里保存一张名称。`row[0]` 就是第一格里那张牌，再剥一层（`*row[0]`）才到元素里的数。它跟「多剥一层」没关系 —— 它是**好几张牌并排摆**。
- **`int **pp`** 是一张牌，**指着另一张牌**。剥一层拿到的还是牌，剥两层才到数。

读法有个笨办法很好用：**从名字出发，先看它紧挨着谁**。`row` 紧挨着 `[3]`，所以它是一排 3 格；`pp` 紧挨着 `*`，所以它是一张牌。这两种写法的正式名字、以及「指向整排的牌」长什么样，是下一课的正题 —— 今天先认出它们不是一个东西就够了。

::: warn 注意
两个特别容易滑过去的地方。

**一、`%d` 印不出名称。** 我们手一滑，把牌直接传给了 `%d`，编译器嘀咕了一句（原话抄在这儿）：

```text
main.c:7:14: warning: format '%d' expects argument of type 'int', but argument 2 has type 'int *' [-Wformat=]
```

用自然语言解释：**「这口槽是给整数的，你塞进来的是张名称。」** 注意它只是**嘀咕**：程序照样被编了出来，跑起来还高高兴兴印了一串没意义的数字（我们那次印出来的是 `-205521308`，你跑出来的一定不一样，因为每次摆元素的位置都不同）。**看见 `warning:` 别当没事。**

**二、星号少一颗，编译器可能一次不吭。** `*pp = *pp + 1;` 和 `**pp = **pp + 1;` 编译器两个都收，可一个改的是「名称指着哪只元素」、一个改的是「元素里的数」 —— 差一颗星，两件完全不同的事，屏幕上却什么都不报。所以每次写到 `**`，我们都回头问自己一句：**这一行要改的到底是名称，还是元素里的数？**
:::

## 七、编译器会拦下来的两种写错法

**第一种：剥多了。** 名称只有一层，却想剥两层：

```c
#include <stdio.h>

int main(void) {
    int fish = 7;
    int *p = &fish;

    printf("%d\n", **p);
    return 0;
}
```

```text
main.c:7:20: error: invalid type argument of unary '*' (have 'int')
    7 |     printf("%d\n", **p);
```

用自然语言解释：**「`*` 想剥的东西是个整数，剥不了。」** 想剥两层，前提是手里那张牌得真的是「指着牌的牌」（`int **`）；`p` 只有一层，第二颗星就落空了。

**第二种：递的时候漏了 `&`。** 函数那边已经写对了（收的是 `int **`），可称呼它的时候递进去的是 `p` 而不是 `&p`：

```c
#include <stdio.h>

void pick_bigger(int *a, int *b, int **out) {
    if (*a > *b) {
        *out = a;
    } else {
        *out = b;
    }
}

int main(void) {
    int x = 3;
    int y = 9;
    int *p = &x;

    pick_bigger(&x, &y, p);
    printf("%d\n", *p);
    return 0;
}
```

```text
main.c:16:25: error: passing argument 3 of 'pick_bigger' from incompatible pointer type [-Wincompatible-pointer-types]
main.c:3:40: note: expected 'int **' but argument is of type 'int *'
```

用自然语言解释：**「第三格要的是『牌的地址』，你递进来的是『元素的地址』。」** 这一条特别值得记：漏掉的那个 `&` 不是什么装饰，它正是**从「递元素」升到「递牌」的那一步**。少写一个字符，递进去的东西就低了一层。

## 八、今天收四句话

::: tip 提示
1. **每多一颗星，就多剥一层。** `int **pp` 是一张牌，指着「指着整数的名称」；`*pp` 拿到内层那张牌，`**pp` 才到元素里的数。
2. **剥一层改名称，剥两层改数。** `*pp = &bone;` 换的是「名称指哪只元素」，`**pp = 42;` 换的是「元素里的数」。
3. **想让函数改掉外面那张牌，就得把「牌的地址」递进去**（`&p`），接的人用 `int **` 接，函数里写 `*out = ...`。递 `p` 只是递了张复印件，外面纹丝不动。
4. **`int **pp` 和 `int *row[3]` 不是一回事** —— 前者是一张牌指着另一张牌，后者是一排格子、每格里一张牌。
:::

## 小任务

1. **少写一颗星。** 把第一节那段里的 `int **pp = &p;` 改成 `int **pp = p;`，先猜编译器会不会拦，再真跑一次对照。它拦下来的那句话，说的是哪两个东西对不上？
2. **多写一颗星。** 把第二节那段里的 `*pp = &bone;` 改成 `**pp = &bone;`，照样先猜再跑 —— 这回它拦不拦？拦下来的那句原话又是关于什么的？
3. **自己写一个方法把名称换掉。** 写一个 `void point_to(int **pp, int *target)`，把外面那张牌改成指着 `target` 那个元素；再在 `main` 里印一行 `p == &bone` 确认真的改到了（改到了会印 `1`）。
4. **想一想（别跑）。** 下面这一个方法，和「`*pp = *pp + 1;`」只差一颗星：

```c
void walk(int **pp, int n) {
    for (int i = 0; i < n; i++) {
        pp = pp + 1;
    }
}
```

先想清楚这两件事：**剥一层的写法挪的是哪张牌，不剥的写法挪的又是哪张牌**；再往下推一步 —— 外面那张牌最后会停在哪儿？

下一课，我们要带你把今天这两张牌摊开摆成一排：**一排名称怎么声明、和「指着整排的牌」怎么分清**，还有那种「指着已经没了的东西」的坏名称该怎么防。今天先把「多一颗星就多剥一层」刻进脑子里
