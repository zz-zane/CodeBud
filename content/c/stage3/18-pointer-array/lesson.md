## 学习目标

本课学习指针数组与野指针。重点包括指针数组与数组指针、怎么分清两种写法、悬空指针、野指针与空指针、怎么防。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、一格一张：先挂一排，再量一量

先看一个能跑的本子。四排数组元素里放着名字，我们另挂一排名称指过去：

```c
#include <stdio.h>

int main(void) {
    char names[4][16] = {"阿花", "计算机", "张三", "煤球"};
    char *row[4];

    for (int i = 0; i < 4; i++) {
        row[i] = names[i];
    }

    for (int i = 0; i < 4; i++) {
        printf("第 %d 张牌 -> %s\n", i, row[i]);
    }

    printf("名称整排占多少格：%d\n", (int) sizeof(row));
    printf("数组元素整排占多少格：%d\n", (int) sizeof(names));
    printf("第 0 张牌上写的，就是 names[0] 的门牌号吗：%d\n", row[0] == names[0]);

    return 0;
}
```

```text
第 0 张牌 -> 阿花
第 1 张牌 -> 计算机
第 2 张牌 -> 张三
第 3 张牌 -> 煤球
名称整排占多少格：32
数组元素整排占多少格：64
第 0 张牌上写的，就是 names[0] 的门牌号吗：1
```

（这几段数是我们在这台机器上真跑出来的，命令就是本项目的标准那一条：`gcc -finput-charset=UTF-8 -fexec-charset=UTF-8 -Wall main.c -o a.exe && ./a.exe`。）

三个数，三句话：

- **32**：一整排名称自己占的地方 —— 四张牌，一张 8 格，装的全是地址。
- **64**：那排数组元素占的地方 —— 四排、每排 16 格，保存的是名字本身。**同样四格，一个 32、一个 64，装的东西压根不是一类。**
- **1**：第 0 张牌上写的，确实就是 `names[0]` 那排元素的地址 —— 所以 `row[0]` 顺过去拿到的，和 `names[0]` 是同一串名字。

再看一眼那一句关键的赋值：`row[i] = names[i];` —— **右边那排元素的名字一出现，自动变成那排元素的地址**（编译器的老规矩，上一阶段「指针与数组」那一课见过）。所以这一句是把地址抄到名称上，名字还好端端待在元素里。

一排名称里第一张和「从第一张开始往前挪一格」是同一张：`row[1]` 和 `*(row + 1)` 说的是同一处。

## 二、先看右边、再看左边：两种写法别再串了

招牌上常并排挂着两个长得很像的写法。我们教你一个读法，两步就够：

**从名字出发 —— 先看它右边，再看它左边。**

```text
char *row[4]      右边先来 [4]：row 是一排四格，每格里装一张名称
char (*p)[16]     括号先把 p 和 * 绑死：p 是一张名称，它指着一整排 16 格
```

第二行那对括号**不能省**：省掉就变成第一个形状了 —— `char *p[16]` 是「一排 16 张名称」，和「一张指着整排的名称」差着十万八千里。书上把前者叫 **数组指针（指着整排的名称）**，把后者那排叫**一排指针**，两个名字里字的顺序换一下，东西就换了。

这两个形状量出来差多少？我们换了个本子，一次量全：

```c
#include <stdio.h>

int main(void) {
    char *row[4];
    char (*p)[16];
    char *many[16];
    char names[4][16];

    p = names;

    printf("一整排名称有多大：%d\n", (int) sizeof(row));
    printf("其中一张牌有多大：%d\n", (int) sizeof(row[0]));
    printf("单张的那张牌有多大：%d\n", (int) sizeof(p));
    printf("它指着的那一整块有多大：%d\n", (int) sizeof(*p));
    printf("一排名称里，名称往前挪一格挪多远：%d\n", (int) ((char *) (row + 1) - (char *) row));
    printf("指着整排的那张牌，往前挪一格挪多远：%d\n", (int) ((char *) (p + 1) - (char *) p));
    printf("一排 16 张名称有多大：%d\n", (int) sizeof(many));

    return 0;
}
```

```text
一整排名称有多大：32
其中一张牌有多大：8
单张的那张牌有多大：8
它指着的那一整块有多大：16
一排名称里，名称往前挪一格挪多远：8
指着整排的那张牌，往前挪一格挪多远：16
一排 16 张名称有多大：128
```

一句一句读：

- **32**：一整排名称（四张 × 8 格）。
- **8** 和 **8**：一张名称的大小 —— 两种写法**一样大**。名称本身没区别，区别在它后头站着什么。
- **16**：`*p` 是「它指着的那一整块」，也就是一整排 16 格。
- **8** 和 **16** 这两行最值钱：`row + 1` 往前挪**一张牌**（8 格），`p + 1` 往前挪**一整排**（16 格）—— 同样是 `+ 1`，走的距离差一倍。
- **128**：`char *p[16]`（一排 16 张名称）比 `char (*p)[16]`（一张名称）大了十六倍。

一句话收进兜里：**名称往前挪一步走多远，看它指着的是什么。**


## 三、坏掉的名称（一）：从来没插过的那张

名称刚要来的时候，牌面上是**空的** —— 不是「空名称」，是**一个字都没写过**：上面留着的是上一个对象用完这一格没擦干净的东西。照着它走，走到的是一处谁都不认识的地方。

这种名称长这样（我们故意把它放进文字框里，不给它编的机会 —— 理由马上讲）：

```text
int *p;
*p = 5;
printf("%d\n", *p);
```

`int *p;` 只说明「p 是一张名称」，**牌面上什么都没写**。编译器看得出苗头，会念你一句：

```text
main.c:5:8: warning: 'p' is used uninitialized [-Wuninitialized]
```

（这是我们真跑出来的原话。它前面还有一行 `main.c: In function 'main':`，这里只抄要紧的一句。）

**念归念，它不拦你** —— 程序照样编得出来、照样跑得起来。跑起来会怎么样？我们连跑 **10 次**：10 次都**当场断气**（屏幕上一个字都没印，进程被系统按掉）。可我们**不敢说它一定断气** —— 同一个写法换台机器、换一份排布，它可能只是印出一串莫名其妙的大数。这就是它最坏的地方：

- 它可能**什么都没发生**，于是你以为自己写对了；
- 它可能**踩坏别人的东西**，当场看不出来，过很久以另一副面孔炸出来；
- 它也可能**当场断气**，让你对着空屏幕发懵。

三种都叫坏名称。规矩只有一条：**名称要来之后，先写上地址，再照着它走。**

## 四、坏掉的名称（二）：窝还回去了，名称还留着

第二种坏名称更阴：**名称插得好好的，可它指着的那间窝已经不归你了。**

前面学过「动态内存」：用 `malloc` 现租一间，用完 `free` 还回去。可还回去的是**窝**，名称不在还的范围内 —— 我们写了个本子量这件事：

```c
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *p = (int *) malloc(sizeof(int) * 4);

    if (p == NULL) {
        printf("没租到\n");
        return 1;
    }

    p[0] = 10;
    printf("租来的时候，第 0 间保存的是：%d\n", p[0]);

    free(p);
    printf("还回去之后，牌上还写着门牌号吗：%d\n", p != NULL);

    p = NULL;
    printf("把名称擦成空名称之后，还有门牌号吗：%d\n", p != NULL);

    return 0;
}
```

```text
租来的时候，第 0 间保存的是：10
还回去之后，牌上还写着门牌号吗：1
把名称擦成空名称之后，还有门牌号吗：0
```

看中间那个 **1**：`free(p)` 之后，牌上**照样写着地址**。照着这个地址走过去，走到的是**一间已经还给管理员、随时可能租给别人的窝**。

麻烦的是「随时可能」真的只是可能。我们真跑过这么一段（窝还了、名称没擦，然后照着旧名称写）：

```text
int *p = (int *) malloc(sizeof(int) * 4);
free(p);
p[0] = 7;
```

它到底会出什么事，取决于**新租到的那间是不是刚还回去的那间**。我们另写了个本子量这件事：租一间、还回去、**再租一间**，看新租到的是不是刚还回去的那间。跑了两轮，**结果对不上**：头一轮**五次**里**三次**落在同一间，第二轮**十次**里只有**两次**落在同一间，另外**八次**租到的是别处（后来再跑十次，又变成**三次**落在同一间 —— 连这个比例本身都不固定）。同一台机器、同一个本子，**两轮都出现两种结果** —— 落在同一间的那几次，「照着旧名称写一笔」看着一切正常；落在别处的那几次，那一笔就写到别人家里去了。**「有时对、有时错」的毛病，比每次都错难查得多。**

顺着旧名称过去用一用它，编译器其实会念一句（同样是真跑出来的原话）：

```text
main.c:7:10: warning: pointer 'p' used after 'free' [-Wuse-after-free]
```

可**念归念，它不拦你**：上面那三行我们连跑 **10 次**，10 次都**安安静静跑完**（退出码 `0`）、屏幕上一个字都没有。写进一间已经还回去的窝里的那一笔，**没有任何人告诉你它出了事** —— 这才是「窝还回去了、名称还留着」最麻烦的地方。

所以还窝之后，**顺手把名称擦成空名称**：`p = NULL;`（上面那个本子的最后两行就是）。这是本课的地址规矩里最省事的一条。

## 五、空名称：最省事的一道防线

`NULL` 就是一张**空名称**：牌面上明明白白写着「不指向任何地方」。一排名称里有几格暂时没东西可指，就先插一张空名称，用之前看一眼：

```c
#include <stdio.h>

int main(void) {
    char *row[4] = {"阿花", NULL, "张三", NULL};

    for (int i = 0; i < 4; i++) {
        if (row[i] == NULL) {
            printf("第 %d 张是空名称，我们跳过\n", i);
            continue;
        }
        printf("第 %d 张牌 -> %s\n", i, row[i]);
    }

    return 0;
}
```

```text
第 0 张牌 -> 阿花
第 1 张是空名称，我们跳过
第 2 张牌 -> 张三
第 3 张是空名称，我们跳过
```

走一圈，有东西的照名字印出来，空名称那格走另一条路。

::: warn 空名称不等于好名称
照着**空名称**走，一样会当场断气。我们真跑过一个「不先看、直接照着走」的本子：连跑 **5 次**，5 次都是一样的结果 —— 走到空名称那一步，进程当场被系统按掉。

可它和「没插过的那张」有一处根本差别：**空名称是一张把「不能走」写在牌面上的名称**。它的坏是**一定响**的坏；一定响的错，你十分钟就能查出来。而没插过的那张，坏得**有时响、有时不响** —— 那才缠人。

所以两件事都要做：**名称要来先写地址；窝还回去就把名称擦成 `NULL`。**
:::

## 六、整排名称不能一起搬家

名称挂多了，我们动过一个偷懒的念头：既然 `row` 和 `other` 都是「一排四张名称」，那能不能一句话把 `other` 那四张**整排搬**到 `row` 里？

**不能。** 编译器当场把我们拦下：

```c
#include <stdio.h>

int main(void) {
    char *row[4] = {"阿花", "计算机", "张三", "煤球"};
    char *other[4] = {"甲", "乙", "丙", "丁"};

    row = other;

    printf("%s\n", row[0]);
    return 0;
}
```

```text
main.c:7:9: error: assignment to expression with array type
```

它的意思是「一排东西不能整个换掉」。为什么？因为 `row` 在编译器眼里压根**不是一格** —— 它是**整排的地址**，认的是那一排本身。整排要换内容，只能**一格一格来**：

```text
row[0] = other[0];
row[1] = other[1];
row[2] = other[2];
row[3] = other[3];
```

要么一开始就别摆两排，让名称直接指过去。记住这个小脾气：**一整排换不掉，单张的名称随时能换** —— 小任务里就有一道「换两张名称」。

::: tip 提示
今天收五句话：

1. **一排名称，一格一张**：`char *row[4]` 是一排四张名称，每张写一个地址。它和「一排数组元素」（元素里装名字本身）不是一类东西 —— 同样四格，名称整排 32 格、元素整排 64 格。
2. **读写法从名字出发、先右后左**：`char *row[4]` 是一排名称，`char (*p)[16]` 是一张指着整排的名称。少写一对括号，形状就换了（一排 16 张名称 = 128 格）。
3. **名称往前挪一步走多远，看它指着的是什么**：`row + 1` 走 8 格，`p + 1` 走 16 格。
4. **坏名称有三个来路**：没插过的（牌面是垃圾）、窝还了名称没擦的、以及不先看就照着空名称走的。前两种**不保证当场报错**。
5. **两道防线**：名称要来先写地址（暂时没得指就插空名称 `NULL`）；窝还回去顺手 `p = NULL;` 擦干净。
:::

## 小任务

1. **先猜再跑。** 把第一节那个本子里的第一行 `sizeof(row)` 改成 `sizeof(row[0])`，别的都不动 —— 先拿纸笔猜它会印出 8 还是 32，再真跑一次对照。为什么这一改就从「一整排」变成了「一张」？
2. **加空名称。** 把第五节那个本子的名称改成六张：`"阿花", NULL, "张三", NULL, NULL, "煤球"`（圈数也要跟着改），先猜屏幕上会多出哪几行，再跑一遍对照。
3. **换两张名称。** 写一个本子：一排三张名称指着三个名字，把**第 0 张和第 2 张对调**（连名称带地址一起换），换完走一圈印出来。想想看：为什么这次能换，而 `row = other` 那次不行？
4. **擦干净再印。** 把第四节那个本子里的 `p = NULL;` 那一行**删掉**，再在最后加一行，印出 `p != NULL` 的结果。先猜这个数会变成几，再跑一遍 —— 然后说说看：这个数能不能拿来判断「窝还在不在」？

我们这一路陪你从第一行 `printf`、数组，走到今天这一排名称 —— **指针这一支，到这儿就走到头了**。名称写错不要紧，怕的是它坏得不声不响 —— 所以每次挂完名称，回头看一眼牌面上写的是什么，再照着走。下一条支流见
