## 学习目标

本课学习查找算法。重点包括线性查找、二分查找、哈希思想。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 第二种找法：每次都往中间砍

工作区边这些元素有一个好脾气：**编号是从小到大摆好的**。有了这个前提，我们就能用第二种找法了 —— **先看正中间那个**：

- 中间那个**比我要找的小** → 那它左边那些更小，全是白看的，整半边**砍掉**，只在右半边接着找；
- 中间那个**比我要找的大** → 左边那半边才有戏，右边整半边**砍掉**。

每比一次，就有一半的元素被排除掉。七只元素最多比 3 次（7 砍成 3、3 砍成 1），一千只元素也只要 10 次 —— 因为它每次都砍一半。

```c
#include <stdio.h>

int fish[7] = {1, 3, 5, 7, 9, 11, 13};

/* 挨着看：从第一个开始一个只比，答「比了几次」；没找到就答负数 */
int line_find(int target) {
    int tries = 0;
    for (int i = 0; i < 7; i++) {
        tries++;
        if (fish[i] == target) {
            return tries;
        }
    }
    return -tries;
}

/* 砍一半：每次先看正中间那个 */
int half_find(int target) {
    int lo = 0;                     /* 还有戏的那一段，头一个的位子 */
    int hi = 6;                     /* 还有戏的那一段，最后一个的位子 */
    int tries = 0;

    while (lo <= hi) {              /* 段里还有元素，就接着找 */
        int mid = (lo + hi) / 2;    /* 正中间那个的位子 */
        tries++;
        if (fish[mid] == target) {
            return tries;
        } else if (fish[mid] < target) {
            lo = mid + 1;           /* 中间那个太小，左边整半边砍掉 */
        } else {
            hi = mid - 1;           /* 中间那个太大，右边整半边砍掉 */
        }
    }
    return -tries;                  /* 段里一个都不剩了，就是没有这一个 */
}

int main(void) {
    int targets[3] = {13, 1, 6};
    for (int i = 0; i < 3; i++) {
        int t = targets[i];
        int a = line_find(t);
        int b = half_find(t);
        printf("找 %d：挨着看 %d 次%s，砍一半 %d 次%s\n", t,
               a < 0 ? -a : a, a < 0 ? "没找到" : "",
               b < 0 ? -b : b, b < 0 ? "没找到" : "");
    }
    return 0;
}
```

```text
找 13：挨着看 7 次，砍一半 3 次
找 1：挨着看 1 次，砍一半 3 次
找 6：挨着看 7 次没找到，砍一半 3 次没找到
```

三行一起看，你就明白该调用哪一个方法了：

- **找 13**：挨着看要 7 次，砍一半只要 3 次 —— 队伍越长，砍一半越占便宜。
- **找 1**：挨着看只要 1 次就中，砍一半还是老老实实比 3 次。**元素少、要找的又正好在前面的时候，挨着看反而快。**
- **找 6**：元素里压根没有 6，两招都得把该看的地方看完，最后照样答「没找到」。

「砍一半」这个词听着含糊：**到底砍掉了什么、还剩哪几个？** 下面拿找 13 那一次，把 `lo`、`hi`、`mid` 三个位子一步一步摆出来。盯着「还有戏的一段」那一栏看它怎么越缩越短。

:::

## 更好的办法：按编号算地址

砍一半虽快，但它总得「比一比」。有没有办法**一步跳到位**、一次都不比？有 —— 前提是编号本身有形状。我们的数据变量有 10 个格子，编号是 0 到 99。那就定个规矩：

```text
格子号 = 编号 ÷ 10 的余数
```

编号 7 进第 7 格，编号 23 进第 3 格，编号 5 进第 5 格。这一手有个名字叫**按编号算地址（哈希）**：拿到编号**算一下**就知道它住哪一格，不用一个只问过去。

麻烦在于：编号 17 算出来也是第 7 格，可第 7 格已经被编号 7 占了。这叫**撞车**。我们的规矩是：撞了车就**往后挪一格**，还撞就再挪 —— 找到第一个空格住下。找的时候也照同一个规矩走一遍：先到算出来的那格敲门，不是它就往后挪，挪到一个**压根没住过东西**的空格，就说明没有这一个。

```c
#include <stdio.h>

#define SLOTS 10

int shelf[SLOTS];
int used[SLOTS];

/* 按编号算门牌号：编号除以 10 的余数 */
int slot_of(int id) {
    return id % SLOTS;
}

void put(int id) {
    int slot = slot_of(id);
    while (used[slot]) {
        slot = (slot + 1) % SLOTS;     /* 撞车了，往后挪一格 */
    }
    shelf[slot] = id;
    used[slot] = 1;
}

/* 答：比了几次才找到；一次都没比就返回 0 */
int find(int id) {
    int slot = slot_of(id);
    int tries = 0;
    while (used[slot]) {
        tries++;
        if (shelf[slot] == id) {
            return tries;
        }
        slot = (slot + 1) % SLOTS;     /* 不是它，照同样的规矩往后挪 */
    }
    return 0;
}

int main(void) {
    put(7);
    put(23);
    put(17);
    put(5);

    printf("找 17：比了 %d 次\n", find(17));
    printf("找 5：比了 %d 次\n", find(5));
    printf("找 99：比了 %d 次\n", find(99));
    return 0;
}
```

```text
找 17：比了 2 次
找 5：比了 1 次
找 99：比了 0 次
```

三行结果正是这一手的脾气：

- **找 5** 只比 1 次 —— 算出来第 5 格，一敲门就是它；
- **找 17** 比了 2 次 —— 算出来第 7 格，可那格住着 7，往后挪一格才找到 17（就是那次撞车的代价）；
- **找 99** 比了 **0** 次 —— 第 9 格压根没住过东西，连门都不用敲：**没有这一个**。

最后那一行最妙：**空格本身就是「这里没有」的证据**。这也是哈希和「挨着看」最大的不同 —— 挨着看必须把该看的地方全看完，才敢下「没有」的结论；哈希只要撞见一个空地，立刻收工。

::: tip 提示
今天记住三句话：**挨着看**最稳，但力气看运气（要找的在最后面就惨了）；**砍一半**每比一次砍掉一半，快得多，但**元素必须已经排好**；**算地址**能一步跳到位，撞车了往后挪一格，撞见空格就是「没有这一个」。
:::
