## 学习目标

本课学习指针深入。重点包括指针运算、指针加减、地址的加减意义。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、名称加一，往后跨一个元素

先从上一课那个「整排元素」的例外讲起：一排元素的名字交出去的时候，交的正是**第一个元素的地址**。所以下面这块名称一初始化就指着第一个元素：

```c
#include <stdio.h>

int main(void) {
    int bowls[4] = {10, 20, 30, 40};
    int *p = bowls;

    printf("%d\n", *p);
    printf("%d\n", *(p + 1));
    printf("%d\n", *(p + 2));
    return 0;
}
```

```text
10
20
30
```

一行一行读：

- **`int *p = bowls;`** —— 名称 `p` 指着第一个元素（`10` 那条）。
- **`*p`** —— 顺着名称走到它指的那个元素前面，拿到 `10`。
- **`*(p + 1)`** —— 先把名称**往后挪一个元素**，再顺着拿。拿到的是第二只元素里的 `20`。
- **`*(p + 2)`** —— 再往后挪一个元素，拿到 `30`。

看出来了吗：**`p + 1` 出来的东西还是块名称**，只不过它指的是「下一个元素」。所以外面还得套一颗星，才轮到「顺着它拿东西」这一步。加号先干、星星后干 —— 我们第四节专门讲这个排队规矩。

## 二、加一到底加了什么？

这是本课最要紧的一句话：

> **名称加一，跨过的是「一整只元素」，不是「一格」。**

元素架上的位置是一格一格排下去的，可名称不是按格走的，它是按**元素**走的。为什么？因为名称上写得清清楚楚它指的是哪种元素 —— `int *` 就是「我指的是装整数的元素」。既然知道每个元素多大，它加一的时候自然就往后跨一整只元素的距离。

```c
#include <stdio.h>

int main(void) {
    int bowls[4] = {10, 20, 30, 40};
    int *p = bowls;

    printf("%d\n", (p + 1) == &bowls[1]);
    printf("%d\n", (p + 3) == &bowls[3]);
    printf("%d\n", (int)(&bowls[3] - &bowls[0]));
    return 0;
}
```

```text
1
1
3
```

- 前两行印 `1`，意思是**真的一样**：`p + 1` 这块名称写的地址，和 `&bowls[1]` 问出来的地址**一字不差**。挪一个元素就是挪一个元素，不是约等于。
- 最后一行是**两块名称相减**：从第一个元素的地址到第四个元素的地址，中间隔了 `3` 只元素。注意它数出来的还是**元素数**（3），不是格数（12）—— 名称的加减从头到尾都用「元素」当单位。

::: tip 提示
记住这句就够用了：**名称加一 = 往后跨一个元素；名称减一 = 往前跨一个元素。** 跨多远由它指的是哪种元素说了算 —— 写着整数的名称跨一整只整数元素（这台机器上是 4 格），写着字符的名称就只跨 1 格。这门手艺等学到字符串那一课，你会看到它有多顺手
:::

## 三、往回挪：名称减一

加得动，当然也减得动。往回挪一格，就是上一个元素：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {10, 20, 30};
    int *p = &bowls[2];

    printf("%d\n", *p);
    p = p - 1;
    printf("%d\n", *p);
    return 0;
}
```

```text
30
20
```

这次名称不是从第一个元素初始化，而是直接指着第三个元素 —— 写法就是**把那个元素的地址问过来**：`&bowls[2]`。然后 `p = p - 1;` 往前跨一个元素，就到 `20` 了。

挪名称的写法有两种，随你挑：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {7, 8, 9};
    int *p = bowls;

    p = p + 1;
    printf("%d\n", *p);
    p++;
    printf("%d\n", *p);
    return 0;
}
```

```text
8
9
```

`p = p + 1;` 是「算出一块新名称，再挂回 `p` 这个名字上」；`p++;` 是同一件事的省字写法，读作「名称往后挪一个元素」。上一阶段「初识指针」那一课学的 `p = &b;` 是**换一个元素指**，今天的 `p++` 是**往后挪** —— 两件事都改名称，但味道不一样。

## 四、星号和加号，谁先排队？

`*p + 1` 和 `*(p + 1)` 长得只差一对括号，干的事却完全不同：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {10, 20, 30};
    int *p = bowls;

    printf("%d\n", *p + 1);
    printf("%d\n", *(p + 1));
    return 0;
}
```

```text
11
20
```

- **`*p + 1`** —— 星星**先**干：顺着名称把 `10` 拿出来，再给这个数加一，得 `11`。名称一动没动。
- **`*(p + 1)`** —— 括号先把名称往后挪一格，再顺着拿，得 `20`。

C 的排队规矩是「**星星比加号靠前**」，所以想先挪名称，就得老老实实**加上一对括号**。少了那对括号，你会得到「元素里的数加一」而不是「下一个元素里的数」—— 结果差了十万八千里，可编译器一次不吭，程序照跑不误。这是本课最容易摔的一跤，摔下去连个响声都没有。

## 五、名称不是数字：拿 `%d` 印地址会怎样

上一阶段「初识指针」那一课提过，地址印出来是一串长得吓人的编号。要是你手一滑，把这块名称直接传给了 `%d`：

```c
#include <stdio.h>

int main(void) {
    int bowls[3] = {1, 2, 3};
    int *p = bowls;

    printf("%d\n", p);
    return 0;
}
```

编译器会嘀咕一句（我们把原话抄在这儿）：

`warning: format '%d' expects argument of type 'int', but argument 2 has type 'int *' [-Wformat=]`

用自然语言解释：**「`%d` 这口槽是给整数的，你塞进来的是块名称呀。」** 但注意 —— 它只是**嘀咕**，不是拦人：程序照样生得出来，跑起来还会高高兴兴印出一串**没意义的数字**给你（我们跑的时候印出来的是 `455080940`，你跑出来的一定和这串不一样，因为每次摆元素的位置都不同）。

**这就是 C 里最需要你留神的一类错**：编译器嘴上说了，手却把你放过去了。程序看起来一切正常，印出来的东西却是垃圾。以后凡是看见 `warning:` 开头的嘀咕，都别当成「没事」。

::: warn 注意
名称加减的时候，别让它挪出整排元素外面去。比如一排只有 3 只元素，你却写了 `int *p = bowls + 5;` 再去 `*p` —— **编译器一个字都不说**（我们真试过，连 warning 都没有），程序也照跑，只是顺手从元素架外面摸了个数回来（我们那一次摸到的是 `828372976`，你摸到的一定是另一个数）。那格子里是什么，谁也说不准；要是你顺着它**往里写**，那就更没准头了 —— 元素架外面的东西会被一个只写坏，出问题的地方和写错的地方能隔出去老远，也可能压根等不到写坏别处、自己先当场断气（我们试过，屏幕上一个字都没印出来），查起来极费眼神。

所以我们的死规矩升级了：**名称当场声明、当场指元素；挪的时候心里数着，绝不挪出整排之外。**
:::

## 六、两块名称加不起来

那名称加名称呢？毕竟加号和减号是亲兄弟，减得动，加总该也加得动吧 —— 想得很美：

```c
#include <stdio.h>

int main(void) {
    int a = 1, b = 2;
    int *p = &a, *q = &b;

    printf("%d\n", p + q);
    return 0;
}
```

```text
main.c:7:22: error: invalid operands to binary + (have 'int *' and 'int *')
    7 |     printf("%d\n", p + q);
```

这句原话的意思是：**「`+` 左右两边都是名称，这两样凑一块儿我们不会算。」** 想想也对 —— 两块名称的地址加起来，指的是哪只元素呢？元素架上没有这么一个元素。

**名称只能跟数字加减，不能跟名称加减。** 唯一能用两块名称做的算术是**相减**（就是第二节最后那行，数出隔了几个元素）。

::: tip 提示
今天收四句话：

1. **名称加一 = 往后跨一个元素**，减一 = 往前跨一个元素；跨多远由名称指的是哪种元素说了算。
2. `p = p + 1;` 和 `p++;` 是同一件事，都是让名称往后挪。
3. **`*p + 1` 是先拿出来再加一；`*(p + 1)` 是先挪名称再拿。** 星星比加号靠前，想挪名称得加括号。
4. **名称只能跟数字加减**；两块名称加不起来，减一减倒是能数出隔了几个元素。
:::
