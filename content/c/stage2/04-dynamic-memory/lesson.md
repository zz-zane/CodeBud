## 学习目标

本课学习动态内存分配。重点包括为什么动态分配、malloc/free、sizeof 运算符、内存泄漏。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## malloc 与 free：租一间，还一间

租变量的函数叫 `malloc`，还变量的函数叫 `free`，它们住在 `stdlib.h` 这位档案管理员家里，所以开头要请它出场。看一个变量的完整一生：

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 4;                                    /* 这次要 4 间 */
    int *rooms = (int *)malloc(sizeof(int) * n);  /* 伸手租 n 间 */

    if (rooms == NULL) {                          /* 没租到怎么办？ */
        printf("变量没租到\n");
        return 1;
    }

    for (int i = 0; i < n; i++) {
        rooms[i] = (i + 1) * 10;                  /* 和数组元素一样按编号取用 */
    }

    for (int i = 0; i < n; i++) {
        printf("第 %d 间：%d\n", i, rooms[i]);
    }

    free(rooms);      /* 用完了，还回去 */
    rooms = NULL;     /* 把名称擦干净，别留着 */
    return 0;
}
```

真跑起来是这样的：

```text
第 0 间：10
第 1 间：20
第 2 间：30
第 3 间：40
```

记住三件事：`malloc` 返回的是一张**指针**，名称上写着第一个变量的地址；租不到时它返回 `NULL`，所以**每次都要看一眼是不是 NULL**；用完了必须 `free`，再把名称擦成 `NULL`，免得下次误以为还能用。

一个变量从租到还，整个过程是这样。留意 `rooms` 这一栏：它自始至终只是一块**名称**，名称上写的是第 0 间的地址 —— 租来的一排变量本身，屏幕上只能看到「第 0 间在哪」和「这几间里保存了什么」这两件事。

## sizeof：随身带的小尺子

`sizeof` 是**运算符**，不是函数：它不用加括号传入，也不必引用名称，写 `sizeof(int)` 和 `sizeof x` 都行，编译器在翻译阶段就把它换成一个小数字了。

那为什么租变量要写 `malloc(sizeof(int) * n)`？因为变量是论**字节**租的，而一个 `int` 占几格要看机器、看类型。让编译器自己拿尺子量一间（`sizeof(int)`），再乘上你要的间数 `n`——**先量一间、再乘间数**，顺序千万别记反。

```c
int arr[5] = {1, 2, 3, 4, 5};
int *p = arr;

printf("%d\n", (int)sizeof(arr));                   /* 20：整排的总格数 */
printf("%d\n", (int)sizeof(p));                     /* 8：名称自己的大小 */
printf("%d\n", (int)(sizeof(arr) / sizeof(arr[0])));/* 5：一共有几个元素 */
```

分成两步看就懂了：量整排给的是**总格数**（20），量一张名称给的是**名称自己的大小**（8）——它可不是被指向那间变量的大小！所以「总格数 ÷ 每个元素的格数」才是元素的只数，这个写法很常用，收下。

::: warn 注意
最大的坑在这：一旦一排元素交到函数手里，收到的只是**一张名称**，函数再拿 `sizeof` 去量，量出来的就只有名称自己（8）啦，那排元素到底有几个它根本问不出来。所以往后的函数要么额外收一个「几个」的传入，要么像以后要学的「链子」那样用末尾的空变量收尾——两种办法我们都会教。
:::

## 内存泄漏：借了变量不还

借了变量不还，管理员就永远腾不出那一间。程序一边跑一边借，地方越占越多，最后会嗷一次被系统赶出去——这就是**内存泄漏（借了变量不还）**。C 里没有**垃圾回收器（内存回收）**，租和还全凭你亲手来。

::: tip 提示
收好这三句：`malloc` 租、`free` 还、还完把名称擦成 `NULL`；`sizeof` 是运算符不是函数，量元素给总格数、量名称只给名称大小；租完先看 `NULL`，用完必定还。
:::
