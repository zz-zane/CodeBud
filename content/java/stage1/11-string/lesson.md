## 学习目标

本课学习String。重点包括String 常用操作、拼接、比较 equals、不可变性直觉。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、先摆一个缸

```java
public class Main {
    public static void main(String[] args) {
        String fish = "数据";
        System.out.println(fish);
        System.out.println(fish.length());
        System.out.println(fish.charAt(0));
        System.out.println(fish + "到手");
        System.out.println("我们有 " + 3 + " 条");
    }
}
```

```text
数据
2
数
数据到手
我们有 3 条
```

一行一行看：

- **`String fish = "数据";`** —— 摆一个叫 `fish` 的缸，里面保存「数据」三条。**双引号**是这串字的边界：引号本身不算内容，就像昨天讲的打印一样。
- **`fish.length()`** —— 缸里**有几条**。两条，所以是 `2`。注意它**带一对小括号**，是要你调用一次才给的活儿（一排元素的 `.length` 就没括号，那是 Java 里最爱绊人的一处不一致，`11` 那课里已经撞过）。
- **`fish.charAt(0)`** —— 掏**第 0 条**出来。编号和 `11` 那课的一排元素一样，**从 `0` 数起**：`charAt(0)` 是「数」，`charAt(1)` 是「据」。
- **`fish + "到手"`** —— 两串接成一串，印出「数据到手」。
- **`"我们有 " + 3 + " 条"`** —— 数字和字符串接起来也行，印出「我们有 3 条」。`+` 碰到这串东西就改行「接字」，这一手昨天在算式里见过。

## 二、常使唤的几个方法

缸身上挂着一堆现成的方法，随调用随用：

```java
public class Main {
    public static void main(String[] args) {
        String s = "  Fish  ";
        System.out.println(s.trim());
        System.out.println(s.trim().toUpperCase());
        System.out.println(s.trim().substring(0, 2));
        System.out.println(s.contains("is"));
        System.out.println(s.indexOf("s"));
    }
}
```

```text
Fish
FISH
Fi
true
4
```

| 方法 | 它干什么 | 这一段的例子 | 结果 |
|---|---|---|---|
| `.length()` | 缸里有几条 | `s.length()` | `8`（两个空格 + Fish + 两个空格） |
| `.trim()` | 把两头的空白掐掉 | `s.trim()` | `Fish` |
| `.toUpperCase()` | 全变成大写 | `s.trim().toUpperCase()` | `FISH` |
| `.substring(a, b)` | 从 `a` 号掏到 `b` 号**之前** | `s.trim().substring(0, 2)` | `Fi` |
| `.contains(x)` | 里面有没有这一小串 | `s.contains("is")` | `true` |
| `.indexOf(x)` | 这一小串在第几号 | `s.indexOf("s")` | `4` |
| `.equals(x)` | 两缸内里一样不一样 | `s.trim().equals("Fish")` | `true` |

两处要盯紧：

- **`substring(0, 2)` 掏到的是 `Fi`，不是 `Fis`** —— 后面那个编号是「**掏到它之前为止**」，`2` 号那颗**不算**。所以掏两颗字符，写的是 `substring(0, 2)`：`0` 号、`1` 号，正好两颗。这一条**永远差一个**，是本课最好摔的地方。
- **方法可以串着调用**：`s.trim().toUpperCase()` 是先把两头空白掐掉、拿到的结果再全变大写。前一个方法返回值上，接着调用下一个方法 —— 一条链子从左往右读下来就行。

`indexOf` 印出来的是 `4`，我们拆给你看：这一串是「空、空、`F`、`i`、`s`、`h`、空、空」，编号从 `0` 数：空是 `0`、空是 `1`、`F` 是 `2`、`i` 是 `3`、`s` 是 `4`。找的是**一模一样**的一小串，所以大小写也算差别。

## 三、`+` 是接字符：注意算式的先后

`+` 在这门语言里有两个身份：**数字身上是加号，缸身上是接字符的线**。一句话里两者混着用的时候，它**从左往右**一个一个算过去 —— 顺序一样，结果可能完全不同：

```java
public class Main {
    public static void main(String[] args) {
        System.out.println(1 + 2 + "");
        System.out.println("" + 1 + 2);
    }
}
```

```text
3
12
```

- **第一句**：先算 `1 + 2`，两边都是数字，老老实实做加法得 `3`；再碰上 `"字"`，改用接字符的线 —— 印出 `3`。
- **第二句**：`"字"` 在最前面，`+` 一登场就是接字符 —— 把 `1` 变成一颗字符接上去，再把 `2` 变成一颗字符接上去，印出 `12`。**它没有做加法**，两个数字是被当成字一个一个字接上去的。

**规律一句话：从左往右算，碰到缸就改行接字符。** 想让数字先加完再接，就给它俩加一对小括号，写成 `(1 + 2) + ""`。

::: tip 提示
接字符这件事，还有一句要记：**只要 `+` 的两边**有一边是这串字，另一个不管是什么（数、名称、另一串字），都会被接上去。所以 `"我们有 " + 3 + " 条"` 才印得出「我们有 3 条」。
:::

## 四、比一样不一样：`.equals(...)`

这一条是 Java 新手摔得最惨的一处，我们上几课提过一次，今天要撞给你看个明白：

```java
public class Main {
    public static void main(String[] args) {
        String a = new String("数据");
        String b = new String("数据");
        System.out.println(a == b);
        System.out.println(a.equals(b));
    }
}
```

```text
false
true
```

两缸里的字**一模一样**，可 `a == b` 印出来是 `false`。

原因在 `==` 问的问题上：它问的是「**你俩是不是同一个缸**」，而不是「你俩里面的字一样不一样」。我们上面是 `new String(...)` **各自做了一个新缸**，两个缸当然不是同一个 —— 于是 `false`。

`a.equals(b)` 问的才是「**内里长得一样吗**」，一颗一颗对过去，`true`。

**规矩就一句：拿两串字比一样不一样，一律 `.equals(...)`，别用 `==`。** 另外提一句：写成 `String a = "数据";`（不用 `new`）的时候，`a == b` 有时候**会碰巧**印出 `true`。碰巧不算数 —— 别去赌那一次运气，规矩照旧。

## 五、缸是焊住的：方法不改原缸，只给你做新缸

```java
public class Main {
    public static void main(String[] args) {
        String s = "张三";
        s.toUpperCase();
        System.out.println(s);
        String t = s.replace("张", "李");
        System.out.println(s);
        System.out.println(t);
        s = "王五";
        System.out.println(s);
    }
}
```

```text
张三
张三
李三
王五
```

- 第二行那句 `s.toUpperCase();` 调用结束了，**`s` 里的字一点没变**，第三行照旧印「张三」。全变成大写的方法**返回了一个新缸**，我们没接住它，它就飘走了。
- `s.replace("张", "李")` 同理：它做了一个新缸「李三」，我们把它接住、起名叫 `t` —— 所以 `s` 印出来还是「张三」，`t` 才是「李三」。
- 最后那句 `s = "王五";` **能改**，但看清楚它是怎么改的：这是把名称 `s` 从「张三」那个缸上摘下来，**重新挂到「王五」那个新缸上**。改的是名称，不是缸。
- **缸里的字符一旦摆好就焊死了，谁都改不动一颗。** 想接住方法做出来的新缸，就得**用名称把它接住**，像 `String t = s.replace(...)` 这样。

「焊住」这三个字光看代码是看不出来的。我们把它拆成一步一步，盯住**名称往哪儿挪**：

::: warn 注意
三个最爱摔的地方，一口气记下来：

- **`s.toUpperCase();` 这样调用结束不接住，等于白调用。** 缸没变、名称也没变，屏幕上什么都看不出来 —— 这种错**不报错、不提醒**，只能靠你自己记住：这串东西的方法**不改原件，只返回新的**。
- **`substring(a, b)` 的 `b` 是「掏到它之前为止」**，多写一个就多掏一颗。掏三颗写 `substring(0, 3)`，不是 `substring(0, 4)`。
- **比两串字一律 `.equals(...)`**；看到两串字中间夹着 `==`，立刻改掉。
:::

## 六、编号越界：编译一次不吭，跑起来才炸

编号从 `0` 数起，那要是一个不留神报了**超出缸里字符数**的编号呢？我们拿一个只有一颗字符的缸试一试：

```java
public class Main {
    public static void main(String[] args) {
        String s = "鱼";
        System.out.println(s.charAt(3));
    }
}
```

```text
Exception in thread "main" java.lang.StringIndexOutOfBoundsException: Index 3 out of bounds for length 1
	at Main.main(Main.java:4)
```

第一行念起来是：**「编号 3 越界了，这个缸只有 1 颗字符。」** 第二行是出事地点：`Main.java` 的第 4 行。这一条和 `11` 那课一排元素的越界是同一个脾气：

| 我们写的 | 什么时候出问题 | 出什么样 |
|---|---|---|
| `s.charAt(3)`（编号越界） | **编译器一次不吭，跑起来才炸** | 一句 `StringIndexOutOfBoundsException`，程序当场断气 |
| `"鱼".charAt(0)`（缸只有一颗） | 正常 | 掏出「鱼」 |

所以掏字符之前，心里先数一遍：**合法的编号是 `0` 到「字符数减一」**。缸里有几颗，调用一句 `.length()` 就问到了。

## 一句话对照表

| 我们写下的 | 它干了什么 |
|---|---|
| `String s = "数据";` | 摆一个缸，保存「数据」三条 |
| `s.length()` | 缸里有几条（`3`） |
| `s.charAt(0)` | 掏第 `0` 条（「数」），编号从 `0` 数起 |
| `s.substring(0, 2)` | 掏 `0` 号到 `2` 号**之前**（`Fi`） |
| `s.trim()` / `s.toUpperCase()` | 掐掉两头空白 / 全变大写 —— **不留原件，另做新缸** |
| `"我们有 " + 3 + " 条"` | 接字符：`+` 有一边是缸，就把另一样接上去 |
| `a.equals(b)` | 两缸内里一样不一样 |
| `a == b` | 两样是不是同一个缸 —— **比字符串千万别用它** |

::: tip 提示
今天记住四句话：

1. **缸里摆着一串字符，字符**从 `0` 号数起，`.length()` 问几颗。
2. **掏字符用 `charAt`，连着一小段用 `substring(a, b)`** —— `b` 是「掏到它之前」。
3. **`+` 有一边是缸，就改行接字符**，一句话从左往右算，`(1 + 2) + ""` 和 `1 + 2 + ""` 一个意思、`"" + 1 + 2` 是另一个意思。
4. **缸是焊住的**：方法不改原件、只返回新缸；比两串字一律 `.equals(...)`。
:::
