## `for`：起点、眼色、收尾

先看它最短的样子：

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            System.out.println(i);
        }
        System.out.println("跑完啦");
    }
}
```

```text
0
1
2
跑完啦
```

小括号里塞了**三段**，被两个分号隔开，我们叫它「起点、眼色、收尾」：

| 位置 | 这一段的原话 | 它负责什么 |
|---|---|---|
| 第一段（起点） | `int i = 0` | 开场前摆一块**圈数牌**，写上「现在跑第几圈」——从 `0` 开始 |
| 第二段（眼色） | `i < 3` | **每一圈开跑前问一句**：还跑吗？答真就再跑一圈，答假就收工 |
| 第三段（收尾） | `i++` | 这一圈跑完，把名称上的数**加 1** |

挂名称的动作**只在开场做一次**；眼色和收尾**每圈都来一遍**。走一遍你就懂了：

| 走到哪 | 名称 `i` 是几 | 眼色 `i < 3` | 大括号里的活儿 | 收尾 `i++` |
|---|---|---|---|---|
| 开场 | 摆上 `0` | 问一次：`0 < 3` 真 → 跑 | 印 `0` | `i` 变成 `1` |
| 第 2 圈 | `1` | `1 < 3` 真 → 跑 | 印 `1` | `i` 变成 `2` |
| 第 3 圈 | `2` | `2 < 3` 真 → 跑 | 印 `2` | `i` 变成 `3` |
| 再来 | `3` | `3 < 3` **假 → 收工** | 不跑 | 收尾也不做了 |

所以屏幕上是 `0`、`1`、`2` 三行——**第一句印的是 `0`，不是 `1`**，因为名称是从 `0` 摆起的；要跑满三圈，眼色就得写 `i < 3` 而不是 `i <= 3`。收工之后，程序接着往下跑那句「跑完啦」，它站在圈外，只印一次。

:::

## 圈里干活：把结果攒起来

绕圈的时候，大括号里想干几句干几句。我们想在圈里**把数一个个加起来**：

```java
public class Main {
    public static void main(String[] args) {
        int total = 0;
        for (int i = 1; i <= 4; i++) {
            total = total + i;
        }
        System.out.println(total);
    }
}
```

```text
10
```

这次的起点是 `1`，眼色是 `i <= 4`——跑的是 1、2、3、4 四圈。`total` 这块名称摆在**圈的外面**：圈里每转一圈，都把它「原来的数加上这一圈的 `i`」再赋给它自己身上。

| 圈次 | 名称 `i` | 圈里干的事 | `total` 变成 |
|---|---|---|---|
| 第 1 圈 | `1` | `total = 0 + 1` | `1` |
| 第 2 圈 | `2` | `total = 1 + 2` | `3` |
| 第 3 圈 | `3` | `total = 3 + 3` | `6` |
| 第 4 圈 | `4` | `total = 6 + 4` | `10` |

四圈跑完，`total` 攒到 `10`，圈外的 `println` 把它印出来——**一句一句加，攒出一整个结果**，这是绕圈最爱干的一种活儿。

## `while`：只写眼色，收尾自己记着

`for` 适合「我知道要跑几圈」。可有些活儿是**「跑到某件事发生为止」**——比如元素里的数据发完为止。这种时候 `while` 更方便：

```java
public class Main {
    public static void main(String[] args) {
        int left = 3;
        while (left > 0) {
            System.out.println("元素里还有 " + left + " 条");
            left = left - 1;
        }
        System.out.println("发完啦");
    }
}
```

```text
元素里还有 3 条
元素里还有 2 条
元素里还有 1 条
发完啦
```

`while` 的小括号里**只放眼色**，一行就念完了：**答真就再跑一圈，答假就收工**。跟 `for` 最大的不同在这儿：

- **`for` 的圈数牌在小括号里**，怎么变（`i++`）也写在小括号里，一处就交代干净了。
- **`while` 不管这些**——名称和「怎么变」都得我们自己在圈里写。上面圈里那句 `left = left - 1;` 就是「元素里少一条」，**忘了写它，`left > 0` 就永远答真，这一圈绕不完**。

`left = left - 1` 这种「自己减一」的活儿太常干，Java 备了句缩写：`left--`，意思和它一模一样。下面这段把上面那段缩着写，屏幕上一个字都不差：

```java
public class Main {
    public static void main(String[] args) {
        int left = 2;
        while (left > 0) {
            System.out.println("还剩 " + left + " 条");
            left--;
        }
        System.out.println("发完啦");
    }
}
```

```text
还剩 2 条
还剩 1 条
发完啦
```

（`left--` 是「减 1」，那 `left++` 当然是「加 1」——上一课和这一课都见过了。）

::: warn 注意
`while` 最阴的坑是「**忘了让圈子向前走**」：圈子里的东西一直不变，眼色就永远答真，程序卡在那儿绕不完，屏幕刷个不停——商品都处理完成了它还没停。写 `while` 的时候，我们自己的土办法是：**写完先低头看一眼圈里有没有一句在改那个数**。`for` 就不会有这个问题，因为「怎么变」写在开头那小括号里了。
:::

### 先问后做，还是先做后问

`while` 是先问后做：眼色答假，圈子里的活儿**一次都不干**。可有些活儿是「先干一次再说」——比如哪怕元素空了，也要先低头看一眼再决定。这种时候用 `do` / `while`：

```java
public class Main {
    public static void main(String[] args) {
        int left = 0;

        while (left > 0) {
            System.out.println("这一句一次都不会印");
        }

        do {
            System.out.println("我们先发一条再说");
        } while (left > 0);

        System.out.println("收工");
    }
}
```

```text
我们先发一条再说
收工
```

元素里是 0 条，两段的差别全露出来了：

- 上面那个 `while`，眼色一上来就问「比 0 大吗」，答假——圈里那句**一次都没印**。
- 下面的 `do` / `while`，**先干一圈再问**：所以「我们先发一条再说」印了出来；问的时候答假，就不再来第二圈了。

记法只有一句：**`do` / `while` 上的眼色在小括号里、后面跟着一个分号**，而且它的活儿**至少干一次**。

## 什么时候用 `for`，什么时候用 `while`

| 心里的规矩长这样 | 用哪个 | 为什么 |
|---|---|---|
| 「绕 N 圈」「从 0 数到 N」——**圈数摆得出来** | `for` | 起点、眼色、收尾挤在一处，一眼看清跑几圈 |
| 「跑到元素空为止」「跑到那条鱼上钩为止」——**圈数说不准** | `while` | 只有眼色说了算，跑几圈看当时的情况 |
| 「先干一次，再决定要不要接着干」 | `do` / `while` | 先做后问，第一圈必跑 |

两个换着用也行：`for` 能写的，`while` 基本都能写，只是要多写几行管名称。挑顺手的那个。

## 半路刹车：`break` 与 `continue`

绕圈绕到一半，我们有时候想提前收工，有时候只想跳过这一圈。Java 给了两个词：

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 10; i++) {
            if (i == 4) {
                break;
            }
            System.out.println(i);
        }
        System.out.println("收工");

        for (int i = 1; i <= 5; i++) {
            if (i == 3) {
                continue;
            }
            System.out.println(i);
        }
        System.out.println("跑完");
    }
}
```

```text
1
2
3
收工
1
2
4
5
跑完
```

- **`break`：这一圈不跑了，整个圈也不跑了，直接跳到圈外去。** 第一个圈子数到 `i == 4` 时踩了刹车——`4` 到 `10` 全没印，屏幕上只有 `1`、`2`、`3`，接着就印「收工」。
- **`continue`：这一圈剩下的活儿不干了，但圈子接着绕下一圈。** 第二个圈跑到 `i == 3` 时跳过——屏幕上是 `1`、`2`、`4`、`5`，**只有 `3` 不见了**，最后照样印「跑完」。

一句话分工：**`break` 是不绕了，`continue` 是这一圈先不算**。上一课 `switch` 里的那个 `break` 也是「不干了下班」，跟这儿是一个意思。

::: tip 提示
`break` 这个名字在 Java 里是**一次只负责最里面那一层圈**。要是圈子里面套圈子，里头的 `break` 只把里圈刹停，外圈接着走——所以踩刹车之前，先看清自己在第几层。
:::

## 圈里还能套圈子

我们发数据是**一排一排**发的：外圈管「第几排」，里圈管「这一排第几个」。两把圈叠起来就这么写：

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 1; i <= 2; i++) {
            for (int j = 1; j <= 3; j++) {
                System.out.println("第 " + i + " 排，第 " + j + " 只");
            }
        }
    }
}
```

```text
第 1 排，第 1 只
第 1 排，第 2 只
第 1 排，第 3 只
第 2 排，第 1 只
第 2 排，第 2 只
第 2 排，第 3 只
```

看屏幕上的排法就懂它的脾气了：**里圈要整整齐齐跑完一整轮，外圈才往前挪一步**。外圈站在 `i = 1` 的时候，里圈把 `j` 从 `1` 跑到 `3`（三个对象各发一条），里圈收工，外圈才轮到 `i = 2`，里圈又从 `j = 1` 重头跑一遍。所以印出来是**先「1 排 1、2、3 只」，再「2 排 1、2、3 只」**，一共六行。

## 拿错料会怎样

先看我们最爱忘的一件事：**圈数牌只住在圈里**。在圈外叫它，编译器就翻白眼了：

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 0; i < 3; i++) {
            System.out.println("绕一圈");
        }
        System.out.println(i);
    }
}
```

```text
Main.java:6: error: cannot find symbol
        System.out.println(i);
                           ^
  symbol:   variable i
  location: class Main
1 error
```

翻译过来是：**「`i` 是谁？我们不认识。」** `int i = 0` 是在 `for` 的小括号里摆的名称，它**只活在这个圈里**——圈子一收工，名称就跟着撤了，圈外那句自然找不到人。想在圈外接着用圈数，就得把名称摆到圈子外面去（像前面那个 `total` 那样）。

再看分号：`for` 小括号里那三段是靠分号分开的，少写一个——

```java
public class Main {
    public static void main(String[] args) {
        for (int i = 0 i < 3; i++) {
            System.out.println("绕一圈");
        }
    }
}
```

```text
Main.java:3: error: ';' expected
        for (int i = 0 i < 3; i++) {
                      ^
1 error
```

**「这儿该有个分号。」** 记住 `for` 小括号的样子：**起点 ; 眼色 ; 收尾**——两个分号，不多不少，位置也固定。

::: tip 提示
今天的绕圈五句话：

1. **`for`：起点、眼色、收尾**，两个分号隔开；挂名称只做一次，眼色和收尾每圈都来。
2. **名称从 `0` 摆起、眼色写 `< 3`，就正好跑三圈**；想跑满三圈别顺手写 `<= 3`。
3. **`while` 只写眼色**，名称怎么变要自己在圈里写——**忘了写，这一圈就绕不完**。
4. **`do` / `while` 先做后问**，活儿至少干一次；眼色在小括号里，后面跟着一个分号。
5. **`break` 是不绕了，`continue` 是这一圈先不算**；圈里还可以套圈，里圈跑完一整轮，外圈才走一步。
:::
