## 学习目标

本课学习STL 总览与迭代器。重点包括STL 地图、迭代器概念、遍历方式。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、STL 地图：三样家当

STL 这个变量中，能拿出来用的家当分成三堆：

| 家当 | 是干什么的 | 我们的叫法 |
|---|---|---|
| **柜子** | 装东西的地方 —— 会自己长大、自己缩小的各种储物柜 | 容器 |
| **变量** | 指着柜子里某一格的「一指就到的名称」，能从这格挪到下一格 | 迭代器 |
| **函数** | 现成的干活本领：排排坐、找东西、整柜换货…… | 算法 |

三样里，**柜子和变量今天就要用**；现成函数是后面某一课的正题（今天只在最后远远看一眼）。

这三样的关系很像我们收拾数据的全套流程：柜子负责装、变量负责指着「现在这一格」、函数的活是「把这些柜子搬来搬去地折腾」。**变量是把柜子和函数缝在一起的那根线** —— 所以它今天是主角。

## 二、第一个柜子：会自己长大的 `vector`

我们先把最常用的那个柜子请出来，它叫 `vector`（念「维克特」）。

请柜子的规矩和以前一样：开头写一句 `#include`，把 `vector` 借出来。然后就可以照下面这样用了：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);
    cout << v.size() << endl;
    cout << v[0] << endl;
    return 0;
}
```

```text
3
3
```

逐句拆开看：

1. **`vector<int> v;`** —— 开一个柜子，起名叫 `v`。名字后面那对**尖括号**里写的是 `int`，意思就是「这个柜子里只放整数」。这句一念完，柜子是**空的** —— 空的没关系，它会自己长大。
2. **`v.push_back(3);`** —— 往柜子**最后面塞一格**，塞进去的是 `3`。（`push_back` 念作「扑许·拜克」，字面意思就是「从后面推」。）
3. **`v.size()`** —— 问「柜子里现在有几格」。塞了三条，所以印出 `3`。
4. **`v[0]`** —— 报编号取货，**编号从 0 数起**，和上一阶段那排数组元素一模一样。

和那排钉死的数组元素比一比：`push_back` 是本课最舒服的一件事 —— **不用事先说好要几格**。塞一条它就长一格，塞一百条就长一百格。

::: tip 提示
`vector` 就是「列表」，学名**容器**。它比那排钉死的数组元素多给的东西不止一样：`push_back` 能随时加、`size()` 能随时问、还能整柜一起递给别人。**今天先记住这三个动作：开柜子、塞一格、问几格。**
:::

## 三、变量：`begin()` 和 `end()`

柜子有了，现在的问题是**怎么一格一格地走**。

报编号当然也行（`v[0]`、`v[1]`、`v[2]`……），可我们得自己数到几才停 —— 万一柜子里有三百格呢？我们想要的是**一个变量**：它指着「现在这一格」，我们调用一次「挪」，它就自己挪到下一格。

C++ 给的正是一对这样的变量：

- **`v.begin()`** —— 一个指着**第一格**的变量；
- **`v.end()`** —— 一个指着**最后一格的后面一格**的变量。

`end()` 这句要停下来多想一秒：它指的**不是最后一格**，而是最后一格**再往后一格** —— 那一格是**不存在**的，它更像柜子尽头站着的一个「到此为止」的看门对象。为什么要这样？因为这样一来，「走完了没有」就有了一个特别干脆的判据：**变量挪到和 `end()` 站在一起，就是走完了**。

这一个执行线程合起来，就是我们走柜子的标准姿势：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);

    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << endl;
    }
    return 0;
}
```

```text
3
8
5
```

拆开看这跑法：

- **`auto it = v.begin()`** —— 起一个叫 `it` 的变量，一开始指着第一格。（`auto` 是「你自己看着办，名字替我写上」；不写它也成，只是那一长串名字我们懒得敲。）
- **`it != v.end()`** —— 只要变量**还没走到看门对象那儿**，就继续跑。
- **`*it`** —— 把变量指着的**那一格里的货**取出来。**那颗小星星读作「指着的那一格」**，少了它，取到的就不是货了（下面有现成的报错）。
- **`++it`** —— 把变量**挪到下一格**。

### 最容易摔的一跤：少了那颗小星星

`it` 和 `*it` 长得只差一个字符，可意思差着一整格货：`*it` 是「指着的**那一格**」，`it` 是「**名称本身**」—— 名称不是一个用来印的整数，编译器不认。我们拿下面这段真跑过一遍，它当场就把我们拦下了：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);

    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << it << endl;
    }
    return 0;
}
```

```text
main.cpp:11:14: error: no match for 'operator<<' (operand types are 'std::ostream' {aka 'std::basic_ostream<char>'} and '__gnu_cxx::__normal_iterator<int*, std::vector<int> >')
      11 |         cout << it << endl;
```

念作：**「`<<` 的右半边要的是一个能印的东西，你递过来的是一张 `__gnu_cxx::__normal_iterator` —— 也就是『变量』。变量印不出来。」** 看到 `no match for 'operator<<'`，先低头看 `<<` 右边那一坨：**该有的星星是不是漏了。**

## 四、走柜子的三套姿势

同一件事（把柜子从第一格走到最后一格），C++ 里有三套写法。我们建议你这样记：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(3);
    v.push_back(8);
    v.push_back(5);

    cout << "用变量：" << endl;
    for (auto it = v.begin(); it != v.end(); ++it) {
        cout << *it << endl;
    }

    cout << "用新写法：" << endl;
    for (int x : v) {
        cout << x << endl;
    }

    cout << "报编号：" << endl;
    for (int i = 0; i < v.size(); i++) {
        cout << v[i] << endl;
    }
    return 0;
}
```

```text
用变量：
3
8
5
用新写法：
3
8
5
报编号：
3
8
5
```

**第二套写法**长得像念咒：`for (int x : v)` 念作「**把 `v` 里的货，一格一格地交给 `x`**」。这一套最短、最不容易写错，日常用得最多。

**第三套**就是报编号 —— 它和上一阶段那排数组元素的走法一样。注意这里有个细节：`v.size()` 给的格数，所以编号跑到 `v.size() - 1` 就是最后一格了，条件是 `i < v.size()`，别写成 `<=`。

三套怎么挑？我们的经验是：

| 想干什么 | 用哪套 |
|---|---|
| 只把每一格拿出来看看、算一算 | `for (int x : v)` —— 最短最省事 |
| 要边看边改柜子里的货 | 用变量那套，星星前面加一个 `&` |
| 要的是编号（比如「第几格最大」） | 报编号那套 |
| 要往中间插、要删中间的格 | 变量那套（收在后面某一课） |

### 一个不吵不闹的坑：`int x` 改的是副本

上面那张表第二行那句「星星前面加一个 `&`」，是本课最值钱的一个细节。先看**没有** `&` 的时候会发生什么：

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    for (int x : v) {
        x = x * 2;
    }

    for (int x : v) {
        cout << x << endl;
    }
    return 0;
}
```

```text
1
2
3
```

**柜子里的货一个都没变。** 我们拿最啰嗦的那档念叨（`-Wall`）真跑过一次，编译器**一个字都没说**：编得过、跑得完、结果悄悄地不对。

原因是这套新写法里，`x` 拿到的是**那一格货的一份副本** —— 像我们从柜子里把数据捞出来放在旁边看。改副本，柜子里那份纹丝不动。

要让改动真的落回柜子里，写 `for (int &x : v)` —— 星星前面多一个 `&`，意思是「**这个 `x` 就是柜子里那一格本人**，不是副本」。同一份 `main`，只改这一个字符，再跑一次：

```text
2
4
6
```

**一字之差，从「改了白改」变成「真改动了」。** 这类坑不报错、不警告，只能靠自己记住：**要动柜子里的货，名字前面写 `&`。**

::: warn 注意
`end()` 那一格**是不存在的**，千万别去取货（`*v.end()` 是错的）。它唯一的用处就是当那个「到此为止」的路标。我们的判别口诀是：**变量和 `end()` 站在一起时，柜子就已经走完了** —— 那时候不该再取货，该收工了。
:::

## 五、我们今天记住的三句话

::: tip 提示
1. **STL 有三样家当**：柜子（容器）、变量（迭代器）、现成函数（算法）。今天用的是前两样。
2. **`vector` 是列表**：`v.push_back(x)` 往后塞一格、`v.size()` 问几格、`v[i]` 报编号取货（编号从 0 起）。
3. **走柜子的标准姿势**：`for (auto it = v.begin(); it != v.end(); ++it)` —— `*it` 是那一格的货、`++it` 是挪到下一格；嫌啰嗦就用 `for (int x : v)`，**要改货就写 `for (int &x : v)`**。
:::

## 一句话对照表

| 我们写下的 | 它的意思 |
|---|---|
| `vector` 后面尖括号里写 `int`、再起名 `v` | 开一个只放整数的柜子（一开始是空的） |
| `v.push_back(3);` | 往柜子最后面塞一格，塞的是 `3` |
| `v.size()` | 柜子里现在有几格 |
| `v[0]` | 报编号取货，**编号从 0 数起** |
| `v.begin()` | 指着**第一格**的变量 |
| `v.end()` | 指着**最后一格的后面一格**的变量（那格不存在，是路标） |
| `for (auto it = v.begin(); it != v.end(); ++it)` | 从第一格走到走完为止 |
| `*it` | 变量**指着的那一格里的货** |
| `++it` | 把变量挪到下一格 |
| `for (int x : v)` | 一格一格地看每一份**副本** |
| `for (int &x : v)` | 一格一格地**直接动柜子里的货** |
