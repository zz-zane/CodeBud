## 学习目标

本课学习RAII。重点包括资源获取即初始化、作用域即生命周期、应用。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、先看看「手写开关」漏在哪

上一课的变量换成了**库房门**：进门要推、出门要关。我们先用手写的写法来一遍 —— 两个函数，一个开一个关，进了门自己记着调用。

```cpp
#include <iostream>
#include <string>
using namespace std;

void openDoor(string who) { cout << "推开 " << who << endl; }
void closeDoor(string who) { cout << "关上 " << who << endl; }

void work(bool early) {
    openDoor("库房门");
    if (early) {
        return;
    }
    cout << "取了数据" << endl;
    closeDoor("库房门");
}

int main() {
    work(false);
    cout << "--- 提前出门那一趟 ---" << endl;
    work(true);
    cout << "收工" << endl;
    return 0;
}
```

```text
推开 库房门
取了数据
关上 库房门
--- 提前出门那一趟 ---
推开 库房门
收工
```

第二趟又是老毛病：门**推开了**，`关上` 一次都没印。原因和上一课一模一样 —— 那句 `if (early) { return; }` 把 `closeDoor` 整个跳过去了。

::: warn 注意
「关门」这件事的危险程度和内存不一样：变量忘了还，程序还能跑完；**门忘了关**，第二个对象一推就推不开了（真实世界里的文件、锁、连接，全都在这一档）。所以这条法则必须刻进骨头。
:::

## 二、黄金法则：领在初始化证上，还在死亡证明上

RAII 三个字母是 Resource Acquisition Is Initialization 的缩写，直译过来是**「资源的获取就是初始化」**。念着拗口，拆开看只有两句话：

- **领**资源这件事，写进**构造函数（构造函数）**里 —— 名称一初始化就把门推开；
- **还**资源这件事，写进**析构函数（析构函数）**里 —— 名称一死就把门关上。

我们把「库房门」也做成一块这样的名称：

```cpp
#include <iostream>
#include <string>
using namespace std;

struct Door {
    string who;
    Door(string w) : who(w) { cout << "推开 " << who << endl; }
    ~Door() { cout << "关上 " << who << endl; }
};

void work(bool early) {
    Door d("库房门");
    if (early) {
        return;
    }
    cout << "取了数据" << endl;
}

int main() {
    work(false);
    cout << "--- 提前出门那一趟 ---" << endl;
    work(true);
    cout << "收工" << endl;
    return 0;
}
```

```text
推开 库房门
取了数据
关上 库房门
--- 提前出门那一趟 ---
推开 库房门
关上 库房门
收工
```

对着上一节那版看一眼就懂了：**都是提前出门，一个漏、一个不漏**。

差别只有两处，都在 `Door` 这块名称里：`Door(...)` 是**初始化时**干的事（推门），`~Door()` 是**死去时**干的事（关门）。我们的 `work` 里再没出现过「关」这个字 —— 可它照样关上了。**领和还都被写进了名称的生死里，中间那条路上怎么走，就没有漏的机会了。**

::: tip 提示
记号别记错：`~` 念作「析构」，`~Door()` 就是「Door 这块名称死的时候要做的事」。C++ 会在名称**离开它初始化的那片花括号**时自动称呼它一次，我们不用手动叫。
:::

## 三、作用域就是生命线

为什么名称知道该什么时候死？因为在 C++ 里，**那些不带 `new` 的局部家伙就活在那片花括号里**：花括号开始，它初始化；花括号结束，它死亡。这件事有个正式说法叫**作用域**，名称的**生命周期**就是它。

所以「提前出门也不漏」根本不是什么特殊照顾 —— `return`、`break`、抛异常、甚至只是花括号走到头，**这些路的终点都是「走出花括号」**，名称一律在那儿等着还东西。

看一个更细的例子：门里面的门。

```cpp
#include <iostream>
using namespace std;

struct Door {
    string who;
    Door(string w) : who(w) { cout << "开 " << who << endl; }
    ~Door() { cout << "关 " << who << endl; }
};

int main() {
    Door outer("大门");
    {
        Door inner("里屋");
        cout << "在里屋翻数据" << endl;
    }
    cout << "回到大门" << endl;
    return 0;
}
```

```text
开 大门
开 里屋
在里屋翻数据
关 里屋
回到大门
关 大门
```

盯住顺序：**后开的先关**（`里屋` 在 `大门` 前面关掉）。这就是叠盘子 —— 后放上去的先拿下来。C++ 的规矩是「谁后初始化，谁先死」，所以里屋那块名称先走，大门那块才走。

这一条有个很实在的用处：**只要把名称请进一层花括号，就等于给这件事划了一个「只管这么长」的圈** —— 圈的尽头自动收摊。

## 四、不只是内存：领的东西可以是一个「状态」

黄金法则最讨喜的地方是：**「资源」这两个字不限于变量**。借来的账本、打开的文件、临时改掉的设置，凡是「用完得还原」的东西，都能做成名称。

我们写了个小活儿：有些话要小声说，说完就得恢复正常。手写的写法得记着在每条出门的路上调用一次「恢复」，我们换成名称来拿：

```cpp
#include <iostream>
using namespace std;

bool loud = true;

struct Quiet {
    bool old;
    Quiet() : old(loud) {
        loud = false;
        cout << "（小声说话）" << endl;
    }
    ~Quiet() {
        loud = old;
        cout << "（恢复说话）" << endl;
    }
};

void say(const char* s) {
    if (loud) {
        cout << s << endl;
    } else {
        cout << "……" << endl;
    }
}

int main() {
    say("计算机早");
    {
        Quiet q;
        say("计算机早");
    }
    say("计算机早");
    return 0;
}
```

```text
计算机早
（小声说话）
……
（恢复说话）
计算机早
```

名称 `q` 初始化时把 `old`（**原来的**那个值）记在手心里，然后把自己需要的样子换上；死的时候把 `old` 还回去。中间那句 `say("计算机早")` 印的是 `……`，出了花括号又正常了。

这套「**先记住旧样子，出门再换回来**」的写法，我们后面讲文件、讲锁的时候还会用 —— 它们全都是同一块名称，只是领的东西不一样。

## 五、回头看：上一课那位帮手就是这条法则的一张脸

上一课请名称那句话，是 `unique_ptr<Fish> p = make_unique<Fish>("计算机");`。把这句话拆开，正好是黄金法则的两半：`make_unique` 在**构造函数里**把变量租下来（领），`unique_ptr` 的**析构函数**把变量还回去（还）。所以「走出花括号就自己还」不是名称的什么小聪明，是**顺序**：领写进构造函数、还写进析构函数、生死交给作用域。

同一张脸我们还会在别处见到：

- `shared_ptr` —— 数着人头，最后一根手指松开时还；
- 文件流 —— 打开的文件在名称死时自己关（后面有一课专门讲它）；
- 锁 —— 进了变量锁上门，出门自己开（我们在「多线程执行」那一阶段会正式见到它）。

::: tip 提示
判断一段代码「像不像 RAII」有个一秒钟的办法：**找 `new` / 打开 / 上锁的地方，看那个「还」是不是一个字都不用写。** 要是还得在每条出门的路上手动补一句，那就不是这张脸。
:::

## 一句话对照表

| 想干什么 | 写什么 |
|---|---|
| 领资源 + 记上「要还」 | 写在**构造函数**里（`Door(string w) { ... }`） |
| 还资源 | 写在**析构函数**里（`~Door() { ... }`） |
| 什么时候还 | 名称走出它初始化的那片**花括号**（作用域结束） |
| 提前出门 / 抛异常也不漏 | 一个字都不用写 —— 那些路的终点都是「走出花括号」 |
| 只让某一段生效 | 把名称请进一层花括号，圈的尽头自动收摊 |
| 临时换状态，出门还原 | 在构造函数里**先记下旧值**，析构函数里换回去 |
