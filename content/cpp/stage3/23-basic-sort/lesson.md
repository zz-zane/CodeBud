## 学习目标

本课学习基础排序。重点包括三种排序、复杂度直觉、何时用哪个。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 冒泡法：两两比一比，慢慢浮上去

第一个方法最憨，也最好懂：**从头到尾，挨着的两个比一比**——左边那个比右边长，就换个个儿。这样走完一趟，最长的那个一定被一路换到了最末尾。

```cpp
#include <iostream>
#include <vector>

/* 冒泡：挨着的两个比一比，左边比右边长的就换个个儿 */
void bubble_sort(std::vector<int>& fish) {
    int n = fish.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            if (fish[j] > fish[j + 1]) {
                int t = fish[j];
                fish[j] = fish[j + 1];
                fish[j + 1] = t;
            }
        }
    }
}

int main() {
    std::vector<int> fish = {5, 2, 9, 1, 8, 6};
    bubble_sort(fish);
    std::cout << "排排坐：";
    for (int i = 0; i < fish.size(); i++) {
        std::cout << fish[i] << " ";
    }
    std::cout << "\n";
    return 0;
}
```

```text
排排坐：1 2 5 6 8 9
```

四句要念清楚：

1. **函数外面的 `&` 是「动手」还是「抄一份」的分水岭**：写着 `std::vector<int>& fish`，函数就对着你那摊数据动手；把这个 `&` 去掉，它就只是抄了一份自己排着玩，外面的摊子原封不动。这个坑不报错、不崩，只是排完一看：咦，一点没变。
2. **外层那一圈管「走几趟」**：一趟只能把一个送到它该在的位子上，所以最多走 `n - 1` 趟。
3. **内层那一圈管「这一趟里比到哪儿」**：写的是 `j < n - 1 - i`，那个 `- i` 是因为**末尾的 `i` 只已经站好了**，不用再比。
4. **换位子要用一个手**：`int t = fish[j];` 先把这个捧在手上，再挪、再放回去。少了这个手，两个都会变成同一个值。

下面把**第一趟**完整走一遍。这一趟最值得看的是第 6~8 步：换一次位子为什么要写成三行。盯着 `这排数据` 那一栏，它每一步都是当前真实的摊位。

`fish[j] = fish[j + 1];` 执行完的那一瞬间，摊位上是 `2 2 9 1 8 6` ——

这个错**不报错、不崩**，只是排出来的结果少了一个数 —— 所以「先捧住」这三个字永远手写。

## 这一个方法要跑多少圈？

数一数就知道它有多累。六只数据，第一趟比 5 次、第二趟比 4 次……加起来是 15 次：

```cpp
#include <iostream>

int main() {
    int n = 6;
    int times = 0;
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - 1 - i; j++) {
            times++;
        }
    }
    std::cout << "6 只数据，两两比一比要 " << times << " 次\n";
    return 0;
}
```

```text
6 只数据，两两比一比要 15 次
```

15 就是 6 乘 5 再除以 2。记住这个形状：**数据变成 n 只，比一比的次数大约就是 n 乘 n 再除以 2** —— 数据翻一倍，次数翻**四倍**。十只数据比 45 次，一百只数据就要比 4950 次，一千只数据是 499500 次。这就是为什么数据一多，憨办法就处理不消了：我们的变量再快，也架不住次数这么涨。（这个「涨得多快」的账，`cpp-stage3-16` 那一课专门算过。）

## 挑最短法：每一轮先选出最短的一个

第二招改了个思路：**不再两两换着走，而是每一轮先扫一遍，找出剩下这些里最短的那个**，然后请它和最前面那个换个位子。一轮只换一次，但一轮能定下一个。

```cpp
#include <iostream>
#include <vector>

/* 每一轮先挑出最短的一个，和最前面那个换个位子 */
void selection_sort(std::vector<int>& fish) {
    int n = fish.size();
    for (int i = 0; i < n - 1; i++) {
        int shortest = i;                 /* 先假定最前面那个最短 */
        for (int j = i + 1; j < n; j++) {
            if (fish[j] < fish[shortest]) {
                shortest = j;             /* 遇到更短的，记下它的位子 */
            }
        }
        if (shortest != i) {
            int t = fish[i];
            fish[i] = fish[shortest];
            fish[shortest] = t;
        }
    }
}

int main() {
    std::vector<int> fish = {7, 3, 9, 1, 4};
    selection_sort(fish);
    std::cout << "挑最短：";
    for (int i = 0; i < fish.size(); i++) {
        std::cout << fish[i] << " ";
    }
    std::cout << "\n";
    return 0;
}
```

```text
挑最短：1 3 4 7 9
```

它和冒泡最大的差别在**换位子的次数**：挑最短法一轮只换一次（或者一次都不换），冒泡一趟可能换好几次。要是「换一次」很贵（比如数据特别大，搬起来费劲），挑最短法就划算。

## 理牌法：摸一张，插进已经理好的一小段

第三个方法最像我们理牌：手里已经理好一小叠，新摸起一张，就**从后往前比**，比它长的都往后挪一格，腾出来的位子就是它的。第一张牌不用理（一张牌本来就整齐），所以从第二张开始。

```cpp
#include <iostream>
#include <vector>

/* 摸起一张往前比，比它长的都往后挪一格，腾出的位子就是它的 */
void insertion_sort(std::vector<int>& fish) {
    int n = fish.size();
    for (int i = 1; i < n; i++) {
        int hold = fish[i];               /* 摸起来捧在手上 */
        int j = i - 1;
        while (j >= 0 && fish[j] > hold) {
            fish[j + 1] = fish[j];        /* 比它长的往后挪一格 */
            j--;
        }
        fish[j + 1] = hold;               /* 腾出来的位子，放下 */
    }
}

int main() {
    std::vector<int> fish = {6, 1, 8, 2, 5};
    insertion_sort(fish);
    std::cout << "理牌式：";
    for (int i = 0; i < fish.size(); i++) {
        std::cout << fish[i] << " ";
    }
    std::cout << "\n";
    return 0;
}
```

```text
理牌式：1 2 5 6 8
```

⚠️ 那个 `j >= 0` 是**收手条件**：一路比到最前面（`j` 退到 -1）就得停，不然变量会伸到摊子外面去。它的前半句 `fish[j] > hold` 是「还没找到该停的位子」，两半缺一不可。

## 什么时候用哪一个方法

三个方法的「比一比的次数」其实**差不多**，都是 n 乘 n 那个形状。真正让它们分高下的是别的东西：

| 办法 | 最擅长的事 | 什么时候称呼它 |
|---|---|---|
| 冒泡 | 一眼看懂、代码最短 | 数据很少，或者我们只是想给你讲清楚「排排坐是怎么回事」 |
| 挑最短 | 换位子的次数特别少 | 搬一个数据很贵、比一比很便宜的时候 |
| 理牌 | **摊子本来就差不多整齐**的时候 | 只添了一两个新的，前面那一叠早就理好了 |

理牌法最后那一格值得多念两遍：如果一摊数据**本来就挺整齐**，它真的快得惊人 —— 我们量过，六只已经排好的数据，理牌只比了 `5` 次，另两招都得比 `15` 次。

可要是**完全倒着摆**（最长的那个在最前面），名次就跟直觉不一样了 —— 同样六只，我们量出来是：挨着比、慢慢挪的那招**挪了 `15` 次**；挑最短只挪 `3` 次；理牌**也要挪 `15` 次**（三个方法「比一比」的次数都是 `15`，一样多）。**所以「理牌最慢」这话是错的**：倒着摆的时候，费变量的是**挪得多**的那两招，省变量的是挑最短。所以「哪一个方法好」这个问题，得先看**你的数据长什么样**。

::: tip 提示
今天记住三句话：**冒泡**是「挨着比、慢慢挪」；**挑最短**是「每轮选冠军、只换一次」；**理牌**是「摸一张、往前插」。三个方法的目标都是「从短到长」，比一比的次数都是 n 乘 n 那个形状 —— 差别在它们怎么动变量。

写给学过 C 的对象：这三个方法在 C 里是拿一排 `int fish[6]` 干的，在 C++ 里换成 `std::vector<int>`，三行交换的地方也可以写成 `std::swap(fish[j], fish[j + 1]);` —— 这类**现成的函数**，我们在「现成函数大全」那一课专门讲，今天先自己动手写一遍，才看得懂它替你做了什么。
:::

::: warn 注意
两个坑，我们盯着屏幕见过好几次：① 内层那一圈写到 `j < n` 就**伸到摊子外面**去了：`fish[j + 1]` 在 `j` 是最后一个时会碰到不属于你的地方（`vector` 上会用 `.at()` 当场调用停，用 `[]` 则是读出个莫名其妙的数）；② 函数上**忘了写 `&`** —— 程序照样跑、照样不报错，可排好的只是它抄走的那一份，你外面的摊子一点没变。这两个错都属于「不吭声」的那种，写完记得先印出来看一眼。
:::

## 小任务

把冒泡法改一改：如果**这一趟一次都没换过**，说明摊子已经整整齐齐了，那就别再白跑剩下的趟数，直接收工（提示：多加一个数记「这趟换过没有」，外层每趟开头把它清零）。拿一摊本来就排好的数据试试，看看它是不是只跑了一趟就停手了。
