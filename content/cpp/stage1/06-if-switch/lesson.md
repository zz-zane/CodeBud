## `if`：眼色要用小括号圈起来

先看最小的形状。我们只问一句：「元素里还有数据吗？」

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;

    if (fish > 0) {
        cout << "元素里还有数据，开始处理" << endl;
    }
    return 0;
}
```

```text
元素里还有数据，开始处理
```

盯着 `if (fish > 0) {` 这一行看，它其实是三块拼起来的：

1. **`if`** —— 开场白，意思是「我们要问一句眼色了」。
2. **一对小括号 `( )`** —— 眼色**必须**住在里面。这是 C++ 的硬规矩，漏了小括号，编译器连门都不让你进。
3. **一对大括号 `{ }`** —— 圈住「归这条路管的话」。眼色答真，大括号里的话才上场；答假，整块跳过。

**这里正是 C++ 和 Python 气质不同的地方。** 你在通用课里见过的 Python，是用冒号加缩进来划分「哪句话归谁管」的；C++ 不认缩进，它只认**大括号**。所以我们在大括号里把每一行都往里推 4 格，纯粹是为了好读 —— 就算把它们挤成一行，编译器也照样认。

上面那段里还有一样新东西：`cout << "……" << endl;`。

- **`cout`** 读作「往外调用」，作用和你见过的打印函数一样：把东西调用到屏幕上。
- **`<<`** 是**输入接口**，一个不够可以连着写好几个，东西会一个接一个输出。
- **`endl`** 是「换一个新行」，调用结束它光标就跳到下一行。忘了写它，下一次的输出就会**接在这一行的屁股后面**。

## `else`：眼色答假时走的那条路

只有一条路要挑的时候，一个 `if` 就够了。可我们还想说一句「要是元素空了呢」，那就请 `else` 出场：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 0;

    if (fish > 0) {
        cout << "有数据，开始处理" << endl;
    } else {
        cout << "元素空了，去找计算机" << endl;
    }
    return 0;
}
```

```text
元素空了，去找计算机
```

`else` 是这一串的**兜底**：上面每个眼色都答了假，才轮到它。它后面**不写眼色** —— 它不用问，它就是「剩下的全归我」。

**「先算答案、再挑路」这两拍**是怎么走的，我们拆成一步一步，走给你看：

## `else if`：中间那些眼色

三条路的时候，把中间那些眼色写成 `else if`：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 2;

    if (fish >= 5) {
        cout << "数据满满，我们先晒会儿太阳" << endl;
    } else if (fish > 0) {
        cout << "快见底啦，减少消耗" << endl;
    } else {
        cout << "元素空了，去找计算机要点" << endl;
    }
    return 0;
}
```

```text
快见底啦，减少消耗
```

读法只有一句话：**从上往下一个一个问，谁先答「真」就走谁那条路，然后整串眼色到此结束。**

我们把第一行换个数，三条路就都露一次脸：

| `fish` 是几 | 谁答了真 | 屏幕上印出 |
|---|---|---|
| `9` | `fish >= 5` | 数据满满，我们先晒会儿太阳 |
| `2` | `else if (fish > 0)` | 快见底啦，减少消耗 |
| `0` | 前面全答假，轮到 `else` | 元素空了，去找计算机要点 |

顺便交代两件事：

- 中间的候补（`else if`）**想排几个排几个**，一路往下排都行；但一串的末尾最多只站一个兜底。
- `else` **不是非写不可**。不写的话，前面全答假就**什么都不做** —— 这一串眼色整体跳过，程序接着往下跑。

## 一个等号，两个等号

这是新手最常摔的一跤，我们单独拎出来：

- **一个等号 `=`**：把右边**装进**左边的变量。`fish = 3` 是「把 3 装进 `fish`」。
- **两个等号 `==`**：问一句「两边一样吗」，答真或假。

而 C++ 在这里有一个**比 Python 更阴**的脾气：你把一个等号写进眼色里，编译器**不会拦你**，程序照样创建后、照样跑。看：

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 0;

    if (fish = 3) {
        cout << "我们以为元素里有数据" << endl;
    }
    cout << "fish 现在是 " << fish << " " << endl;
    return 0;
}
```

```text
我们以为元素里有数据
fish 现在是 3 
```

元素明明是空的，屏幕上却说「元素里有数据」——因为 `fish = 3` 干的是「把 3 装进 `fish`」，这件事本身有个结果值 3。**C++ 里只有「是不是 0」这一条真假规矩：0 算假，别的都算真。** 3 不是 0，于是眼色答真，路就走进去了。

编译器其实看见了，它会小声嘀咕一句 `warning: suggest parentheses around assignment used as truth value`（这句话的意思是「你是不是想写两个等号呀」）。

**但那个是一句警告，不是错误** —— 它不会拦下这份程序。这条和 Python 完全相反：Python 读到这句会当场甩你一个 `SyntaxError` 不让你跑，C++ 只是念叨一句就放你过去，然后给你一个不对的结果。

所以写眼色的时候，**永远回头检查一眼是不是两个等号**。

## 三目运算符：一句话里问完就取值

`if` / `else` 管的是「走哪条路」，可有时候我们只想要**一个值** —— 两条路都得返回点东西回来，然后再比大小。这时候写一整串 `if` 就有点兴师动众了。C++ 给这种活儿准备了一个简短形状：**三目运算符**。

它的长相是：`眼色 ? 答真时取这个 : 答假时取那个`。

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 0;

    cout << (fish > 0 ? "元素里有数据" : "元素空了") << endl;

    int a = 3;
    int b = 5;
    int bigger = a > b ? a : b;
    cout << "更大的那个是 " << bigger << endl;
    return 0;
}
```

```text
元素空了
更大的那个是 5
```

三块家当，一眼就认全：

1. **问号 `?` 前面** —— 就是眼色，跟 `if` 小括号里那句一模一样。`fish > 0` 答假，所以取后面那个。
2. **`?` 和 `:` 中间** —— 眼色答**真**时取的那一样。
3. **冒号 `:` 后面** —— 眼色答**假**时取的那一样。

所以 `a > b ? a : b` 读作「`a` 比 `b` 大吗？大就取 `a`，不然就取 `b`」，返回的那个数正好落进 `bigger` 里。

两件要留心的事：

- **调用 `cout` 的时候，整个三目式子要用小括号包起来**（`(fish > 0 ? "……" : "……")`）。因为 `<<` 的黏人程度比 `? :` 高，不包小括号，编译器会看岔眼。
- **三目只适合「二选一、每个选项是一个值」**。要是每条路要干好几件事（印好几句、算好几步），那就老老实实写 `if` / `else` —— 那才是它该干的活。

::: tip 提示
`if (眼色) { 话 }` 这一行里，**小括号管眼色、大括号管话**。C++ 里这两对括号各有各的活，谁都不能省。看别人的 C++ 代码时，先找小括号 —— 里面那句就是他要问的眼色。
:::

## `switch`：拿一个数去对号入座

眼色问的是「大不大、小不小、一样不一样」，可有些活儿要的是**对号入座**：我们报一个编号，屏幕上就出一条对应的鱼。用一串 `else if` 也能写，但 C++ 给这种活儿准备了专座 —— `switch`：

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice = 2;

    switch (choice) {
        case 1:
            cout << "我们要一条三文鱼" << endl;
            break;
        case 2:
            cout << "我们要一条秋刀鱼" << endl;
            break;
        case 3:
            cout << "我们要一条鳕鱼" << endl;
            break;
        default:
            cout << "这个编号我们不认识" << endl;
            break;
    }
    return 0;
}
```

```text
我们要一条秋刀鱼
```

拆开看，它有四样家当：

1. **`switch (要对的数)`** —— 小括号里放那个「用来对号」的数，这里放的是 `choice`。
2. **`case 值:`** —— 一个编号一张标签，末尾那个**冒号**一个都不能少。
3. **`break;`** —— 每段标签末尾上的「出去吧」。它就是「这一条道走到底了，别再往下走」的意思。（`break` 这个词我们下一课还要专门请出来讲，今天先认个脸：在 `switch` 里它的活就是**把路封住**。）
4. **`default:`** —— 兜底那张标签，前面所有 `case` 都对不上时才轮到它。它不用给值，因为它就是「剩下的全归我」。

有两件事要提醒你：

- **`switch` 只能问「等不等于某一个值」**，号码、编号、菜单上的数字都很合适。但「大于 60 吗」这种**范围**的问话它答不了，那还得请 `if` 出场。
- **对号的数和 `case` 后面的值必须是同一种东西**。我们这里两边都是整数，对得上；换成别的形状编译器就要跟你急了。

## 漏了 `break`，会一路滑下去

这是 `switch` 最经典的一跤，我们真跑给你看。下面这段把 `case 1:` 末尾上的 `break;` 拿掉了：

```cpp
#include <iostream>
using namespace std;

int main() {
    int choice = 1;

    switch (choice) {
        case 1:
            cout << "我们要一条三文鱼" << endl;
        case 2:
            cout << "我们要一条秋刀鱼" << endl;
            break;
        case 3:
            cout << "我们要一条鳕鱼" << endl;
            break;
        default:
            cout << "这个编号我们不认识" << endl;
            break;
    }
    return 0;
}
```

```text
我们要一条三文鱼
我们要一条秋刀鱼
```

我们只报了编号 1，屏幕上却冒出**两条**鱼。因为 `case` 干的事是「跳到这个标签这儿，然后**一路往下走**」，而 `break` 才是那个让路停下的东西。少了它，电脑跳进 `case 1` 之后不会自己回头看编号，而是顺顺当当滑进了 `case 2`，一直滑到遇见 `break` 才停。

编译器**一个字都不会警告你**：这段程序语法上一点问题都没有，它只是在安安静静地干错事。

::: warn 注意
`switch` 里每一段标签的末尾上，**`break;` 是必须自己记得写的**（`default` 那段通常也写上）。写完一串 `case`，回头把每一段的末尾扫一遍，是写 `switch` 的固定动作。
:::


**记住这一条**：`switch` 只**对一次号**（「对号对中的标签」那一栏从头到尾没变过），对完就跳到那张标签往下**挨行跑**；想让路停下来，靠的只有末尾上那个 `break;` 。

## 少了那两行开机咒，C++ 会怎样

上一课的运算符能跑，是因为我们每次都把那两行开机咒抄齐了。今天我们**故意只删掉 `using namespace std;` 这一行**，看看编译器怎么说：

```cpp
#include <iostream>

int main() {
    int fish = 3;
    if (fish > 0) {
        cout << "元素里还有数据" << endl;
    }
    return 0;
}
```

```text
main.cpp:6:9: error: 'cout' was not declared in this scope; did you mean 'std::cout'?
```

这句话的意思是：**「`cout` 这个名字我们不认识；你是不是想说 `std::cout`？」**

`cout` 真正的全名其实叫 `std::cout`（前面的 `std::` 是在说「它住在标准工具箱里」）。`using namespace std;` 那一行干的事，就是**把标准工具箱的门打开**，于是你只写 `cout` 它就认得。门没开，它自然要问你要全名。

所以这段代码有两种修法：把 `using namespace std;` 那行加回去，或者把两个 `cout` 都写成 `std::cout`。两条路都对，我们这里选前一条 —— 短一点，看着舒服。

::: warn 注意
写 C++ 的程序，第一眼先看顶上那两行在不在：

1. **`#include` 那一行** —— 少了它，`cout` 这个名字压根没被请进来。
2. **`using namespace std;` 那一行** —— 少了它，报错会写「`'cout' was not declared in this scope; did you mean 'std::cout'?`」。

看到这句报错，**不用去怀疑 `cout` 写错了**，回头补那一行就好啦。
:::

## 嵌套判断：眼色里再看一眼

眼色也能一层套一层。比如我们想问两件事：元素里有没有数据？今天有没有带客人来？

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 2;
    int guest = 1;

    if (fish > 0) {
        if (guest > 0) {
            cout << "有数据，还带了计算机一起来处理" << endl;
        } else {
            cout << "有数据，本对象处理" << endl;
        }
    } else {
        cout << "元素空了，去工作区边找计算机" << endl;
    }
    return 0;
}
```

```text
有数据，还带了计算机一起来处理
```

读法是**从外往里**：

- 外层先看 `fish > 0`，答真，才轮到它大括号里的东西上场。
- 里面那个 `if (guest > 0)` 再问第二句。它俩是**各自独立**的两对括号，别把它们看成一对。
- 外层要是答假，里面那一整套连问都不会被问到，直接跳到外层 `else` 那条路上。

写嵌套的时候，我们的习惯是**每往里一层就多让 4 格**。C++ 不看缩进，可你的眼睛看 —— 缩得齐，才一眼看得出「哪句话归哪一对大括号管」。

## 小抄：三样家当各管什么

| 家当 | 长相 | 什么时候用它 |
|---|---|---|
| `if` / `else if` / `else` | `if (眼色) { 话 }` | 问「大不大、小不小、一样不一样」，一串往下排 |
| 三目运算符 | `眼色 ? 这个 : 那个` | 二选一，每条路**只吐一个值**出来 |
| `switch` | `switch (数) { case 值: ... }` | 拿一个数**对号入座**，只能问「等不等于」 |

::: tip 提示
今天四件事，各记一句：

1. **`if (眼色) { 话 }`** —— 小括号管眼色、大括号管话，两对括号都不能省。
2. **`else if` 是串起来问的** —— 谁先答真走谁；最严的条件排最上面，不然会被前面宽松的条件抢走。
3. **`=` 是装东西，`==` 才是问话** —— C++ 不会为这个错误拦你，只会给你一个不对的结果。
4. **`switch` 是对号入座** —— 只能对「等不等于某个值」；每段 `case` 的末尾别忘了 `break;`。
:::

::: warn 注意
最坑的三处，写代码时在心里过一遍：

1. **眼色里写成一个等号**：C++ 不报错，`if (fish = 3)` 恒为真，你只能从结果里发现不对。
2. **`case` 后面漏了 `break;`**：会一路滑到下一段，屏幕上多印一条。
3. **顶上那两行开机咒漏了**：`using namespace std;` 一丢，报错就会提到 `std::cout`，别被它绕晕。
:::
