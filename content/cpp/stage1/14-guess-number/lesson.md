## 学习目标

本课学习综合项目：猜数字游戏。重点包括随机数、循环、条件、函数拆分。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、让机器自己想一个数

C++ 里有个函数叫 `rand()`，念作「random」——**它每次调用都会吐一个不太小的整数出来**。要它吐得动，开头得写一句 `#include`，把 `cstdlib` 借出来。

直接称呼它有个小毛病：**每次开演都吐同样一串数。** 我们跑给你看：

```cpp
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    srand(1);
    for (int i = 0; i < 5; i++) {
        cout << rand() % 100 + 1 << endl;
    }
    return 0;
}
```

```text
42
68
35
1
70
```

先看 `srand(1);` 这一句：`srand` 是「**下种子**」—— 念作 s-rand，意思是「我们给这台机器一颗种子，它照着这颗种子吐数」。**同一颗种子，吐出来的那一串永远一模一样**；这就是为什么上面那五行你每次跑都是这五个数。

（这五行是我们在这台机器上跑出来的。**换成别的机器、别的库，同一颗种子吐出来的可能不是这五个数** —— 但「同一颗种子、同一串数」这条规矩到处都一样。）

再看 `rand() % 100 + 1` 这一截：

- **`rand() % 100`** —— `%` 是第 05 课学的「取余」，一个数除以 100 剩下的那点。不管 `rand()` 吐出来多大多小，`% 100` 的结果一定落在 `0` 到 `99` 之间。
- **`+ 1`** —— 把范围挪一格，变成 `1` 到 `100`。

合起来就是「**从 1 到 100 里随便挑一个**」——正是我们心里那个数。

::: tip 提示
`srand` 那句你可能会问：为什么非得钉一颗种子？

因为**种子一样、数就一样**，我们才能把跑出来的结果原样贴给你看，你也才能对着屏幕一行一行核对。这叫**钉住运气**。

真玩的时候当然不能钉 —— 第五节我们教你怎么让种子每次都换一个。
:::

## 二、猜的次数说不准，那就别数圈数

第二个问题：**你猜几次，谁也不知道。**

`for` 圈是我们最熟的那个圈，可它的开头就写着「跑几圈」。要是写成「跑 3 圈」，运气不好就得中途停；写成「跑 20 圈」，猜中了它还在傻问。

所以这回用另一种圈 —— **第七课那种不讲圈数的圈**：

```cpp
#include <iostream>
using namespace std;

int main() {
    int target = 42;
    int picks[4] = {10, 50, 25, 42};
    int i = 0;

    while (true) {
        int guess = picks[i];
        i = i + 1;
        cout << "我们报 " << guess << endl;
        if (guess == target) {
            cout << "猜中啦" << endl;
            break;
        }
    }
    return 0;
}
```

```text
我们报 10
我们报 50
我们报 25
我们报 42
猜中啦
```

三个关键点：

- **`while (true)`** —— 第七课我们提过它，还说过「我们故意不给能跑的示例，因为它一跑起来就停不下来」。**今天它配上 `break`，能停了**，可以放心跑。念作「**一直转下去，直到有人调用停**」。
- **`break;`** —— 猜中了就调用停，从圈里跳出来。这就是「收工」两个字。
- **`int picks[4] = {10, 50, 25, 42};`** 和 `int guess = picks[i];` —— 这一排是**替身**。

### 为什么要替身？

因为你跟着我们在这儿跑的时候，**键盘是敲不进去的** —— 机器不会停下来等你输入。所以要教「反复猜」这件事，我们就**先把你要猜的那几个数写成一排**，让机器自己一格一格往下报：先报 10、再报 50、再报 25、最后报 42。

`i` 是「报到第几格了」，每报一格就 `i = i + 1;`。`picks[i]` 就是第 `i` 格上那个数 —— 一排元素加编号取货，第 08 课学的老手艺。

（真坐在键盘前面玩的那一版在第五节，那才是给你自己玩的。）

## 三、三条岔路：`check` 函数

现在把「我们回你哪句话」这件事单独拆成一个方法。为什么拆？因为**它是一件事，就该有个名字** —— 第九课那套「一个方法只干一件事」的老规矩，越到项目里越值钱。

```cpp
#include <iostream>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦";
    } else if (guess > target) {
        return "太大啦";
    } else {
        return "猜中啦";
    }
}

int main() {
    cout << check(10, 42) << endl;
    cout << check(50, 42) << endl;
    cout << check(42, 42) << endl;
    return 0;
}
```

```text
太小啦
太大啦
猜中啦
```

- 这一个方法的**料**是两个整数（`guess` 是猜的，`target` 是我们心里那个），**返回的是**一串数据（也就是一句话）—— 所以函数名前面写 `string`。
- 三条岔路正好对应三句话，一条不多一条不少。
- 注意这一个方法**自己不印任何东西**，它只负责**报信**：把该说的话返回，印不印、什么时候印，是称呼它那位的事。

::: tip 提示
「只报信、不印字」这一条，看着像小事，其实是**函数好不好用的分水岭**：

- 我们想把它印在屏幕上 → `cout << check(...)`；
- 我们想把这句话再加工一下（比如前面加个「第 3 次：」）→ 直接拼；
- 我们想测试它 → 不用盯着屏幕看，比一比返回的话对不对就行。

函数里一旦写死了 `cout`，上面三件事它就只能干第一件了。
:::

## 四、把三条岔路塞进圈里

零件齐了，装起来：

```cpp
#include <iostream>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦";
    } else if (guess > target) {
        return "太大啦";
    } else {
        return "猜中啦";
    }
}

int main() {
    int target = 42;
    int picks[4] = {10, 50, 25, 42};
    int i = 0;

    while (true) {
        int guess = picks[i];
        i = i + 1;

        cout << "我们报 " << guess << "：" << check(guess, target) << endl;

        if (guess == target) {
            break;
        }
    }
    return 0;
}
```

```text
我们报 10：太小啦
我们报 50：太大啦
我们报 25：太小啦
我们报 42：猜中啦
```

看那句最长的：`cout << "我们报 " << guess << "：" << check(guess, target) << endl;`

它是前面几课学过的东西**串起来**的：先印一段字，再把 `guess` 印上去，再接一句 `check` 返回的话。**没有任何新东西**，只是零件多了几个 —— 项目课的味道就是这个。

## 五、拆成一整局：`play` 函数

到这儿机器能跑了，可它还是「摊在地上」的：想再玩一局就得把那一大段全抄一遍。收工之前，我们把它折成函数：

```cpp
#include <iostream>
#include <cstdlib>
#include <string>
using namespace std;

string check(int guess, int target) {
    if (guess < target) {
        return "太小啦";
    } else if (guess > target) {
        return "太大啦";
    } else {
        return "猜中啦";
    }
}

int play(int target, int picks[], int n) {
    int i = 0;
    while (i < n) {
        int guess = picks[i];
        i = i + 1;

        cout << "我们报 " << guess << "：" << check(guess, target) << endl;

        if (guess == target) {
            return i;
        }
    }
    return 0;
}

int main() {
    srand(1);
    int target = rand() % 100 + 1;
    int picks[4] = {10, 50, 25, 42};

    int used = play(target, picks, 4);
    cout << "答案是 " << target << "，一共猜了 " << used << " 次" << endl;
    return 0;
}
```

```text
我们报 10：太小啦
我们报 50：太大啦
我们报 25：太小啦
我们报 42：猜中啦
答案是 42，一共猜了 4 次
```

这一折，折出来四样东西，一样一样看：

1. **`play` 收三样料**：我们心里那个数（`target`）、那一排替身（`picks[]`）、还有这一排有几格（`n`）。
   —— 注意**一排元素递进函数的时候，格数得自己另外报**：上一课我们讲过，一整排元素的名字交出去的是第一个元素的地址，函数并不知道这一排有多少格。这就是 `n` 为什么非得跟着一起来，也是圈里那句 `while (i < n)` 的依据：替身还有，就接着报。
2. **猜中了不写 `break;`，直接 `return i;`** —— 第九课学的「把结果返回」。这一个方法返回的是**猜了几次**，正是 `main` 想要的那个数字。
3. **万一替身报完了还没猜中**，圈一结束就落到最后那句 `return 0;` —— 返回一个 `0`，意思是「一次也没猜中」。**函数必须每条路都有结果返回**，这条兜底的路也别忘了。
4. **`int used = play(target, picks, 4);`** —— 调用一局，把「猜了几次」装进 `used`。
5. **`srand(1);` 挪到了 `main` 一开头**，`target` 是**当场抽**的：以后想换个数，改种子就行，函数一行都不用动。

（顺带一句：`play` 的圈里没有 `break` —— 因为 `return` 一出，整个函数当场收工，比「跳出圈」还干脆。下一节的「小任务」里我们会问你：要是把它换回 `break`，会发生什么？）

## 六、真机版：自己敲数字来玩

上面那台机器是**我们替你猜**。你想要的那一版，是**你自己在键盘上敲**。这就是输入接口 `cin` 上场的地方 —— 它长得跟第 04 课一模一样：

```text
#include <iostream>
#include <cstdlib>
using namespace std;

int main() {
    srand(1);
    int target = rand() % 100 + 1;
    int guess = 0;
    int used = 0;

    cout << "我们想了一个 1 到 100 的数，来猜猜看" << endl;
    while (true) {
        cout << "猜一个数：";
        if (!(cin >> guess)) {
            cout << endl << "输入接口空了，我们先收工" << endl;
            break;
        }
        used = used + 1;
        if (guess < target) {
            cout << "太小啦" << endl;
        } else if (guess > target) {
            cout << "太大啦" << endl;
        } else {
            cout << "猜中啦！一共猜了 " << used << " 次" << endl;
            break;
        }
    }
    return 0;
}
```

这一段**要敲键盘**，所以我们没法在这儿现场跑给你看。我们把种子钉成 `1`、自己按顺序敲了 `10`、`50`、`25`、`42`，那一次的屏幕是这样的：

```text
我们想了一个 1 到 100 的数，来猜猜看
猜一个数：太小啦
猜一个数：太大啦
猜一个数：太小啦
猜一个数：猜中啦！一共猜了 4 次
```

四句话，把这一版和前面那版对一对：

- **`cin >> guess`** 就是第 04 课的输入接口：我们问「猜一个数：」，你就敲一个数进去，它把那个数装进 `guess` 里。
- **`if (!(cin >> guess))`** 是第 04 课那根**保险绳**：万一输入接口空了（没人往里喂东西了），别让程序傻等或者乱转，直接收工。
- **猜完一次，`used = used + 1;`** —— 自己数着猜了几次。
- **`srand(1)` 要换掉。** 真玩的时候把它换成 `srand(time(0));`（还得在开头加一句 `#include`，把 `ctime` 借出来）—— `time(0)` 是「**现在几点**」，每次开演的时间都不一样，于是种子每次都不一样，我们心里那个数自然也就每局都换。**要是你还留着 `srand(1);`，那每局都是同一个 42，玩两遍就没意思了。**

::: warn 注意
这一节的两个坑，都是我们踩过的：

1. **`srand` 一句只能下种一次**，而且要在最开头。把它塞进圈里，每猜一次就重新下一颗种子 —— 种子一样、第一个数就一样，你会碰上一台「怎么猜都猜不中」的机器。
2. **`cin >> guess` 那句不能顺手删掉那根保险绳。** 真在键盘前面玩的时候，玩到一半想按 Ctrl+C 或者输入没了，圈就靠它落地收工；没了它，机器会拿着上一次猜的那个数空转，屏幕上刷得停不下来。
:::

## 小抄表

| 写法 | 念作 | 干什么 |
|---|---|---|
| 开头 `#include` 一句 `cstdlib` | 把 `rand`、`srand` 借出来 | 抽数要先写这一句 |
| `srand(1);` | 下种子 | 钉住运气，同一个种子吐同一串数 |
| `rand()` | 吐一个整数 | 每次调用都吐一个不太小的整数 |
| `rand() % 100 + 1` | 从 1 到 100 随便挑一个 | `%` 把结果压进 0 到 99，`+ 1` 挪到 1 到 100 |
| `while (true) { ... }` | 一直转，直到有人调用停 | 不知道要转几圈的时候用它 |
| `break;` | 调用停 | 从圈里跳出来 |
| `return i;` | 把结果返回、当场收工 | 在函数里，它比 `break` 还干脆 |
| `if (!(cin >> guess))` | 保险绳 | 输入接口空了就收工（第 04 课那根） |
| `srand(time(0));` | 每次换一颗种子 | 真玩的时候用（还要 `#include` 把 `ctime` 借出来） |

::: tip 提示
装一台机器，我们走的是这四步 —— 以后你自己开工也照这个节奏：

1. **把大活儿拆成小零件**（算范围、判大小、数次数），一件一件单独跑通；
2. **每个零件都拆成一个方法**（`check` 就是「报信」那一个方法），一个方法只干一件事；
3. **零件串起来装上**（第四节那句最长的 `cout`），先跑通再收拾；
4. **折成函数**（`play`），让主流程只剩下「下种子 → 抽数 → 调用一局 → 印结果」四行。
:::
