## 第一件事：给同一个元素再挂一个名字

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int& other = fish;

    other = 10;
    cout << fish << endl;
    cout << other << endl;
    return 0;
}
```

```text
10
10
```

盯住新冒出来的那一行：

```text
int&  other = fish;
```

- **装数的名字后面紧贴着一个小小的 `&`** —— 这就是「温柔版」的记号。它说的是：`other` **不是一个新元素**，它是**给 `fish` 那个元素再挂上的第二个名字**。
- 我们改的是 `other`，可印出来 `fish` 也变成 10 了 —— **因为它俩根本就是同一个元素，只是挂着两个名字。**
- 这种「同一个元素的第二个名字」，有个说法叫**别名**。

::: tip 提示
`other` 不是一个「指向 `fish` 的名称」，**它就是 `fish`**。所以：

- 印 `other` 和印 `fish`，出来的东西一模一样；
- 改 `other` 就是改 `fish`，`other = other + 1;` 也是给 `fish` 加 1；
- 一根魔杖，两个名字，一个元素。就这么简单。
:::

## 让函数直接摸到那个元素

回到开头那个「加了 1 却纹丝不动」的实验。我们现在**只改一个地方** —— 在那份料上多写一个 `&`：

```cpp
#include <iostream>
using namespace std;

void addOne(int& n) {
    n = n + 1;
}

int main() {
    int fish = 3;
    addOne(fish);
    cout << fish << endl;
    return 0;
}
```

```text
4
```

**只多了一个 `&`，结果从 3 变成了 4。**

把两版摆在一起，区别一眼就看出来：

| 函数那一头怎么写 | 函数里的 `n` 是什么 | 函数改得动外面吗 |
|---|---|---|
| `void addOne(int n)` | 一张**复印件** | 改不动，白改 |
| `void addOne(int& n)` | 外面那个元素的**另一个名字** | 改得动，一改就到位 |

最舒服的一点是：**引用的时候一个字都不用改。** 两版在 `main` 里都是同一句 `addOne(fish);` —— 变的只是**函数那头怎么接这份料**。写了 `&`，意思就是「别复印了，我们要直接摸原件」。

这也顺手解释了开头那个实验：**一整排元素整份递过去的时候，编译器天生就不复印**，函数摸到的就是外面那一排，所以你什么都不用写。可**单独一个元素默认是复印的** —— 想让它也摸到原件，就得自己写上那个 `&`。

至于「为什么一整排就天生不复印」，那是下一课的主角，今天先按下不表。

### 再来一个：对调两个元素

对调两个元素里的东西，是「必须摸到原件」最经典的一例：我们得借一个临时元素，把两边的货你来我往地倒一遍。

```cpp
#include <iostream>
using namespace std;

void swapTwo(int& a, int& b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3;
    int y = 8;
    swapTwo(x, y);
    cout << x << endl;
    cout << y << endl;
    return 0;
}
```

```text
8
3
```

两样料都写上 `&`，函数里那一套「借临时元素、你来我往」才**真的对调到外面那两个元素上**。

那要是两个 `&` 都漏了呢？

```cpp
#include <iostream>
using namespace std;

void swapTwo(int a, int b) {
    int temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 3;
    int y = 8;
    swapTwo(x, y);
    cout << x << endl;
    cout << y << endl;
    return 0;
}
```

```text
3
8
```

函数里**确实对调了**，可以对调的是两张复印件 —— 外面那两个元素一根毛都没动，印出来还是 3 和 8。

::: warn 注意
**这种「改了却什么都没发生」的错，编译器不会报错。**

程序能跑、语法全对、屏幕上还老老实实印出两个数，只是那两个数是**没改过的**。它不像别的错误那样跳出来咬你一口 —— 它静静地待着，等你自己发现。

所以每写完一个方法「本该改动外面」的函数，我们都干一件事：**在 `main` 里把它改过的那个元素印出来看看到底变了没。** 这一眼，比什么都值。
:::

## 和「硬邦邦的那一版」有什么不一样

C++ 里还有一种家伙，学名叫**硬邦邦的那一版（指针）**。它跟我们今天教的温柔版有点像 —— 两样都跟「别处的某只元素」有关 —— 可脾气差得远。

今天你只要先记住三条：

| | 温柔版（`&` 那一版） | 硬邦邦的那一版 |
|---|---|---|
| 开张的时候 | **必须当场绑好**，不能先空着 | 可以先空着，以后再挂 |
| 绑好之后 | **一辈子不换**，绑谁就是谁 | 想换就换，今天指这个、明天指那个 |
| 用的时候 | 跟普通名字一样，直接写 | 每次用都得多写一个小记号 |

第二条最容易摔，我们给你看个实验：

```cpp
#include <iostream>
using namespace std;

int main() {
    int a = 1;
    int b = 2;
    int& r = a;

    r = b;
    cout << a << endl;
    cout << b << endl;
    return 0;
}
```

```text
2
2
```

`r = b;` 这一句，看着特别像「把 `r` 改绑到 `b` 上去」—— **不是。**

温柔版**一旦绑好就一辈子不换**，所以这一句真正干的事是：**把 `b` 的值抄进 `r` 那个元素**。而 `r` 就是 `a`，于是 `a` 也成了 2。

我们再给你看一个反面例子：要是有人想说「先摆一根空的，以后再绑」，编译器当场翻脸。

```cpp
#include <iostream>
using namespace std;

int main() {
    int& r;
    int fish = 3;
    r = fish;
    cout << r << endl;
    return 0;
}
```

```text
main.cpp:5:10: error: 'r' declared as reference but not initialized
```

`declared as reference but not initialized` 的意思是：**「你说这是个温柔版，可你没说它绑的是哪只元素。」**

看到 `not initialized` 那几个字，就回头看那一行：**`=` 后面有没有当场跟上它要绑的那个元素？** 写成 `int& r = fish;` 那样，才有一根能用的。

（至于第三行那条「用的时候要多写个小记号」，下一课那位正式登场时你会看得清清楚楚。）

## 什么时候该用它

| 我们想干的事 | 料那头怎么写 |
|---|---|
| 函数只是**看看**那份料，不动它 | 什么都不加（`int n`） |
| 函数要**改外面那个元素** | 料上写 `&`（`int& n`） |
| 函数要用一大份东西，又不想每调用一次就复印一大份 | 料上写 `&`（只看不改也一样能省） |
| 递过去的是一整排元素 | **天生就不复印**，什么都不用加 |

最后一行是今天最省事的一条：**一整排元素本来就摸得到原件，不用你操心。**

::: tip 提示
本课五次总结，一句话一个：

1. **递一个元素进函数，默认是复印一份** —— 函数里改了也传不出来，而且不报错。
2. **料上写 `&`（`int& n`）就变成「直接摸原件」** —— 引用的那一头一个字都不用改。
3. **`int& other = fish;`** —— 给同一个元素再挂一个名字，改哪个都是改那个元素。
4. **开张时必须当场绑好，绑好就一辈子不换** —— `r = b;` 不是改绑，是把 `b` 的值抄进 `r`。
5. **一整排元素天生就不复印** —— 这是它和单独一个元素最不一样的地方。
:::
