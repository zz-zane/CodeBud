## 定义：给一段活儿起个名字

我们的第一个方法，就干一件事：打个招呼。

```cpp
#include <iostream>
using namespace std;

void meow() {
    cout << "我们来啦" << endl;
}

int main() {
    meow();
    meow();
    return 0;
}
```

```text
我们来啦
我们来啦
```

先看清楚**它写在哪儿**：这一个方法在大括号外面、在 `main` 的**上面**，和 `main` 平起平坐。**它不是写在 `main` 里面的东西** —— 它是我们自己新添的一个方法，跟 `main` 站在同一层。

它的形状固定成四块：

```text
返回什么   名字( 塞进来的料 ) {
    一堆活儿
}
```

一块一块认：

- **最前头那一个词（这里是 `void`）** —— 说的是「这一个方法干完活儿，会不会带东西回来」。`void` 的意思是**空手**：干完就干完，什么都不带出来。这个词你先照着抄，等讲到「返回东西回来」那一节，你会一眼看懂它为什么长这样。
- **`meow`** —— 我们给这一个方法起的名字，随你起，能一眼看出它干什么就行。
- **`()`** —— 那对小括号里现在**空着**，意思是「调用这一个方法不用往里塞东西」。
- **`{ ... }`** —— 一对大括号包住的，就是**这一个方法要干的整段活儿**。这一对括号和 `if`、跑圈的那些是同一副，写法也一样。

### 调用一次，它就整段跑一遍

`main` 里那两句 `meow();`，就是**调用这一个方法**：

- 写法是**名字 + 一对括号 + 一个分号** —— 括号和分号一个都不能少；
- 调用一次，大括号里那整段活儿就跑一遍；调用两次就跑两遍。**我们的变量不用再抄第二遍。**

这就是它最大的好处：**一段活儿只写一遍，想跑几遍就调用几遍。**

哪天我们想把招呼改成「我们又来了」，只改函数里那**一个**地方，`main` 里那两句一个字都不用动。

### 函数要写在称呼它的上面

这一条是新手最容易摔的地方，我们单独拎出来。

C++ 是**从上往下一行行读**的。读到 `main` 里那句 `meow();` 的时候，编译器会问一句：「`meow` 是什么？我们没见过这个名字。」

要是你把函数写到了 `main` 的**下面**，它读到那一句时确实还没见过：

```cpp
#include <iostream>
using namespace std;

int main() {
    meow();
    return 0;
}

void meow() {
    cout << "我们来啦" << endl;
}
```

```text
main.cpp:5:5: error: 'meow' was not declared in this scope
```

编译器这句话的意思是：**「`meow` 这个名字，我们站在这儿没见到过。」**

看到 `was not declared in this scope`，第一件事就是**往上看**：称呼它的那一句上面，有没有把这一个方法好好写出来？没有的话挪上去，立刻就好。

## 塞料：让同一个方法每次有点不一样

只会调用「我们来啦」的函数有点笨 —— 每次输出的话一模一样。我们想让它每次能说点不同的，就该**往括号里塞料**了。

括号里那几样东西，我们管它叫**塞进去的料（参数）**：

```cpp
#include <iostream>
#include <string>
using namespace std;

void feed(string name, int count) {
    cout << name << " 领到 " << count << " 条数据" << endl;
}

int main() {
    feed("计算机", 3);
    feed("小黄鱼", 5);
    return 0;
}
```

```text
计算机 领到 3 条数据
小黄鱼 领到 5 条数据
```

看这一个方法的开头：

- **`(` 里那两样** —— `string name` 和 `int count`，中间**用逗号隔开**。一样料写一份：**先写它是什么样，再写它在这一个方法里叫什么名字**。
- **函数里那两句话，用的是这两个名字。** `name` 和 `count` 只在这一个方法的大括号里活着 —— 出了这对括号，谁都不认识它们。
- **引用的时候，括号里按顺序一份份塞进去。** `feed("计算机", 3)` 就是「把 `"计算机"` 交给 `name`，把 `3` 交给 `count`」。

**顺序是对着来的**：第一份料给第一个名字，第二份料给第二个名字。你要是写成 `feed(3, "计算机")`，那就是把 `3` 交给 `name` —— 编译器当场翻脸（`3` 没法交给装字的柜子）。

### 少塞了一份料会怎样

```cpp
#include <iostream>
using namespace std;

void feed(string name, int count) {
    cout << name << " 领到 " << count << " 条数据" << endl;
}

int main() {
    feed("计算机");
    return 0;
}
```

```text
main.cpp:9:9: error: too few arguments to function 'void feed(std::string, int)'
```

`too few arguments` 就是**「塞进来的料太少了」**。这一个方法说好要两样，我们只给了一样，编译器不给开工。

它报错那行还把这一个方法的完整长相抄给你看了 —— **括号里两样，一样都不能少**。看到 `too few arguments`，就去数括号里的逗号：这一个方法定义时要几样、引用的时候给了几样，对得上吗？

## 返回东西回来：`return`

上面两招都是「空手」的：干完活，什么也不带回来。可我们常常想让一个方法**干完顺手带个结果出来** —— 比如「把两个数加起来」。

还记得第一段那个形状吗？最前头那个词管的就是这件事。把它从 `void` 换成一个装数的名字，函数就有东西可返回了：

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    int total = add(3, 5);
    cout << total << endl;
    cout << add(10, 20) << endl;
    return 0;
}
```

```text
8
30
```

- **最前头的 `int`** —— 这一个方法干完会**返回一个数回来**。这就跟我们满月时那句 `int fish = 3;` 是同一个 `int`：它说的都是「这里保存的是一个数」。
- **`return a + b;`** —— 这一个方法的收尾。**`return` 干两件事：把后面的东西交出去，然后这一个方法立刻收工。** 大括号里排在它后面的活儿，一句都不会再跑。
- **返回的东西可以当场用掉**：`int total = add(3, 5);` 是先把返回的 8 装进小元素再印；`cout << add(10, 20);` 是直接拿去印，连元素都省了。

::: tip 提示
**空手还是返回东西，只看最前头那一个词：**

- 写成 **`void`** —— 空手，干完活什么都不带回来。这种函数**不能**塞进 `cout` 里印，也不能装进元素里 —— 它没有东西可给。
- 写成 **`int`**（或者别的装数的名字）—— 干完会返回一个数回来，可以直接拿去印、拿去算、装进元素里。

还有一个新手最常犯的：**函数里说好要返回东西回来，可 `return` 从头到尾没写。** 编译器**不拦你** —— 它只在旁边留一句警告（`no return statement ...`），编译照样过，看着像没事。可这样写出来的程序**一跑起来多半当场就崩掉**，结果根本拿不到。

**警告不是「没事」**，它就是来提醒你这一句的。写函数时先问自己：这一个方法答不答话？答话就得有 `return`。
:::

### 返回的东西还能传给下一个方法

既然返回的就是一个数，那它当然能直接塞给另一个方法当料：

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) {
    return a + b;
}

int main() {
    cout << add(3, 5) << endl;
    cout << add(add(1, 2), 4) << endl;
    return 0;
}
```

```text
8
7
```

第二句读起来是**从里往外**的：先算里面那层 `add(1, 2)`，返回 3；再把 3 当成第一份料，调用一次 `add(3, 4)`，返回 7。

这个形状看着眼熟吧？—— 上一课那排元素、你学过的加减乘除，都是这么一层套一层拼起来的。**函数返回的东西，就是一个能接着用的结果**，可以往外套无数层。

## 同名多招：编译器怎么知道引用的是哪一个方法

最后一件事，C++ 独有的一手。

我们想给同一件事起同一个名字，只是料不一样：**塞给它一个数，就翻倍；塞给它一串字，就把这串字接两遍。**

```cpp
#include <iostream>
#include <string>
using namespace std;

int more(int n) {
    return n * 2;
}

string more(string s) {
    return s + s;
}

int main() {
    cout << more(21) << endl;
    cout << more("字") << endl;
    return 0;
}
```

```text
42
字字
```

**两招的名字一模一样，都叫 `more`。** 编译器不糊涂 —— 它挑哪一个方法，看的是**你塞进去的是什么**：

- 塞进去的是 `21`（一个数），就走第一个方法，返回 42；
- 塞进去的是 `"字"`（一串字），就走第二招，返回「字字」。

学名管这叫**同名多招**，我们更爱说「一名的多招」。要同时站着，规矩只有一条：

> **同样多的料 + 每样料什么样不一样，才能重名。**

比如说，`int more(int n)` 和 `string more(string s)` 都是一份料，可一份是数、一份是字，编译器分得清；要是你再写一个 `int more(int n2)` —— 也是「一份数」，那就和第一个方法**撞得一模一样**了，它会说分不清。这种错误很少见，今天认个脸就好。

## 小抄表

| 我们想问的 | 记这个 |
|---|---|
| 一段活儿要反复用 | 给它起个名字、拿大括号包起来，写在 `main` 上面 |
| 这一个方法要怎么调用 | `名字(料);` —— 括号和分号一个都不能少 |
| 引用的时候要带东西进去 | 括号里按**顺序**一份份塞 |
| 干完要带个结果出来 | 最前头写 `int`，末尾 `return 结果;` |
| 干完什么都不带 | 最前头写 `void` |
| 名字一样的两招 | 编译器看你**塞进去的是什么** |

::: warn 注意
本课最容易摔的三处：

1. **函数写到了称呼它的地方下面。** 报 `was not declared in this scope` —— 把这一个方法挪到 `main` 上面。
2. **塞的料少了一份。** 报 `too few arguments` —— 数一数括号里的逗号，两边的份数对得上吗。
3. **说好要返回东西回来，却忘了写 `return`。** 编译能过，编译器只在旁边留一句警告 —— 看着像没事，可一跑起来多半**当场崩掉**。这种最阴，它不拦你，得靠你自己检查。
:::
