## 学习目标

本课学习异常处理初步。重点包括异常概念、throw、try/catch、常见异常。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

```text

```

## 一、先自己扔一个异常出来

要学接车，最快的办法是先自己扔一辆。看这一段：

```cpp
#include <iostream>
using namespace std;

int main() {
    try {
        throw 42;
    } catch (int e) {
        cout << "接住了 " << e << endl;
    }
    cout << "程序还在跑" << endl;
    return 0;
}
```

```text
接住了 42
程序还在跑
```

一句一句看：

- **`try { ... }`** —— 一对大括号圈出「要盯着跑的那一段」。这是铺在地上的一块**异常处理分支**。
- **`throw 42;`** —— **扔出去**。意思是「我们不干了，这活儿交给上级」。我们往上一扔的是个数字 `42`。
- **`catch (int e) { ... }`** —— **在异常处理分支上接住**。括号里写的是「接什么样的车」：这里写 `int`，意思是「扔出来的是整数，我们就接」；接住的那件东西装进 `e` 里，接下来就能用了。
- 最要紧的是**最后那句 `程序还在跑` 也印出来了**。`throw` 把 `try` 里剩下的话全都打断了（所以剩下那句是 `catch` 接的手），可**整个程序没停**，`try` 后面的话照跑不误。

`try`、`catch`、`throw` 三个名字都是英文小写，念起来就是它们的字面意思：**试**、**接住**、**扔**。

## 二、真·从一堆字里挖数字

现在来真的。这个函数叫 `stoi`，念作「s-to-i」，是 string to int 的缩写 —— **把一串数据读成一个整数**：`stoi("42")` 就是数字 `42`。（别的语言里干这活的函数写法不一样，那是下一阶段的事。）

可要是那串东西根本不是数字呢？

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    try {
        int n = stoi("字");
        cout << n << endl;
    } catch (const invalid_argument& e) {
        cout << "这不是数字：" << e.what() << endl;
    }
    return 0;
}
```

```text
这不是数字：stoi
```

- **`stoi("字")`** —— 那串东西不是数字，所以 `stoi` 自己就**扔一个异常**出来。它扔的车上挂着 `invalid_argument` 这块名称，意思是「**你给的料不对**」。
- **`catch (const invalid_argument& e)`** —— 括号里写的正是「我们接那种挂着 `invalid_argument` 名称的车」。`const` 和 `&` 是它的标准写法，今天就照着抄（那个 `&` 就是上一课那块名称，意思是「别复印，我们要接住原车」）。
- **`e.what()`** —— 车上贴着的一句说明。这里印出来是 `stoi`（意思：「问题出在 `stoi` 这一句上」）。

注意 `cout << n << endl;` 那一句**没印出东西** —— 车一扔出来，`try` 里剩下的话就全部作废，直接跳到接车的 `catch` 里。

## 三、越界：从没有的那颗拿数据

第二种翻车，翻的是「越界」：

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    string word = "miai";
    cout << word.at(1) << endl;

    try {
        cout << word.at(10) << endl;
    } catch (const out_of_range& e) {
        cout << "越界：" << e.what() << endl;
    }
    return 0;
}
```

```text
i
越界：basic_string::at: __n (which is 10) >= this->size() (which is 4)
```

- **`word.at(1)`** —— 第 1 号位置上的那颗数据。这一串从 **0** 数起，所以 1 号是第二个字母 `i`。这一句好好的，印出来了。
- **`word.at(10)`** —— 这一串只有 4 颗，第 10 颗**根本不存在**，于是 `at` 扔出一辆挂着 `out_of_range` 名称的车（意思是「**超出范围**」）。
- 车上那句说明里数字都告诉你了：`(which is 10) >= this->size() (which is 4)` —— 你要的是第 10 颗，而这一串只有 4 颗。

（顺带说一句：`at` 是**带异常处理分支版的取法**；第一课那种用方括号 `word[10]` 的取法越界时**不抛出异常** —— 我们真跑过，`string word = "miai"; word[10];` 编译期 **0 字节**、一次不吭就编过了。可「不抛出异常」**不等于「安静」**：跑起来它当场断气，退出码 **127**，屏幕上甩出一句 `Assertion '__pos <= size()' failed.`（441 字节），一个结果都没印出来。不抛出异常的坏处正是**接不住** —— `try` / `catch` 在这儿一点用没有，程序直接就没。）

## 四、自己甩一个异常

`stoi` 和 `at` 扔的车是它们扔的，我们自己也能造一辆。办法就是 `throw` 一个**带说明的车**：

```cpp
#include <iostream>
#include <stdexcept>
using namespace std;

int countFish(int n) {
    if (n < 0) {
        throw runtime_error("数据数不能是负数");
    }
    return n * 2;
}

int main() {
    try {
        cout << countFish(3) << endl;
        cout << countFish(-1) << endl;
        cout << "这一句不会印出来" << endl;
    } catch (const runtime_error& e) {
        cout << "接住了：" << e.what() << endl;
    }
    return 0;
}
```

```text
6
接住了：数据数不能是负数
```

- **`throw runtime_error("数据数不能是负数");`** —— 自己造一个异常，车上贴一句话。`runtime_error` 是「**跑起来以后出的错**」这种名称（用它得先在开头写一句 `#include`，把 `stdexcept` 借出来 —— 我们已经写在上面了）。
- 第一次调用 `countFish(3)` 好好的，印出 `6`；第二次给了个 `-1`，函数里就 `throw` 了 —— 你数数看，`这一句不会印出来` 果然**没印出来**，直接被 `catch` 接住，印出车上那句话。

这里有个很值得记住的点：**函数里一个 `try` 都没有。** 抛出异常的在函数里，接车的在称呼它的那一层 —— **抛出异常的和接车的不用是同一层**。函数只管「这事不对，我们扔上去」，谁接它，是称呼它那位的事。

## 五、兜底的那一辆：`catch (...)`

要是我们压根不知道会翻出什么样的车呢？那就铺一张**什么都接**的异常处理分支：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    try {
        throw string("数组元素打翻了");
    } catch (const string& e) {
        cout << "接到一串字：" << e << endl;
    } catch (...) {
        cout << "不管是什么，先接住再说" << endl;
    }

    try {
        throw 7;
    } catch (const string& e) {
        cout << "这一句接不到" << endl;
    } catch (...) {
        cout << "不管是什么，先接住再说" << endl;
    }
    return 0;
}
```

```text
接到一串字：数组元素打翻了
不管是什么，先接住再说
```

- 第一段扔的是一串字，第一个 `catch` 要的正是「一串字」，接住了 → 印 `接到一串字：数组元素打翻了`。
- 第二段扔的是数字 `7`，第一个 `catch` 只要一串字，**接不住**，就往下落到兜底那个 `catch (...)` → 印 `不管是什么，先接住再说`。
- **`catch (...)` 里那三个点念作「什么都行」**，它是最后一道异常处理分支，什么车都接。规矩是：**兜底那一个必须排在最后** —— 前面的先挑，挑剩下的才轮到它，写在前面就把后面的全抢光了。

（第二段里那个 `这一句接不到` 没印出来 —— 说明 `catch` 是**从上往下挑第一个对得上的**，一个车只被一个 `catch` 接走。）

## 六、没翻车的时候，异常处理分支就当没铺

```cpp
#include <iostream>
#include <string>
#include <stdexcept>
using namespace std;

int main() {
    try {
        int n = stoi("7");
        cout << n + 1 << endl;
    } catch (const invalid_argument& e) {
        cout << "这一句不会印出来" << endl;
    }
    return 0;
}
```

```text
8
```

`stoi("7")` 好好的，一点没翻车，`catch` 里那句一个字都没印 —— **异常处理分支只是备着，不用最好**。这正是可以放心给整段活铺异常处理分支的原因：顺利的时候，它不花你一分钱。

## 常见翻车表

| 车上挂的名称 | 什么时候来 | 你会在哪儿撞上它 |
|---|---|---|
| `std::invalid_argument` | 给的料根本不对 | `stoi("字")` —— 那串东西不是数字 |
| `std::out_of_range` | 越界了 | `一串字.at(10)` —— 那串只有 4 颗 |
| `std::runtime_error` | 跑起来以后出的错 | 我们自己 `throw` 出来的（车上贴一句话） |
| 那三个点 `...` | 什么都接 | 兜底异常处理分支，**排在最后** |

::: tip 提示
五件小抄，一句话一件：

1. **`try { ... }`** —— 铺异常处理分支：这一段要盯着跑。
2. **`throw 某某;`** —— 抛出异常：我们不干了，扔给上级。
3. **`catch (什么样 e) { ... }`** —— 接车：括号里写接什么样的车。
4. **`e.what()`** —— 车上贴的那句说明。
5. **`catch (...)`** —— 什么都接，排在最后。
:::

::: warn 注意
**本课最大的一个坑：不是所有的翻车都叫异常，`catch` 也不是万能的。**

我们真跑过这样一段：

```text
int a = 10;
int b = 0;
cout << a / b << endl;
```

屏幕上**什么都没有**，程序当场就没了 —— 铺多少层 `catch` 都没用。因为这件事不是「有人扔了一个异常」，是**机器自己烧了保险丝**，直接停机。**这种翻车接不住，只能提前防**（动手之前先看一眼除数是不是 0 ）。

另外两条：

1. **别把一大段活全塞进一个 `try` 里。** 铺得太长，出了事你根本不知道该从哪儿查 —— 异常处理分支要铺在你**真的会翻的那几句**周围。
2. **`catch` 括号里写的名称对不上，就是接不住。** 上面第二段那个 `这一句接不到` 就是活例子：来的是数字，你只接一串字，车就从你手边过去了（要是外面还有兜底，它就落到兜底那儿）。
:::

## 小抄表

| 写法 | 念作 | 干什么 |
|---|---|---|
| `try { ... }` | 铺异常处理分支 | 这一段要盯着跑 |
| `throw 42;` | 扔一个异常 | 把这件麻烦交给上级 |
| `throw runtime_error("说明");` | 自己造一辆带说明的车 | 车上贴一句话给接车的人看 |
| `catch (int e) { ... }` | 接数字那种车 | 括号里写接什么样子的 |
| `catch (const invalid_argument& e) { ... }` | 接「料不对」那种车 | 标准写法，照抄 |
| `catch (...) { ... }` | 什么都接 | 兜底异常处理分支，**排最后** |
| `e.what()` | 车上的说明 | 印出来给对象看 |
