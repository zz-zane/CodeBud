## 学习目标

本课学习cin 与 cout。重点包括cout 输出、cin 输入、endl、流的概念直觉。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 先复习一句：`cout` 很老实，不会替你垫空格

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "你好" << "张三" << endl;
    cout << "你好" << " " << "张三" << endl;
    return 0;
}
```

```text
你好张三
你好 张三
```

两行只差中间那一件货：第一行塞的是两截字，紧贴着出来了；第二行我们多塞了一件 `" "`——**一对引号里夹着一个空格**，于是中间空出一格。

再记一遍这条脾气：**管子塞什么念什么，缝要留多宽，得你自己写进引号里**。

顺着这个脾气，把一件件货塞成一句完整的话就很简单了：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name = "张三";
    int fish = 3;
    cout << name << " 当前记录了 " << fish << " 条数据" << endl;
    return 0;
}
```

```text
张三 当前记录了 3 条数据
```

留神那两种货是怎么排排坐的：一串字、一个整数、又一串字，全都往同一根管子里塞，它按顺序输出。**整数不用你操心格式**——你上一课给它挂了 `int` 的名称，它自己知道该怎么念。

## 「流」是什么：两根管子里的水

我们说的「管子」，正式名字叫**流**（英文 stream）。这个名字取得挺贴切：数据像水一样，**一样样顺着管子流过去**。

```text
你敲键盘 ——传入——→  【cin 进水管】  →  程序  →  【cout 出水管】 ——返回——→  屏幕
```

流有个好处：**它是「一样接一样」的**。你不用提前说「这次要送三样东西」，接着塞、接着返回就行，管子里顺次排着队。C++ 里这两根管子还有个共同点：**管子两边接的是什么，名称上一看就知道**——上一课学的那些类型，在这里就派上大用场了。

## `cin`：把耳朵接上

给程序装耳朵，引用的是 `cin`（念作「C-in」，in 就是「进来」）。它的箭头和 `cout` 正好相反：**`>>` 是往回流**，把外面的东西返回进屋。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    if (!(cin >> a >> b)) {
        a = "张三";
        b = "字";
    }
    cout << "第一口复制到：" << a << endl;
    cout << "第二口复制到：" << b << endl;
    return 0;
}
```

```text
第一口复制到：张三
第二口复制到：字
```

我们往输入接口里填的是 `张三 ` 这一行，它却返回**两口**——这就是 `cin >>` 的第一个脾气：

> **`cin >>` 遇到空格就停下。**

它读的是「一样东西」，不是「一整行」。中间那个空格就是它的**停止线**：第一口复制到空格前头的 `张三`，第二口再从停止线后头接着返回 `字`。所以两个连着的 `>>` 要你喂两样东西，从前往后一样样分。

::: warn 注意
上面那段代码里，我们多写了几行你还没学过的东西。我们把它单挑出来给你看：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a, b;
    if (!(cin >> a >> b)) {
        a = "张三";
        b = "字";
    }
    cout << a << b << endl;
    return 0;
}
```

这是我们给课文里每一段**要听话的源代码**系的一条**保险绳**，我们给你解释：

- `cin >> a >> b` 是「从管子里返回两口货」。**管子里空空的时候它返回不到东西**，会摆出一张「没读到」的脸色。
- `if (!(cin >> a >> b))` 读作：「**先返回一口试试；脸色不对的话**……」
- 大括号里那两行是备用方案：我们提前备好一份货（`张三`、`字`），返回不到就用它顶上。

系上这条绳子，这段代码**有没有人喂都能平平安安跑完**。至于「看脸色分岔」这套本事，等讲到「条件判断」那一课我们再细说，今天照着抄就行。

反过来说：**你自己写的时候不必系它**。在练习场里先把输入接口填好，直接写 `cin >> a;` 也是好的。
:::

### 练习场里的输入接口在哪儿

打开「**▶️ 运行代码**」那一页，工具栏上有一个框，上面写着「**程序要你输入什么吗？（不需要就留空）**」——那个框就是输入接口。要喂的东西写在里面，点运行，程序里的 `cin` 就会把那一行取走。

它要几口，你就喂几样；一口都不喂，我们的保险绳会替你顶上。程序跑到输入接口会**停下来等你**——屏幕上半天没动静，不是坏了，它是在等你。

### 读数字：名称写好了，它自己会认

`cin` 有一件比别家省心的事：**它知道你要读的是数字，不用你动手转换**。

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    if (!(cin >> a >> b)) {
        a = 3;
        b = 5;
    }
    cout << a << " + " << b << " = " << a + b << endl;
    return 0;
}
```

```text
3 + 5 = 8
```

我们往输入接口里填的是 `3 5` 两样，它直接返回进两间 `int` 屋，还当场把加法算了出来。

这就是 C++ 把活儿揽过去的地方：**名称（`int a, b;`）已经说清了屋里保存的是整数，`cin` 照名称收货**。你在一串字那一门语言里学过的「先摘数字再算」那一步，这里不用做。

## `getline`：返回一整行

要是想连名字里的空格一起取走呢？上面那个脾气就不够用了。换一件工具：`getline`。

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string line;
    if (!getline(cin, line)) {
        line = "张三 ";
    }
    cout << "整行复制到：" << line << endl;
    return 0;
}
```

```text
整行复制到：张三 
```

一样是 `张三 `，这回它**整行都取走了**，中间的空格原样保留。

`getline` 和 `cin >>` 的分工记住这一句就够：

| 工具 | 返回什么 |
|---|---|
| `cin >>` | 一样东西，**遇空格就停** |
| `getline(cin, ...)` | **一整行**，一直复制到换行 |

## 两个一起用：一个不吭声的坑

现在把两件工具凑到一段源代码里，来看一个**不报错**的坑。我们的输入接口里填的是两行：第一行 `7`，第二行 `计算机`：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish;
    string name;
    if (!(cin >> fish)) {
        fish = 7;
    }
    getline(cin, name);
    if (name.empty()) {
        name = "（空空的）";
    }
    cout << "数据 " << fish << " 条" << endl;
    cout << "名字是 " << name << endl;
    return 0;
}
```

```text
数据 7 条
名字是 （空空的）
```

数量返回对了，名字却是空空的——**我们明明喂了「计算机」啊**。

问题出在管子里那点没人要的**残渣**：

1. `cin >> fish` 只认「一样东西」，它在读到 `7` 后面的那个**换行**时就停下来了；
2. 可它**没把那个换行拿走**——换行还留在管子里；
3. `getline` 一开口，先复制到的东西正是那个换行。**它确实复制到了「一整行」，只不过这一行是空的**，所以 `name` 里什么都没有；
4. 而 `计算机` 还排在管子后面，压根没轮到它。

这四步是**怎么一步一步走**的，我们拆开演给你看 —— 输入接口里填的是两行：`7`，下一行 `计算机`：

管子里剩下的那点**残渣**看不见，可它一步一步都在那儿 —— 混着用的时候垫一句 `cin.ignore();`，丢掉的正是那个换行；丢完再开口，`getline` 复制到的才是真正的第二行（课文里那份「正常」的版本，加的就是这一句）。

想让它正常，得把管子里那点残渣**先消耗**：

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    int fish;
    string name;
    if (!(cin >> fish)) {
        fish = 7;
    }
    cin.ignore();
    if (!getline(cin, name)) {
        name = "计算机";
    }
    cout << "数据 " << fish << " 条" << endl;
    cout << "名字是 " << name << endl;
    return 0;
}
```

```text
数据 7 条
名字是 计算机
```

多出来的那一行 `cin.ignore();` 就是「**把管子里剩着的那一个字符丢掉**」——丢掉的正是那个捣乱的换行。丢完再开口，`getline` 复制到的就是真正的第二行。

::: tip 提示
这个坑最坏的地方是：**它不报错**。屏幕上照样出字，数量还是对的，你要是没留意那个空名字，程序会一路带着错跑下去。

记住这条口令：**`cin >>` 和 `getline` 混着用的时候，中间垫一句 `cin.ignore();`**。它俩分工不同——一个只认「一样东西」、还把换行留在管子里，一个专处理「一整行」。我们往后写这种一问一答的源代码，都会顺手垫上它。
:::

::: tip 提示
「输入与输出」这一课，记住四句话就够用啦：

1. **`cout`** 是出水管：`<<` 塞一样、念一样，缝要自己写进引号里，换行用 `endl`；
2. **`cin`** 是进水管：`>>` 往回流，遇空格就停，读数字不用你转换；
3. **`getline`** 返回一整行，一直复制到换行；
4. **两个混用要垫 `cin.ignore();`**，把留在管子里的残渣消耗。

还有一句要紧的：程序跑到输入接口会**停下来等你**——这不是卡住了。
:::
