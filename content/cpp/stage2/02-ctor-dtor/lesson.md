## 学习目标

本课学习构造函数与析构函数。重点包括构造、重载构造、析构、初始化列表。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

```text
Cat c1;
c1.name = "张三";
c1.fish = 3;
Cat c2;
c2.name = "李四";
c2.fish = 1;
```

## 一、构造函数：创建对象那一刻自动跑的那一个方法

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat(string n, int f) {
        name = n;
        fish = f;
    }

    void show() const {
        cout << name << " 有 " << fish << " 条数据" << endl;
    }
};

int main() {
    Cat c1("张三", 3);
    Cat c2("李四", 1);
    c1.show();
    c2.show();
    return 0;
}
```

```text
张三 有 3 条数据
李四 有 1 条数据
```

看 `main` 里那两行：`Cat c1("张三", 3);` —— **创建对象的时候直接把料一起传入了**，我们一行都没多写。类定义上多出来的那一个方法，就是这一切的关键：

- **函数名和类定义名一个字都不差。** 类定义叫 `Cat`，这一个方法就叫 `Cat`。这是它唯一的「认领暗号」—— 编译器只要在类定义里看见一个跟类定义同名的函数，就知道「这是初始化那一刻要跑的规矩」。
- **它脑袋上不写「返回什么」。** 你看它的开头：`Cat(string n, int f)` —— 前面**不写** `void`、不写 `int` —— 因为初始化不是称呼它去干活，压根不存在「返回什么」这件事。
- **没人称呼它，它自己跑。** `Cat c1("张三", 3);` 这一句里，实例一落地，构造函数**立刻**被调用了一次：`n` 收到 `张三`、`f` 收到 `3`，两格就装好了。
- **两个输入接口是有先后的**：`n` 先接住 `"张三"`，`f` 再接住 `3`。喂料的顺序得跟脑袋上的顺序对上，这是第一阶段学函数时就已经定下的规矩。

一句口诀先记住：**函数名跟类定义同名、脑袋上不写返回什么、创建对象那一刻自动跑。**

::: warn 注意
构造函数**不能**写 `void`！我们当初想：「函数都爱在脑袋上写个返回类型，那我们也写一个总没错吧」—— 结果编译器当场拦下：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;

    void Cat(string n) {
        name = n;
    }
};

int main() {
    Cat c1("张三");
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:9:5: error: return type specification for constructor invalid
```

念作：**「构造函数头上不许写返回什么。」** 报错里那个 `constructor` 说的就是构造函数。看到它，就去把脑袋上那个 `void`（或者 `int`、`string`）**删掉** —— 它的脑袋上除了收什么料，别的什么都不该有。
:::

## 二、初始化列表：在大括号之前就把格子装好

上面那一个方法的状态里是两行「先接住料、再塞进格子」。同样一件事，还有更利索的写法：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat(string n, int f) : name(n), fish(f) {}

    void show() const {
        cout << name << " 有 " << fish << " 条数据" << endl;
    }
};

int main() {
    Cat c1("王五", 5);
    c1.show();
    return 0;
}
```

```text
王五 有 5 条数据
```

脑袋后面多了那一小段：` : name(n), fish(f)` —— 它叫**初始化列表（初始化列表）**，念作「**用 `n` 去装 `name`、用 `f` 去装 `fish`**」。

- 它在**大括号里那几行之前**执行。也就是说：实例刚落地的瞬间，东西**已经在格子里了**，而不是「先空着一会儿、再塞进去」。
- 一格一件事，中间用逗号隔开；清单写完再写那对大括号，状态里可以什么都不写 —— 于是整招缩成了 `Cat(string n, int f) : name(n), fish(f) {}` 这么一行。
- **有些格子不用清单就装不进去**：我们给格子加了「初始化以后再也不许改」的封印（`const int fish;`）之后，就只能靠清单装。

::: warn 注意
**带封印的格子（`const`）只能靠初始化列表装。** 我们试过把它放在状态里塞：

```cpp
#include <iostream>
using namespace std;

class Cat {
public:
    const int fish;

    Cat(int f) {
        fish = f;
    }
};

int main() {
    Cat c1(3);
    cout << c1.fish << endl;
    return 0;
}
```

```text
main.cpp:6:15: note: 'const int Cat::fish' should be initialized
main.cpp:9:14: error: assignment of read-only member 'Cat::fish'
```

编译器一共说了两句：上面那句 note 是「**这一格该在初始化列表里装好**」，下面那句 error 是「**这是只读的格子，不许赋值**」。所以看到 `read-only member`，就去把这一格从状态里挪到清单上 —— 写成 `Cat(int f) : fish(f) {}` 就通了。
:::

### 清单的写法，不决定装东西的先后

我们刚学这一手的时候以为「清单里谁写在前面，谁就先装」。真跑过一次才知道**不是**：装的先后只看**类定义上格子的先后**。我们把清单写反过一次，编译器当场念叨：

`main.cpp:7:9: warning: 'Cat::weight' will be initialized after [-Wreorder]`

⚠️ 这三种 `[-Wreorder]` 的字样我们是在**本机真跑出来的**，它说的是「你清单里的顺序跟类定义上格子的顺序对不上」。**但它只出声、不拦你** —— 程序照跑，数字照样装对。所以别把它当耳旁风：看见 `reorder`，要么把清单顺序理顺，要么干脆别在清单里搞跨格子的花样。

## 三、几套初始化法：同一个类定义，想怎么生就怎么生

类定义上可以挂**不止一套**构造函数：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    Cat() : name("无名"), fish(0) {}
    Cat(string n) : name(n), fish(0) {}
    Cat(string n, int f) : name(n), fish(f) {}

    void show() const {
        cout << name << "：" << fish << " 条" << endl;
    }
};

int main() {
    Cat a;
    Cat b("张三");
    Cat c("李四", 3);
    a.show();
    b.show();
    c.show();
    return 0;
}
```

```text
无名：0 条
张三：0 条
李四：3 条
```

类定义上写了三套：不带料的、只带名字的、两样都带的。编译器**看你喂了几样料、喂的是什么**，就去挑对得上的那一套 —— 这正是第一阶段「同名多招」的老套路，只不过现在它管的是「怎么初始化」。

- `Cat a;` —— 一样料都没喂 → 跑 `Cat()` 那套：名字默认「无名」、条数 0。**这就是「刚初始化别空着」的正解**：上一课那个名字格空空的对象，从此有救啦。
- `Cat b("张三");` —— 喂了一根字符串 → 跑 `Cat(string n)` 那套。
- `Cat c("李四", 3);` —— 一根字符串加一个数 → 跑两样都带的那套。

**只要料的分量或者类型不一样，几套初始化法就能同时挂在一个类定义上**，我们不用给它们起三个名字。

## 四、析构函数：对象走的时候，自动跑的那一趟

有初始化就有离开。我们给类定义再添一笔 —— 函数名前面多一个小波浪号 `~`：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;

    Cat(string n) : name(n) {
        cout << name << " 初始化啦" << endl;
    }
    ~Cat() {
        cout << name << " 睡着啦" << endl;
    }
};

int main() {
    Cat a("张三");
    {
        Cat b("李四");
        cout << "里屋现在有两个" << endl;
    }
    cout << "里屋空了" << endl;
    return 0;
}
```

```text
张三 初始化啦
李四 初始化啦
里屋现在有两个
李四 睡着啦
里屋空了
张三 睡着啦
```

三件事，一件一件看：

1. **构造函数按 `main` 里创建对象的先后跑**：张三先创建后，李四后创建后，所以先印张三那行。
2. **里屋那对大括号一结束，里屋里的李四就被收走了** —— 谁**走出**自己所在的那对大括号，谁就被自动收走。我们一句都没调用 `~Cat()`，它自己跑的。
3. **倒着收**：李四先走，张三后走（张三住在外面的变量里，得等 `main` 结束才走）。这就像栈 —— **最后放上去的，最先被拿走**。

我们把这几个时刻拆成一步一步，走给你看 —— 盯着大括号看到哪儿了：

**两个「自动」就是这一段的全部价值**：走到创建对象那一行，构造函数自己跑；走出那对大括号，析构函数自己跑 —— 我们一次都没调用过它们。哪个对象归哪对大括号管，它就在哪个 `}` 上被收走。

那析构函数到底有什么用？今天的对象身上没什么好收拾的，所以看着像走过场。等我们讲到「临时租来的变量」那一课你就知道了：**借来的东西，必须在对象走的时候还回去** —— 析构函数就是放那句「还回去」的地方。今天先把它什么时候跑记牢就够了。

## 五、我们今天记住的三句话

::: tip 提示
1. **构造函数**：函数名跟类定义名一字不差，脑袋上**不写返回什么**，`Cat c1("张三", 3);` 那一刻自动跑。
2. **初始化列表**：脑袋后面写 ` : name(n), fish(f)`，它在**大括号之前**就把格子装好；带封印的格子只能这么装。清单的**写法**不决定装填顺序，类定义上格子的先后才决定。
3. **析构函数**：名字是 `~类定义名`，**走出那对大括号时自动跑**；同一段里几个对象，倒着收。
:::

## 一句话对照表

| 我们写下的 | 它的意思 |
|---|---|
| `Cat(string n, int f) { ... }` | 构造函数：创建对象那一刻自动跑，脑袋上不写返回什么 |
| `Cat c1("张三", 3);` | 创建一个对象，同时把两样料传给构造函数 |
| `Cat(string n, int f) : name(n), fish(f) {}` | 初始化列表：在大括号之前就把格子装好 |
| `const int fish;` | 带封印的格子，只能靠初始化列表装 |
| 类定义上挂三套 `Cat(...)` | 几套初始化法，按料的分量 / 类型挑一套 |
| `~Cat() { ... }` | 析构函数：走出大括号时自动跑，几个对象倒着收 |

下一课，我们要教你一个方法「指名道姓说我们自己」的手艺：当传入进来的数据和格子**同名**的时候，那位藏在函数里的「自己」就再也躲不掉了 —— 它叫 `this`。去下一课探险
