## 学习目标

本课学习类与对象。重点包括class 定义、成员变量、成员函数、创建对象。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

```text
int fish1 = 3;    string name1 = "张三";
int fish2 = 1;    string name2 = "李四";
int fish3 = 5;    string name3 = "王五";
```

## 一、我们的类，第一次动笔

摊开纸笔，我们先画一个最普通的对象：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;

    void meow() {
        cout << "我们是" << name << "，当前记录了 " << fish << " 条数据" << endl;
    }
};

int main() {
    Cat c1;
    c1.name = "张三";
    c1.fish = 3;
    c1.meow();
    return 0;
}
```

```text
我们是张三，当前记录了 3 条数据
```

这一小块里干了**两件事**：先定义类，再根据类创建一个实例。一行一行看：

- **`class Cat { ... };`** —— 定义类的口令。`class` 就是「我们要定义一个类」，`Cat` 是这张纸的名字。**大括号闭合以后别忘了那个分号** —— 这一条上一课在卡片类定义上说过，换成 `class` 还是它。
- **`public:`** —— 一行小标签，意思是「下面这几样，类定义外面也够得着」。**今天先照抄**，它的来龙去脉我们留到第 4 课专门讲，今天你只要记得：**类定义里每样东西，都得站在某一行这样的标签下面。**
- **`string name;`** —— 类定义上的第一栏家常：**每个照它创建后的对象，都自带一格名字。** 这一行是我们在纸上画的「格子」，不是真的在哪儿开了一个。
- **`int fish;`** —— 第二栏家常：每个对象自带一格数据数。
- **`void meow() { ... }`** —— 类定义上定义的方法。它的写法和第 9 课学的函数一模一样，只差一件事：**它画在类定义的大括号里面**。所以函数里那句 `name`、`fish`，说的是**「我们自己」那两格** —— 不用写任何前缀，抬眼就看得见。

## 二、根据类创建一个实例

类定义最下面那三行，就是创建对象和使唤对象：

```cpp
Cat c1;              // 根据类创建一个实例，给它起名叫 c1
c1.name = "张三";     // 把 "张三" 放进它的名字那一格
c1.fish = 3;         // 把 3 放进它的数据那一格
c1.meow();           // 让这一个自己施展 meow 这一个方法
```

（这几行只是把上面完整程序里的同一段抄出来看，单独跑不了，所以没给输出。）

- **`Cat c1;`** —— 照类定义**真的创建一个对象**来，我们给它起个临时称呼叫 `c1`。这一句在 C++ 里**就是创建对象的全部动作** —— 不像有些语言还得调用一次 `new Cat()`，C++ 的写法更短：**写上类定义名，跟一个名字，对象就站在你跟前了。**
- **`c1.name`** —— 点号是从这个对象身上够到某一格的办法。念作「`c1` 这个对象的 `name` 那一格」。够到之后，它就跟普通的一个元素没两样，能放能取。
- **`c1.meow()`** —— 让**这一个**施展那一个方法。**先说哪个对象，再调用函数名** —— 和上一阶段学的调用函数，只多了前面那一段「哪个对象」。它输出的自然是用**自己**的名字和自己的数据数。

## 三、类定义不是对象

这句话我们要单独拎出来说 —— 它是新手第一个跟头：

> **`class Cat { ... };` 画完，元素边一个对象都没有。**

类定义上写的每一行，说的都是「凡是照它创建后的对象，长什么样、会什么」。可类定义自己不包含独立执行过程、不会处理数据，也**不占任何一格** —— 它只是画在那儿。真正让世界多一个对象的，是 `Cat c1;` 那一句。

这也是上一课那张卡片类定义教过你的同一件事：**类定义画了不做卡片，手里就没东西用。**

## 四、生两个：各带各的格子

类只需定义一次就够，想创建几个创建几个。我们再创建一个，看看它俩的账会不会串：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
};

int main() {
    Cat c1;
    Cat c2;
    c1.name = "张三";
    c1.fish = 3;
    c2.name = "李四";
    c2.fish = 1;

    c1.fish = c1.fish + 2;
    cout << c1.name << " 的账上是 " << c1.fish << " 条" << endl;
    cout << c2.name << " 的账上是 " << c2.fish << " 条" << endl;
    return 0;
}
```

```text
张三 的账上是 5 条
李四 的账上是 1 条
```

我们只给张三加了 2 条，李四**一点没跟着变**，还是它自己那 1 条。

- **类定义只有一张**，画完就那样，生多少个对象都不会把它用旧。
- **格子是每个对象各带一份的**。根据类创建实例，它就带着自己那一套 `name` 和 `fish`，和别的对象谁也不碰谁。
- 所以 `c1.fish = c1.fish + 2;` 动的是**张三那一格**，跟李四半点关系都没有。

这一整套「定义类 → 创建对象 → 装格子 → 调用函数」到底按什么顺序走，我们拆成一步一步给你看：

## 五、刚创建后的对象，格子里是什么

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
};

int main() {
    Cat c1;
    cout << "刚初始化，名字是【" << c1.name << "】" << endl;
    return 0;
}
```

```text
刚初始化，名字是【】
```

刚创建后的对象，名字那一格**本来就是空的** —— 字符串，没人往里放东西的时候就是空的一串（所以印出来两个方括号之间什么都没有，不是印出「空」这两个字）。

那 `int` 那一格呢？**没人往里放过东西之前，那格里是什么谁也没说。** 所以我们在上面这段里**一个字都没去读** `fish` —— 读一个没人放过的格子，你拿到的是一个说不准的东西，跟运气差不多。

想让它一初始化就带着名字、带着数据数？那就是下一课的正题：**让类定义在创建对象的那一刻，自动把格子摆好**。今天先记住：**没用过 `=` 放东西的格子，不要读。**

## 六、我们今天摔的两跤

**第一跤：类定义末尾那个分号忘了。**

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
}

int main() {
    Cat c1;
    c1.name = "张三";
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:9:2: error: expected ';' after class definition
```

编译器这句话的意思是：**「类定义画到这儿该收尾了，我们在等一个分号。」** 看到 `expected ';' after class definition`，别去怀疑类定义里的哪一行 —— **直接看类定义大括号后面那一个字符**。

**第二跤：够一格类定义上根本没有的家常。**

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
public:
    string name;
    int fish;
};

int main() {
    Cat c1;
    c1.name = "张三";
    c1.weight = 4;
    cout << c1.name << endl;
    return 0;
}
```

```text
main.cpp:14:8: error: 'class Cat' has no member named 'weight'
```

念作：**「`Cat` 这张类定义上，没有叫 `weight` 的那一格。」**

我们想给对象记体重，可类定义上压根没画这一栏 —— 类定义上没有的东西，实例身上当然也没有。**先回类定义加一栏，再回来写这一句**，顺序就是这样。

::: tip 提示
今天记住五句话：

1. **`class 类定义名 { ... };`** —— 定义一个类，大括号后面那个分号别丢。
2. **类定义里先写家常（几格），再写函数。** 函数里那句 `name`、`fish`，说的是我们自己那两格。
3. **`Cat c1;` 就是根据类创建一个实例**，C++ 不用调用 `new`；点号够到它自己的格子：`c1.name`。
4. **类定义只有一张，格子是每个对象各带一份**，改一个不动另一个。
5. **没人放过东西的格子不要读** —— 名字那一格是空的，装数的格子是什么谁也没说。
:::

::: warn 注意
- **类定义 ≠ 对象。** 只写 `class Cat { ... };` 而没写 `Cat c1;`，元素边一个对象都没有。
- **类定义末尾的分号**是本课最贵的一个字符，报 `expected ';' after class definition` 就是它。
- **`public:` 那一行今天先照抄**，缺了它类定义外面够不着里面的格子。
:::

## 一句话对照表

| 我们写下的 | 它的意思 |
|---|---|
| `class Cat { ... };` | 画一张叫 `Cat` 的类（**大括号后面别忘分号**） |
| `public:` | 「下面这几样，类定义外面也够得着」—— 今天先照抄 |
| `string name;` / `int fish;` | 类定义上的两格家常，每个实例自带一套 |
| `void meow() { ... }` | 类定义上定义的方法，函数里直接用 `name`、`fish` 就是自己那两格 |
| `Cat c1;` | 根据类创建一个实例，C++ 不必写 `new` |
| `c1.name = "张三";` | 把东西放进 `c1` 这一个的名字格 |
| `c1.meow();` | 让 `c1` 自己施展那一个方法 |
| `c1` 和 `c2` | 两个实例，格子各带各的，改一个不动另一个 |
