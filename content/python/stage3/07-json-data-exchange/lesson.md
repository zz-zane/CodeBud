本课学习JSON 与数据交换。重点包括json 模块、序列化、配置文件。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## JSON：一张所有对象都认的快递单

JSON 的规矩少得可怜，一个手数得过来：

- 一盒**贴了名牌的格子**，用一对**大括号**括起来：`{"张三": 2}`。左边是名牌，右边是东西，中间一个冒号。
- 名牌**必须**用**双引号**包起来 —— 单引号它不认，这一点等会儿你会亲眼看到它翻脸。
- 好几格之间用**逗号**隔开：`{"张三": 2, "李四": 1}`。
- 格子里的东西可以是数字（`2`）、真假（`true` / `false`）、空（`null`）、一句话（`"数据"`，也用双引号包着）、一盒更小的格子（`{"名字": "数据"}`），或者一排贴了编号的数组元素（`[1, 2, 3]` 这种用方括号括起来的一排格子）。

就这些。它简单到这个地步，正是因为**越简单的东西，越是谁都读得懂** —— 这就是「数据交换」四个字的意思：两样不同的东西之间递话，得挑一种**双方都认**的说法。

## 装箱：`json.dumps`

Python 里管快递单的那盒工具就叫 `json`，请它进屋只写一句 `import json`。

「把格子柜里的东西搬进一张纸条」这个动作，书上叫**序列化**，我们喜欢叫它「**装箱**」。装箱的函数叫 `dumps`：

```python
import json

零食 = {"名字": "数据", "数量": 3}
print(json.dumps(零食))
print(json.dumps(零食, ensure_ascii=False))
```

```text
{"\u540d\u5b57": "\u6570\u636e", "\u6570\u91cf": 3}
{"名字": "数据", "数量": 3}
```

两行只差一个小开关，印出来的东西却完全不一样：

- **第一行**：`json.dumps(零食)` 把格子柜变成了一张纸条，可「名字」两个字变成了 `\u540d\u5b57`、「数据」变成了 `\u6570\u636e`。这是**转义写法**：每个中文字都被记成了它自己的编号，写成 `\u` 加四位十六进制。纸条本身没错，只是**人看着费劲**。
- **第二行**：多喂了一个 `ensure_ascii=False`，中文就原样印出来了。`ensure_ascii` 读作「保证只用 ASCII 那一小撮英文符号」，把它关掉（写成 `False`），它就不再把中文换成编号。

✨ **这一点我们要重重画一道线**：`ensure_ascii=False` 写不写，**屏幕上的字长得完全不一样**。以后你照着课文对答案，或者打开别人给的 JSON 文件看到满屏 `\u` 开头的密码，都是这一个小开关在起作用 —— 那不是坏了，是**默认就这么办**。

::: tip 提示
`json.dumps` 交回来的东西，是**一张纸条**（一串数据穿成的字符串），不是格子柜了。你可以 `print` 它、可以把它写进抽屉、可以顺着网线寄出去 —— 但**不能**再拿它当格子柜使：纸条不认名牌，`纸条["名字"]` 会当场出错。想再按名牌取东西，得先**拆箱**。
:::

## 拆箱：`json.loads`

反过来，把纸条搬回格子柜，叫**反序列化**，我们叫它「**拆箱**」。函数是 `loads`：

```python
import json

纸条 = '{"名字": "数据", "数量": 3}'
零食 = json.loads(纸条)
print(零食["名字"])
print(零食["数量"])
```

```text
数据
3
```

拆开看：

- 第一行，纸条在 Python 里是一串字符，我们用**单引号**把它包起来 —— 这样里面那些**双引号**才能原样留着当内容。要是外面也用双引号，两对引号会打起来，这句话写到一半就断了。
- `json.loads(纸条)` 把这张纸条**读回成格子柜**：`零食` 又变回一个能按名牌引用名称的格子柜了。
- 所以 `零食["名字"]` 能调用出「数据」，`零食["数量"]` 能调用出 `3`。**拆箱之后，它跟我们从头建一个格子柜没有半点区别。**

到这儿，装箱（`dumps`）、拆箱（`loads`）一对就齐了。这里的 **`s` 是对纸条的** —— 记住这句，下面的抽屉那一对就好记了。

## 纸条上写着小写的真假与 null

有一件事容易看花眼。我们亲手写一张纸条交给 Python 拆：

```python
import json

纸条 = '{"全屏": false, "音量": 8, "备注": null}'
设置 = json.loads(纸条)
print(设置)
print(设置["全屏"])
print(设置["备注"])
```

```text
{'全屏': False, '音量': 8, '备注': None}
False
None
```

- 纸条（JSON）上写的是**小写**的 `false` 和 `null`；拆箱回到 Python，它们就变成我们熟悉的大写 `False` 和 `None`。反过来也一样：Python 的 `True` / `False` / `None` 出门上纸条，一律写成小写的 `true` / `false` / `null`。
- 顺带盯一眼第一行输出：`print(设置)` 印出来的是**格子柜本来的样子** —— 名牌没包引号、每一项之间是**单引号**。而 `dumps` 印出来的是**纸条的样子**，一律**双引号**。两个东西都摆在屏幕上时，一眼就能分清手里拿的是哪一个。

## 取出来的顺序：放入顺序

```python
import json

清单 = {"张三": 2, "李四": 1, "三花": 3}
print(json.dumps(清单, ensure_ascii=False))
print(json.dumps(清单, ensure_ascii=False, sort_keys=True))
```

```text
{"张三": 2, "李四": 1, "三花": 3}
{"三花": 3, "张三": 2, "李四": 1}
```

- **第一行**：按我们**放进去的顺序**印 —— 先放张三就印张三，再放李四就印李四。Python 3.7 起，格子柜的「放入顺序」是**写在语言保证里的**：你按什么次序放，它就按什么次序取，不会时灵时不灵。
- **第二行**：多写了 `sort_keys=True`（给名牌**排排坐**），名牌就按**它们自己的字符编号**重排，于是「三花」跑到了最前面。注意它比的是字符的编号，跟拼音、跟笔画都没关系 —— 别拿拼音去猜它的次序。

这两条路都是**确定的**：不写 `sort_keys` 就是放入顺序，写了就照字符编号排，跑一百遍都一样。所以你照着课文对答案，一定对得上。

## 存进抽屉：配置文件

JSON 最日常的用处，是**把设置存进一个文件里**，下次打开软件再读回来 —— 这种文件就叫**配置文件**。一个 `{"音量": 8}` 存进去，就是一个最简单的配置文件了。

先看「给人读」的写法，多喂一个 `indent=2`，纸条就一格一行、缩进两格，整整齐齐：

```python
import json

设置 = {"音量": 8, "主题": "工作区蓝", "全屏": False}
print(json.dumps(设置, ensure_ascii=False, indent=2))
```

```text
{
  "音量": 8,
  "主题": "工作区蓝",
  "全屏": false
}
```

再看真正存进抽屉、再读回来的整套动作：

```python
import json

设置 = {"音量": 8, "主题": "工作区蓝"}

with open("设置.json", "w", encoding="utf-8") as 文件:
    json.dump(设置, 文件, ensure_ascii=False)

with open("设置.json", encoding="utf-8") as 文件:
    读回来的 = json.load(文件)

print(读回来的)
print(读回来的["主题"])
```

```text
{'音量': 8, '主题': '工作区蓝'}
工作区蓝
```

逐句拆：

- `with open("设置.json", "w", encoding="utf-8") as 文件:` —— 打开（没有就新建）一个叫 `设置.json` 的抽屉。`"w"` 是「我要往里**写**」，`encoding="utf-8"` 是「按能装中文的写法存」。`as 文件` 给这个抽屉起个名字，缩进里那几行都对着它干活，出了这一段它自己会关好 —— 这一个方法你以前见过，今天照抄就行。
- `json.dump(设置, 文件, ensure_ascii=False)` —— 注意这里**没有 s**！`dump` 要两样东西：一个格子柜、一个抽屉。它把格子柜直接装进抽屉，**不把纸条交给你**。
- `json.load(文件)` —— 从抽屉里拆箱回来，同样**没有 s**。

一句话记牢：**带 s 的对纸条，不带 s 的对抽屉。**

::: warn 注意
三个最容易踩的坑：

- **忘了 `ensure_ascii=False`**：中文全变成 `\u6570\u636e` 这种密码。它不是坏了，是默认就这么办。
- **`dump` 和 `dumps` 写反**：`dumps` 只要一个格子柜，`dump` 还要你再给一个抽屉。写成 `json.dump(零食)` 少给一个抽屉，解释器会说你少喂了它一样东西。
- **纸条上拿单引号包名牌**：`{'张三': 2}` 在 Python 里是个合法的格子柜，但它**不是**一张合法纸条 —— 纸条上的名牌必须用双引号。
:::

## 坏纸条会长什么样

要是纸条上写的根本不是一张合法快递单，`loads` 会当场犯难。我们这儿有两张坏纸条。

第一张：光秃秃三个中文字。

```python
import json

零食 = json.loads("数据")
```

解释器当场犯难：

```text
Traceback (most recent call last):
json.decoder.JSONDecodeError: Expecting value: line 1 column 1 (char 0)
```

一张合法纸条，要么是 `{...}`、要么是 `4`、要么是 `"数据"`（**自己带上双引号**）—— 光秃秃三个字什么都不算，它只好说自己「Expecting value」：**在等一个值**。

第二张：名牌用单引号包着。

```python
import json

零食 = json.loads("{'张三': 2}")
```

```text
Traceback (most recent call last):
json.decoder.JSONDecodeError: Expecting property name enclosed in double quotes: line 1 column 2 (char 1)
```

这句话翻译过来很直白：「**名牌要用双引号包起来**」。它没有生气，只是不认单引号。

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `import json` | 请出管纸条的那盒工具 |
| `json.dumps(格子柜)` | **装箱**：格子柜 → 一张纸条 |
| `json.dumps(格子柜, ensure_ascii=False)` | 装箱，中文原样印，不变 `\u` 密码 |
| `json.dumps(格子柜, sort_keys=True)` | 装箱，名牌按字符编号排排坐 |
| `json.dumps(格子柜, indent=2)` | 装箱，一格一行、缩进两格，给人读 |
| `json.loads(纸条)` | **拆箱**：一张纸条 → 格子柜 |
| `json.dump(格子柜, 抽屉)` | 装箱，直接装进抽屉（不带 s） |
| `json.load(抽屉)` | 拆箱，直接从抽屉里读（不带 s） |

```python
import json

清单 = {"张三": 2, "李四": 1}
清单["三花"] = 3
print(json.dumps(清单, ensure_ascii=False))
```

```text
{"张三": 2, "李四": 1, "三花": 3}
```

瞧，新添的「三花」排在了**最后** —— 因为它就是最后一个放进去的。

1. 把 `清单["三花"] = 3` 挪到最前面（建好 `清单` 就立刻添），再跑一遍 —— 三花这回印在第几个？
2. 给 `dumps` 多加一个 `sort_keys=True`，再跑 —— 次序变了吗？
3. 把 `ensure_ascii=False` 删掉再跑 —— 屏幕上印出来的是中文，还是 `\u` 密码？
