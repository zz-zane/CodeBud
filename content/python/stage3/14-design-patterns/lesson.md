## 学习目标

本课学习设计模式。重点包括单例、工厂、观察者、模式思想。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 套路一：全窝只有一个的那件东西

**麻烦长这样：** 我们的窝里其实只有**一个**数组元素。可谁想用元素，就在自己那儿写一句「造一个元素」——三处写了三句，就造出三个元素。三个元素各记各的存量，我们往里添了五条数据，另一处去看还是空的。

**摆法：** 让「造一个元素」这件事**怎么调用都只给同一个**。

```python
class 数组元素:
    _唯一的一个 = None

    def __new__(cls):
        if cls._唯一的一个 is None:
            cls._唯一的一个 = super().__new__(cls)
            cls._唯一的一个.存量 = 0
        return cls._唯一的一个

元素1 = 数组元素()
元素2 = 数组元素()
元素1.存量 += 5
print("是同一个元素吗？", 元素1 is 元素2)
print("元素2 里的存量：", 元素2.存量)
```

```text
是同一个元素吗？ True
元素2 里的存量： 5
```

拆开看：

- **`_唯一的一个 = None`** 是写在**类定义上**的一个记号（我们给它头上加了条下划线，意思是「这是类定义自己的小本子，别乱碰」）。它不归任何一个实例所有——它是**类定义那一层**记着的：我们已经把唯一那个创建后了没有。
- **`__new__`** 是「**创建一个新对象**」那道工序。平常你调用 `数组元素()`，解释器自动就把这道工序跑一遍，谁也不注意它。我们在这儿把它**拦下来**：先看类定义上记着了没有——**记着了就直接把那一个递出去**，没记着才动手创建一个，生完顺手记在类定义上。
- 所以 `元素1` 和 `元素2` 拿到的是**同一个**：往里添五条数据，两处看都是五条。`is` 那句问的就是「是不是同一个东西」，答「真」。
- 这个套路的正式名字叫**单例**——一组只有一例。什么时候值得这么摆：全窝**真的只有一份**的东西——一份全窝共用的设置、一个连着远处工作区的口子、一本日志。什么时候**别**这么摆：只要你自己也说不清「为什么只能有一个」，那就别硬凑，造两个元素不会塌天。

## 套路二：领养处

**麻烦长这样：** 来领对象的对象，其实**不关心**自己领的是学生甲还是学生乙——她只想知道「我要一个对象」。可她得亲手写下品种的名字、还得知道新品种是怎么造的。哪天窝里多了一个品种，她那段代码就得跟着改。

**摆法：** 开一间**领养处**。来领对象的只报一句「要什么样的」，剩下的事领养处自己掂量。

```python
class 学生甲:
    def 输出结果(self):
        return ""

class 学生乙:
    def 输出结果(self):
        return "嗷"

def 领养一个(花色):
    if 花色 == "橘":
        return 学生甲()
    return 学生乙()

for 花色 in ["橘", "李四", "花"]:
    print(花色, "->", 领养一个(花色).输出结果())
```

```text
橘 -> 
李四 -> 嗷
花 -> 嗷
```

拆开看：

- **`领养一个(花色)`** 就是门口那间领养处。你报花色，它去后面挑一个递给你；你拿到手就能调用 `输出结果`，**从头到尾不知道**它是照哪张类定义创建后的。
- 好处落在**改一处**上：将来窝里添一个「学生丙」的品种，改动只发生在**领养处这一处**；所有来领对象的地方一个字都不用动。
  （上面第三行「花」拿到的是学生乙——因为领养处只认「橘」这个字，别的都走最后那条兜底的路。这也是领养处的脾气之一：兜底给谁，你说了算。）
- 这个套路的正式名字叫**工厂**——造东西的地方。别人不自己造，来这儿领。

## 套路三：摇铃与听众

**麻烦长这样：** 处理要通知全窝的对象。要是摇铃的那位手上**攥着一份名单**、还得挨个知道「张三听见了会冲向元素、李四听见了会先翻个身」，那每加一个对象，她手里那份名单和那一串「谁听见了会怎样」都得改。

**摆法：** 摇铃的**只管摇**，对象自己**订**上来的。

```python
class 处理铃:
    def __init__(self):
        self.听众 = []
    def 订上(self, 对象):
        self.听众.append(对象)
    def 摇铃(self, 菜名):
        for 对象 in self.听众:
            对象.听见了(菜名)

class 对象:
    def __init__(self, 名字):
        self.名字 = 名字
    def 听见了(self, 菜名):
        print(self.名字, "冲向", 菜名)

铃 = 处理铃()
铃.订上(对象("张三"))
铃.订上(对象("李四"))
铃.摇铃("数据")
铃.摇铃("商品")
```

```text
张三 冲向 数据
李四 冲向 数据
张三 冲向 商品
李四 冲向 商品
```

拆开看：

- **`处理铃` 只管两件事**：谁能订上（`订上`）、摇的时候挨个通知（`摇铃`）。它**不知道**每个对象听见了会做什么——它只负责挨个调用一句 `听见了`，剩下的是每个对象自己的事。
- 这正是已有实现对象那句「**多态调用**」：同一句 `听见了` 输出，学生甲冲过来了、学生乙翻个身——**说好的那句话一样，各对象按自己的性子接**。你只管在每个对象自己的类定义上写它的接法。
- 好处还是**改一处**：明天要加一个学生丙，**铃那边一个字都不用改**，只要她自己也订上来就行。
- 这个套路的正式名字叫**观察者**——一件东西动了，所有订上来的都跟着动。什么时候值得：一件事发生了，**有一个以上的地方要跟着动**，而且这些地方**将来还会增减**。人少又固定的时候，直接挨个引用名称反而更清楚。

## 套路怎么认、怎么用

三个套路长得差得远，可它们仨身上有个共同点：**都在把「改一处」变成现实**。

- 单例：全窝共用一件东西，省掉「你有三个元素」的混乱。
- 领养处：来领对象的不认识品种，添品种只改一处。
- 处理铃：摇铃的不认识听众，添听众只改一处。

所以你在自己的代码里，只要发现「**改一处得动十处**」，那儿多半就住着某个套路能治的病。反过来，你背下来十个套路的名字，却找不到那个病，那一个也用不上。

我们把判断的三条写在这儿：

1. **先有麻烦，再找套路。** 为了用套路而用套路，等于往窝里摆一堆没人用的柜子——占地还挡路。
2. **套路不是必须的。** 上面三段都是十几行；很多时候不用它，直接写反而更好看、更好懂。
3. **名字只是拿来聊天的。** 记不住「单例」「工厂」这些名字一点关系都没有，记住**「有这么个摆法」**才管用——哪天你翻别人的窝，看见一个眼熟的结构，那才有用。

::: tip 提示
今天记住三条：① 套路是**摆法**不是代码，讲的是「谁该管什么、谁该不认识谁」；② 三段套路的共同点都是**把「改一处」做实**——发现「改一处得动十处」，那儿就是病；③ 别为了用而用，**先有麻烦，再找套路**。
:::

::: warn 注意
我们最想拦你的一件事：**别背名字**。

「单例」「工厂」「观察者」这些名字，是已有实现对象事后给老方子起的称呼，**不是学套路的入口**。你要是先把名字背下来，再满世界找地方套，最后大概率会写出——「本来只要三行的东西，被拆成三个类定义、绕了两道，跑起来一点毛病没有，可读起来谁也不认识」。那叫为了套路而套路，是我们见过最费时间的自坑。
:::

## 小任务

我们给你留两个：

1. 给上面那口处理铃**添一个新对象**（比如「三花」），要求：**铃那边一个字都不改**。改完摇一次铃，看看是不是三个对象都有自己的反应——这一条做到了，你就摸到这个套路的脾气了。
2. 对着自己以前写的本子找找，有没有这两样东西：一样是「全窝真的只能有一份」的，一样是「改一处得动十处」的。找到以后**先别急着改**——把「麻烦」用一句话写清楚，再回头看这一课，看看哪一段对得上。
