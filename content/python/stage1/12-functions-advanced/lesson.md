## 学习目标

本课学习函数进阶。重点包括默认参数、关键字参数、多返回值。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一、默认参数（自带的数据）：不喂就用函数自己那份

我们的函数里，有一条数据几乎每次都是同一个值 —— 比如打招呼的开场白，十次里有九次都是「你好」。每次都要把它重新喂一遍，太啰嗦了。

解法很朴素：**在函数头上，我们先给这条数据配好一份。** 你喂了，就用你喂的；你不喂，函数就端出自己带的这份。

```python
def greet(name, greeting="你好"):
    print(f"{greeting}，{name}")

greet("张三")
greet("李四", "早上好")
```

```text
你好，张三
早上好，李四
```

拆开看这一行行：

- **`greeting="你好"`** —— 函数头上直接写「名字 `=` 一份值」，意思就是「这条数据我们自己带了一份」。带等号的那一条，就是**自带的数据**。
- **第一次 `greet("张三")`** 只喂了一条，`greeting` 那一格**空着**。空着不要紧，函数把它自己带的 `"你好"` 端了出来，于是印出「你好，张三」。
- **第二次 `greet("李四", "早上好")`** 喂了两条，自带的那份**被顶掉**，改用你喂的 —— 印出「早上好，李四」。

一句话：**喂了就听你的，不喂就听函数的。**

### 自带的那份必须排在最后

有自带数据的那条，**必须排在没自带的后面**。要是排反了，解释器连跑都不跑：

```text
def greet(greeting="你好", name):
    print(name)
```

```text
  File "...\main.py", line 1
    def greet(greeting="你好", name):
                             ^^^^
SyntaxError: parameter without a default follows parameter with a default
```

最后那句用自然语言解释就是：**没自带存货的那条，排到了自带存货的后面。**

为什么 Python 要立这条规矩？因为喂的时候是**按顺序对号入座**的：第一条进第一个位置，第二条进第二个位置……要是自带的排在前面，你只喂一条的时候，解释器就不知道这一条到底是给谁的 —— 是补上自带那个缺，还是跳过它传给后面那个？**它分不清，索性不许你写。**

规矩记成一句话：**自带存货的排最后** —— 前头那些必须喂，后头那些可以偷懒。

::: tip 提示
自带的数据就记三件事：**写法**是 `名字=值`；**脾气**是你喂了就顶掉、不喂就用它带的；**排位**是必须排在没自带的后面。三件事都记住，这一节就通关了。
:::

## 二、关键字参数（点名传入）：报上名字再喂

第一节解决的是「懒得喂」，这一节解决的是**喂错位置**。

老办法传入，是**排队对号入座**：你只管往队里塞，塞第几个它就是第几个。姿势记岔一位，两份东西就换了个位置 —— 而且它**不报错**，只是安安静静地把城市当成了年龄。这种错最难找。

第二种姿势是**点名传入**：每份数据先报上名字，再传入：

```python
def intro(name, age, city):
    print(f"{name}今年{age}岁，住在{city}")

intro("张三", 3, "工作区")
intro(city="工作区", age=3, name="张三")
intro("李四", age=5, city="工作区")
```

```text
张三今年3岁，住在工作区
张三今年3岁，住在工作区
李四今年5岁，住在工作区
```

- **第一句**是**排队传入**（老办法）：按位置一个一个塞进去。
- **第二句**是**点名传入**：写法是 `名字=要喂的东西`。三条都点了名，所以**顺序随便你怎么颠**，解释器照样对号入座 —— 印出来的和第一句一模一样。
- **第三句**是**混着来**：前面没点名的照旧排队，后面点名的就能随便放。

点名传入有两个好处：

1. **不怕记岔顺序。** 三个位置连排在一起，写到第三天就忘了第三个是年龄还是城市；点名写出来，一眼就读得懂。
2. **可以只喂想改的那几条。** 剩下的位置不写，它们照旧按排队或者用自带的那份（上一节学的）补上。

### 没点名的必须排在前面

这条规矩和上一节是一家人：**没点名的一定要排在点了名的前面。**

```text
def intro(name, age, city):
    print(name)

intro(age=3, "张三", "工作区")
```

```text
  File "...\main.py", line 4
    intro(age=3, "张三", "工作区")
                           ^
SyntaxError: positional argument follows keyword argument
```

用自然语言解释：**点名环节开始之后，又冒出一个没点名的。**

为什么也拦？因为 `age=3` 一出现，解释器就当「从这儿起改成点名」了。后面再冒出来一个没点名的，它不知道该把你排在哪个位置 —— 排在 `age` 前面吗？可 `age` 已经被点走了呀。分不清，就照样不许写。

::: warn 注意
两条排位规矩，一口气记下来：

- **自带存货的排最后** —— `def f(a, b=3):` 对，`def f(a=1, b):` 错。
- **没点名的排前面** —— `f(1, 2, c=3)` 对，`f(c=3, 1, 2)` 错。

这两条错法都是**还没开跑就报错**（`SyntaxError`）：解释器读一眼函数头就把单子退回来了，你写的代码**一个字都不会执行**。报错听起来吓人，其实是好事 —— 它把你从「喂错了位置却安安静静跑完」那种更深的坑里拽了出来。
:::

## 三、多返回值（一趟返回好几样）：逗号是关键

前两节说的都是**传入**的姿势，这一节说**返回**。

我们的函数干完活，`return` 后面可以**排一串**，用逗号隔开 —— 一趟全返回：

```python
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

条数, 总价 = 报账(4, 3)
print(条数)
print(总价)
```

```text
4
12
```

- **`return 条数, total`** —— 逗号是关键。写 `return 条数` 只返回一样；写成 `return 条数, total`，就一趟返回**两样**。
- **左边摆几个变量，它就按顺序一份一份倒给你。** `条数` 接到 `4`，`总价` 接到 `12`。这一手第 10 课在**元组（焊死的小盒子）**身上见过，叫**解包** —— 按顺序倒出来。
- 顺序是**从左到右**对着来的：左边第一个变量接第一样，第二个接第二样。

### 其实返回的是一整盒

要是左边**只摆一个变量**去接，那它接到的就是**一整盒**：

```python
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

结果 = 报账(4, 3)
print(结果)
print(结果[0])
```

```text
(4, 12)
4
```

- **`print(结果)` 把整盒端出来给你看**：`(4, 12)` —— 圆括号和逗号都印出来了。这不是巧合，`return 条数, total` 返回的真身就是一个**元组**，第 10 课那个焊死的小盒子。
- **既然是盒子，就能报编号取**：`结果[0]` 拿到 `4`，`结果[1]` 拿到 `12`。

所以「一趟返回好几样」的真相是：**函数返回一整盒，左边摆几个变量，它就当着你的面拆成几份。**

### 变量个数对不上就炸毛

```text
def 报账(条数, 单价):
    total = 条数 * 单价
    return 条数, total

a, b, c = 报账(4, 3)
```

```text
Traceback (most recent call last):
  File "...\main.py", line 5, in <module>
    a, b, c = 报账(4, 3)
    ^^^^^^^
ValueError: not enough values to unpack (expected 3, got 2)
```

最后那句用自然语言解释：**要拆的东西不够，说好给三个，实际只有两个。**

注意它和上一节那两条错的**脾气不一样**：

- `SyntaxError` 那两条，是解释器**读一眼就退单**，代码一个字都不跑。
- 这一条是**跑到那一行才炸**的 —— 前面的函数都好好干完活了，到拆盒子这一步才发现变量多摆了一个。

::: tip 提示
三种姿势收口：

- **自带的数据**（`def f(a, b=3):`）—— 这条数据几乎每次都一样，懒得喂时用。
- **点名传入**（`f(b=5, a=1)`）—— 位置记不住、或者只想改其中一两条时用。
- **一趟返回好几样**（`return a, b`）—— 干完活有好几样成果要带回来时用。

三条排位规矩再念一遍：**自带存货的排最后，没点名的排前面。**
:::

## 四、三样一起上：把姿势叠起来

最后把三种姿势叠在一段代码里，看一眼它们怎么配合：

```python
def 报账(条数, 单价=3):
    total = 条数 * 单价
    return 条数, total

print(报账(4))
print(报账(2, 5))
print(报账(6, 单价=2))
```

```text
(4, 12)
(2, 10)
(6, 12)
```

- **`print(报账(4))`** —— 单价没喂，用自带的 `3`，`4 × 3 = 12`，返回 `(4, 12)`。
- **`print(报账(2, 5))`** —— 单价喂了 `5`，自带的那份被顶掉，`2 × 5 = 10`，返回 `(2, 10)`。
- **`print(报账(6, 单价=2))`** —— 条数排队喂、单价点名喂，混着来也行，`6 × 2 = 12`，返回 `(6, 12)`。

三种姿势谁也不碍着谁：**自己带的负责偷懒，点名的负责不记岔，逗号负责一次多带几样。**
