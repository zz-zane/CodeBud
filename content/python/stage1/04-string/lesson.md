## 学习目标

本课学习字符串。重点包括字符串创建、索引、切片、常用方法。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 串字符串：引号就是那根线

串一条字符串的办法简单到不像话：**拿引号把内容围起来**。单引号 `'` 和双引号 `"` 都行，只要左右配成对：

```python
a = "字符串"
b = '字符串'
print(a)
print(b)
```

```text
字符串
字符串
```

两次打印一模一样，说明在 Python 眼里 `"` 和 `'` 是**同一根线**，你喜欢哪根就用哪根。串好的字符串照样可以放进一个叫 `a` 的变量里存着，往后引用名称就能取——这件事你上一课已经会了。

### 引号划出来的那条界线

引号还管着一件大事：**分清「数字」和「长得像数字的字符」**。

```python
print(3 + 5)
print("3" + "5")
```

```text
8
35
```

同样是 3 和 5，一个得 `8`、一个得 `35`，差别全在引号上：不带引号的 `3` 是**真正的数字**，`+` 老老实实做加法；带引号的 `"3"` 则是**两颗字符穿成的字符串**，而字符串加字符串就是把两条接成一条更长的——`"3" + "5"` 得到的是 `"35"` 。

### 节点与复印

`+` 能把两条字符串接起来，`*` 能把同一条字符串复印好几遍：

```python
print("一口" + "一口")
print("哈" * 3)
```

```text
一口一口
哈哈哈
```

`"哈" * 3` 就是「把这一颗复印三份、再串成一串」。

## 报编号取一颗：索引

字符串最贴心的地方是：**每一颗都有编号**，而且编号从 `0` 开始。

```python
s = "上山打老虎"
print(s[0])
print(s[1])
print(s[2])
print(s[4])
```

```text
上
山
打
虎
```

把 `s = "上山打老虎"` 摊在桌上，编号和那一颗的对应关系长这样：

| 编号 | 0 | 1 | 2 | 3 | 4 |
|---|---|---|---|---|---|
| 那一颗 | 上 | 山 | 打 | 老 | 虎 |

所以 `s[0]` 是第一颗「上」，`s[4]` 是第五颗「虎」——**方括号里写编号**，读作「字符串 `s` 的第几颗」。规律只有一条：**从 0 开始数**，第一颗永远是 0 号，往后依次加一。

### 倒着数：负数编号

想拿最后一颗的时候，从 0 数到 4 太累了。Python 允许你**从末尾往回数**，用负数：

```python
s = "上山打老虎"
print(s[-1])
print(s[-2])
```

```text
虎
老
```

`s[-1]` 是倒数第一颗，`s[-2]` 是倒数第二颗——**`-1` 就是最后一颗**，往后你会天天用到它。字符串不长的时候，`s[4]` 和 `s[-1]` 指的是同一颗。

::: warn 注意
报了一个不存在的编号，Python 会当场翻脸。这条字符串只有 5 颗（编号 0~4），你要是写 `s[5]`，它会甩给你一句 `IndexError: string index out of range`——意思是「编号跑到字符串外面去啦」。看到这句，先掰手指数一数字符串有几颗，别硬猜。
:::

## 剪一段：切片

光拿一颗不够用的时候，把编号写成 `起点:终点` 的样子（中间是**冒号**，不是逗号），就能剪下**连着的一段**：

```python
s = "上山打老虎"
print(s[1:3])
print(s[:2])
print(s[3:])
```

```text
山打
上山
老虎
```

规则只有一句，请你念三遍：**含头不含尾**。`s[1:3]` 拿的是编号 1 和 2 这两颗，**编号 3 那颗不要**——所以剪下来是「山打」，不是「山打老」。刚开始学的人十有八九会把这个记反，多写两遍就顺了。

两头都可以偷懒：
- `s[:2]` 省略了起点 → 从**最开头**开始剪（等于 `s[0:2]`，得到「上山」）
- `s[3:]` 省略了终点 → 一路剪到**末尾**（得到「老虎」）

## 字符串自带的函数：常用方法

字符串自己会不少本事。称呼它们的写法和报编号不一样：**先写字符串的名字，中间点一个点，再写函数的名字，最后跟一对小括号**。

```python
name = "MiAi"
print(name.lower())
print(name.upper())
print(len(name))
```

```text
miai
MIAI
4
```

- `name.lower()`：整条变成小写，`MiAi` 变成 `miai`
- `name.upper()`：整条变成大写，`MiAi` 变成 `MIAI`
- `len(name)`：数一数有几颗，得到 `4`

注意 `len` 的写法和前两个**不一样**：它是外面请来的外援函数，字符串得**放进括号里**、前面**不点**——写成 `len(name)` 才对。而 `lower`、`upper` 是字符串**自带的**函数，要点着它的名字调用：`name.lower()`。

（顺带一提：`lower` 和 `upper` 拿中文字符串没辙——中文本来就不分大小写，它俩只会原样还给你，别以为是坏了。）

还有一条铁规矩：**函数的名字要照着抄**。Python 认大小写——`upper` 写成 `Upper`，它就不认得这一个方法了。

另外两个每天都要用上的：

```python
s = "上山打老虎"
g = "  数据  "
print(g.strip())
print(s.replace("打", "抓"))
```

```text
数据
上山抓老虎
```

- `g.strip()`：把**两头的空格**掐掉。`"  数据  "` 前后各挂着两个空格，`strip()` 之后干干净净只剩「数据」。别人递过来的文字常常带着看不见的空格，`strip()` 就是那把掸子。
- `s.replace("打", "抓")`：要传入两颗数据——第一颗是**要被换掉的**，第二颗是**换成什么**。于是「上山打老虎」变成了「上山抓老虎」。

还有一件常常要问的事：「这条字符串里有没有某一段？」用 `in` 去问它，它返回 `True` 或者 `False`：

```python
s = "上山打老虎"
print("老虎" in s)
print("商品" in s)
```

```text
True
False
```

::: tip 提示
今天这四件事，各记一句：
1. **串**：引号一围就是字符串；`+` 是节点，`*` 是复印。
2. **数**：`s[0]` 第一颗、`s[-1]` 最后一颗，编号**从 0 开始**。
3. **剪**：`s[起点:终点]`，**含头不含尾**；起点终点都可以不写，不写就取到头/尾。
4. **用**：自带的函数点着调用 `name.upper()`；外援函数 `len(name)` 把字符串放进括号里。
:::

::: warn 注意
三个最容易踩的坑：
- 编号越界会挨 `IndexError` 的骂，报编号之前先数清字符串有几颗。
- `"3"` 和 `3` 不是一回事——写成 `"3" + 5` 会报错，Python 一时分不清你是要做加法还是接字符串。
- 函数后面那对小括号不能丢：`name.upper` 只是把函数本身拿出来（没施展），`name.upper()` 才会给你大写的结果。
:::
