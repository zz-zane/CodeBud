## 学习目标

本课学习函数基础。重点包括def 定义、调用、参数、return。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

```text
张三，早上好，今天也要好好处理饭
李四，早上好，今天也要好好处理饭
三花，早上好，今天也要好好处理饭
```

## 一、`def`：把自己的第一个方法记下来

登记一个方法用的是 `def`（英文 define 的缩写，我们管这一行叫**起手式**）。先看一个最小的：

```python
def greet():
    print("你好")

print("上课前")
greet()
print("下课后")
```

```text
上课前
你好
下课后
```

咦，屏幕上第一条怎么是「上课前」？我们明明把 `def` 写在最上面呀。逐块拆开看，顺序就明白了：

- **`def greet():`** —— 这一行只是**登记**：我们在函数簿上写下「有这么一个方法，名叫 `greet`，里头干这几件事」。**登记的时候，函数一步都不会动**，解释器只是把它记下来。
- **缩进的那一句** —— 函数的身体。缩进 4 个空格，意思是「这句属于上面这一个方法」。缩进的规矩和 `for`、`if` 那一套一模一样：冒号后面往里让一格，同一层的活儿缩得一样多。
- **`greet()`** —— 这才叫**施展**（术语里说「调用」，我们说「调用一次」）。函数名后面跟一对小括号，函数簿上包着的活儿就从第一句跑到最后一句。
- **空括号 `()`** —— 这一个方法什么都不要，所以称呼它的时候括号里空着。

**「登记」和「施展」是两件事** —— 这是今天的第一个坑，也是最容易摔的那个。

::: warn 注意
有两个「不报错、但屏幕上什么都没有」的坑，我们都摔过：

1. **登记了，却没调用一次。** 只写 `def greet():` 和它的身体、忘了写 `greet()`，程序会安安静静地跑完，屏幕上**一个字都没有**。解释器心想「你让我记下来，我记下来了；你又没调用我，我干嘛要动」—— 它一点毛病都没有，你也没法从报错里看出问题。
2. **引用的时候把小括号丢了。** 写 `greet` 是「指着函数簿上这个名字说：喏，就是它」；只有写 `greet()`（**带上小括号**）才是「施展」。少这一对括号，照样不报错、照样什么都不发生。

记住判据：**报名字不带括号 = 只是指了一下；报名字带括号 = 现在立刻动手。**
:::

还有个坑，是眼睛一花就会犯的 —— 把冒号漏了：

```text
def greet()
    print("你好")

greet()
```

我们把这行敲进解释器的耳朵，它当场翻脸：

```text
  File "...\main.py", line 1
    def greet()
               ^
SyntaxError: expected ':'
```

`SyntaxError` 是「**话没说圆**」—— 句子的形状不对，它连往下读都读不了。最后那句 `expected ':'` 是它在说：「我们站在这儿，正等着一个冒号呢。」所以记牢：**函数名后面那对小括号、和紧跟的冒号，一个都不能少。**

## 二、参数：让函数别再写死

刚才那一个方法太死板了 —— 念什么全写死在函数里，想让三个对象各听各的那一句，就得写三个方法。我们换个写法：在函数簿上先摆一个**空元素**，元素上写个名牌，施展的时候往里放东西。

```python
def greet(name):
    print(f"你好，{name}")

greet("张三")
greet("李四")
```

```text
你好，张三
你好，李四
```

- **`def greet(name):` 里的 `name`** —— 登记函数时先摆出来的空元素。术语表里管它叫**参数（参数）**：它只是「施展时要往这儿放东西」的记号，此刻元素里还是空的。
- **`greet("张三")`** —— 施展时把 `"张三"` 这条数据**传入元素里**。这一趟跑起来，函数里的 `name` 就当作 `"张三"` 用。
- **`greet("李四")`** —— 同一个方法，第二次喂的是 `"李四"`。所以屏幕上多了一行，两行只差名字。
- 函数里的 `name` 是**函数自己内部的叫法**，和你外头建的变量互不打扰：函数跑完，这个元素也就收起来了。

**一次登记，喂什么都行** —— 这才是「打包」最值钱的地方：重复的话只写一遍，剩下的交给传入的数据。

### 好几个元素：按顺序一一对应

要喂两样东西，就在括号里摆两个元素，用逗号隔开：

```python
def show_fish(name, count):
    print(f"{name}今天有 {count} 条数据")

show_fish("张三", 3)
show_fish("李四", 5)
```

```text
张三今天有 3 条数据
李四今天有 5 条数据
```

- 登记时 `(name, count)` 摆了两个元素，施展时就得喂两样，**按顺序一一对应**：第一位传给 `name`，第二位传给 `count`。
- 喂反了会怎样？写 `show_fish(5, "李四")`，解释器**不会拦你** —— 它老实照做，然后印出「5今天有 李四 条数据」这种驴唇不对马嘴的话。元素是照名牌收东西的，它不检查你传入的到底是不是那个意思。
- 少喂一样也不行。我们写好函数，引用的时候却忘了喂名字：

```text
def greet(name):
    print(f"你好，{name}")

greet()
```

解释器当场拦下：

```text
Traceback (most recent call last):
  File "...\main.py", line 4, in <module>
    greet()
TypeError: greet() missing 1 required positional argument: 'name'
```

最后那句翻译过来是：「**这一个方法还缺一样非喂不可的东西，名字叫 `name`。**」喂少了当场断气；喂多了它也照样翻脸。**摆了几个元素，就喂几样 —— 一样不多、一样不少、顺序不错**。

::: tip 提示
传入三句话，抄在函数簿封皮上：

1. **元素摆在小括号里**（`def greet(name):`），名字随你起，函数里都按这个名字叫它。
2. **喂的东西按位置对号入座**：第一位进第一个元素，第二位进第二只元素。
3. **元素的数目就是喂的数目**：少了、多了，解释器都要炸毛。
:::

## 三、`return`：把结果返回

函数不光能干脏活，还能**顺手返回点东西回来**。返回东西用的是 `return`，术语里叫**返回值（返回值）**。

```python
def add_fish(a, b):
    return a + b

total = add_fish(3, 5)
print(total)
print(add_fish(10, 1))
```

```text
8
11
```

- **`return a + b`** —— 函数算完 `3 + 5`，把 `8` **返回**到称呼它的那个地方。
- **`total = add_fish(3, 5)`** —— 调用一次、喂两条数据，函数把 `8` 返回，正好落进 `total` 这个变量。结果和普通的数一样，**能存进变量、能接着算、能传给别的函数**。
- **`print(add_fish(10, 1))`** —— 这一趟调用函数的地方直接就是 `print` 的输入接口，`11` 一被返回就顺手印了出去。

结果还能接着参与运算：

```python
def double(n):
    return n * 2

print(double(3) + double(4))
```

```text
14
```

`double(3)` 返回 `6`，`double(4)` 返回 `8`，两个结果相加得 `14` —— **函数输出的东西，就是一个普普通通的值**，放在哪儿都行。

### 见好就收：`return` 一跑，函数就收工

`return` 除了「返回东西」，还有个脾气：**它一执行，这一个方法当场结束** —— 后面就算还排着活儿，也不干了。

```python
def check(n):
    if n > 0:
        return "还有数据"
    print("这句只在没结果可返回的时候才轮到")
    return "元素空了"

print(check(5))
print(check(0))
```

```text
还有数据
这句只在没结果可返回的时候才轮到
元素空了
```

- 第一次调用 `check(5)`：眼色答「真」，`return` 当场把结果取走，**下面那句 `print` 根本没轮到**。
- 第二次调用 `check(0)`：眼色答「假」，先印那句话，再 `return` 收工。

所以 `return` 还有个别名：**提前收工**。想让它别急着走，就得把 `return` 挪到函数的最末尾。

### `print` 和 `return` 是两回事（今天最扎心的坑）

这两个词长得像、干的活却完全不同，我们把它们摆在一起比一次：

```python
def add_fish(a, b):
    print(a + b)

total = add_fish(3, 5)
print(total)
```

```text
8
None
```

看清楚：第一行 `8` 是函数里那句 `print` 输出的；第二行的 `None` 就蹊跷了 —— `total` 怎么会变成 `None`？

因为这一个方法**只调用了，没返回**。`print(a + b)` 是把结果**输出给主人听**，调用结束就散了；调用函数的那个地方手心里空空的，`total` 自然也装不到东西。Python 给「空手」留了一个专门的记号：`None`，意思是「**这儿什么都没有**」。

所以这三句话的分工是：

- **想让屏幕看见** → 用 `print`。
- **想把结果交回给调用函数的地方接着用** → 用 `return`。
- **两个都想要** → 函数里 `return`，外面再 `print` 一次。

::: tip 提示
今天四样东西，一句话串起来：

**`def` 起手式登记函数 → 报名字带 `()` 施展 → 括号里的空元素接住参数 → `return` 把结果返回调用函数的地方。**

再补一条：没写 `return` 的函数，返回的是 `None` —— 这不是出错，是「我们只干活，不带东西回来」。
:::

| 写什么 | 我们的说法 | 干什么用的 |
|---|---|---|
| `def greet(name):` | 起手式 | 在函数簿上登记一个方法，括号里摆好空元素 |
| `greet("张三")` | 调用一次施展 | 让函数真的跑一遍，括号里喂数据 |
| `name` | 参数 | 函数内部对「传入那样东西」的叫法 |
| `return a + b` | 返回值 | 把结果交回调用函数的地方；不写就是 `None` |
