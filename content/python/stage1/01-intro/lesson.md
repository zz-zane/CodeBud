## 学习目标

本课学习认识 Python 与第一个程序。重点包括Python 是什么、print 你好、解释执行直觉。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## Python 是什么

Python 是一门**编程语言**。它有两个特别讨对象喜欢的性子：

- **短**。同样是「让电脑念一句话」，有的语言要铺床叠被写上好几行，Python 一行就够。
- **随和**。它不逼你先背一大堆规矩，想到什么就写什么，特别适合第一次碰编程的你。

顺便说个冷知识：Python 这个词本来有「蟒蛇」的意思，可它跟蛇一点关系都没有——它这名字是照着人类一个爱讲笑话的喜剧团体起的。所以别怕它咬你 

## 第一个程序：让电脑念一句「你好」

写代码不用什么特别的工具，一行就能开工：

```python
print("你好")
```

```text
你好
```

恭喜！这就是你的第一个程序。别看它只有一行，拆开来看，它是三样东西拼起来的：

1. **`print`** —— 这是**函数的名字**，意思是「把东西输出给我们看」。这个名字要**一个字母都不差**地写对：写成 `prnt`，或者写成中文的「打印」，解释器都不认得。
2. **一对小括号 `( )`** —— 这是**传入的口子**。想让电脑念什么，就把它塞进这对括号里。
3. **一对双引号 `" "`** —— 这是那句话的**边界**。引号里的内容电脑原样输出，而**引号本身不念**。

所以 `print("你好")` 打出来的就是 `你好` 这两个字，前后没有引号。

顺便说一句：光有引号还不行哦——不调用 `print` 这个名字，电脑是不会主动开口念给你听的。**引号负责圈出内容，函数负责开口**，两样缺一不可。

### 漏了引号会怎样

要是写成 `print(你好)`，电脑就不念「你好」了：它会以为 `你好` 是个**名字**，扭头去找「有没有叫这个名字的东西呀」，找了一圈没找着，解释器只好报错给你看。

**加不加引号，就是「一句话」和「一个名字」的分界**——引号里面的是内容，引号本身不是内容。这一条往后天天要用，先记牢。

## 让它念两句：一行一行往下念

想一次念两句，就写两行：

```python
print("你好")
print("示例用户")
```

```text
你好
示例用户
```

电脑是**从上往下一行一行念**的：谁写在前面，谁先出声。把两行的顺序调换一下，输出的顺序也跟着调换。

::: tip 提示
今天记住三件事：**Python 是一门像英语一样好读的编程语言**；**`print("...")` = 让电脑念一念引号里的内容**；**代码一行一行、从上往下执行**。
:::

::: warn 注意
引号里写什么，电脑就原样念什么——哪怕你写的是 `print("1 + 1")`，它也会老老实实输出 `1 + 1` 这几个字，不会替你算成 2 。引号里的是**一句话**，不是一道算式。
:::

## 解释器是怎么干活的：解释执行

电脑只认得 0 和 1，你写的每一行都得由**解释器**翻给它听。这位解释器有两种性子：

- 一种是**先把整本翻完再开演**：把整份代码一口气翻成机器语言，翻完了才交给电脑跑。好处是跑起来快，麻烦是**只要有一个字写错，它一句都不肯跑**，你得整份改完再来。
- 另一种是**解释执行**：读进来一行，翻一行，电脑马上把这一行做掉，再读下一行。

**Python 的解释器属于后面这种**。它的正式名字叫**解释器（解释器）**，而这种「解释执行」的干活方式，我们叫它**解释执行**。

解释执行对新手特别友好：你写一行，它执行一行，哪儿出错也是**当场**告诉你，你能一眼看出是哪一句惹的祸；不像「整本翻完再开演」那样，得等整份查完了才有结果。它还有个脾气要提前知道——它是**一路念下去**的，念到哪一行卡住了，就在那一行停下来，后面的句子就不念了。
