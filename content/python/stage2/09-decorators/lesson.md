## 学习目标

本课学习装饰器。重点包括函数作为对象传递、装饰器与名称重新绑定、转发参数与返回值、常见用途与边界、执行顺序对照。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 函数作为对象传递

Python 函数是对象，可以绑定到名称、作为实参传递并作为返回值。`调用三遍(打招呼)` 传入函数对象，而 `调用三遍(打招呼())` 会先执行打招呼，再传入其返回值。这里定义在模块顶层的是函数，不是实例方法。

```python
def 打招呼():
    print("你好")

def 调用三遍(fn):
    fn()
    fn()
    fn()

调用三遍(打招呼)
```

```text
你好
你好
你好
```

## 装饰器与名称重新绑定

装饰器接收一个可调用对象，并返回用于替代它的对象。`@装饰器` 应用在函数定义完成时，效果相当于 `函数名 = 装饰器(函数名)`；之后调用该名称会调用替代对象。包装函数通过闭包保留被包装函数的引用，不要求外层函数持续运行。

```python
def 加装饰行为(fn):
    def 包装():
        print("【装饰行为：开始】")
        fn()
        print("【装饰行为：结束】")
    return 包装

@加装饰行为
def 打招呼():
    print("你好")

打招呼()
```

```text
【装饰行为：开始】
你好
【装饰行为：结束】
```

## 转发参数与返回值

包装器通常接收 `*args, **kwargs`，把实参与关键字参数转发给原函数，并返回原函数的返回值。忘记 return 会把调用结果变为 None。使用 functools.wraps 可以保留名称、文档等元数据，但不会自动转发返回值。

```python
import functools

def 记一笔(fn):
    @functools.wraps(fn)
    def 包装(*args, **kwargs):
        print(f"要施展的是 {fn.__name__}")
        return fn(*args, **kwargs)
    return 包装

@记一笔
def double(n):
    return n * 2

print(double(3))
print(double.__name__)
```

```text
要施展的是 double
6
double
```

## 常见用途与边界

装饰器可用于日志、计时和权限检查。额外行为不能破坏被包装函数的参数与返回值契约。计时应区分实际测量值与固定示意输出，不能将一次运行的耗时视为所有机器的保证。



## 执行顺序对照

先创建函数对象，再应用装饰器并绑定名称；真正调用时才执行包装函数体。嵌套函数捕获外层绑定形成闭包。区分装饰时与调用时发生的行为，是理解该语法的关键。



## 练习

实现一个记录调用开始与结束的装饰器，保持原函数参数和返回值。用有参数和无参数函数分别验证，再检查 wraps 保留的函数名称。

```python
import functools

def 报时(fn):
    @functools.wraps(fn)
    def 包装(*args, **kwargs):
        print("……计时开始")
        result = fn(*args, **kwargs)
        print("……计时结束")
        return result
    return 包装

@报时
def 加数据(a, b):
    return a + b

print(加数据(2, 3))
```

```text
……计时开始
……计时结束
5
```
