## 学习目标

本课学习函数式编程。重点包括lambda、map、filter、排序 key。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 函数也能当一样东西递出去

先看一件要紧的事：上一课学过的那个「**会下一条的手**」，其实是把「函数」当成普通东西在传。既然函数能传，就能**被塞进别的函数的输入接口**。

先认最短的那个写法：`lambda`。

```python
def 加一(x):
    return x + 1

print(加一(3))
print((lambda x: x + 1)(3))
```

```text
4
4
```

两行都是 `4`，写起来却是两种脾气：

- 上面那个是**有名字的函数**：写一遍，调用一辈子。
- 下面那个是 **`lambda`**：函数**连名字都不起**，就地写、就地施展。它的写法只有三段：`lambda` 开头，冒号前写「传入进来的数据」叫啥（这里是 `x`），冒号后写**要返回的东西**（这里是 `x + 1`）。

注意 `lambda` **不写 `return`**。冒号后面那个式子算出来的结果，就是它要返回值。写成 `lambda x: return x + 1` 会当场报错 —— 它只认一个式子，不认 `return`。

不给名字的函数，也能先绑个名字再用：

```python
加一 = lambda x: x + 1
print(加一(3))
```

```text
4
```

绑了名字它就是一个方法普通的函数，调用和 `def` 写出来的一模一样。那 `lambda` 值钱在哪？值钱在**不用先起名字、可以当场塞进别人的输入接口** —— 下面两节你就看到了。

## `map`：对着每一条都施展同一个方法

```python
数据 = [1, 2, 3]
结果 = map(lambda x: x * 2, 数据)
print(list(结果))
print(list(结果))
```

```text
[2, 4, 6]
[]
```

- `map(一个方法, 一排东西)`：把这一排里每一样**挨个传入那一个方法**，把返回的东西排成新的一排。逗号前是**函数**，逗号后是**一排东西**，顺序别写反。
- `map` **不马上算**。它返回的是上一课讲的那种「**会下一条的手**」—— 你不称呼它就不动。所以要看结果，得用 `list(...)` 把它收进储物柜。
- 第二个 `print` 印出来的是个**空柜子** `[]`，因为那个手**已经被走空了** —— 上一课的规矩在这儿又露面了：一个手只能走一遍。这同时也证明了 `map` 是**要一条算一条**的，不是提前把结果全摆好等着你。

## `filter`：只留下「这一个方法点头」的

```python
数据 = [1, 2, 3, 4, 5]
双数 = filter(lambda x: x % 2 == 0, 数据)
print(list(双数))
```

```text
[2, 4]
```

`filter(一个方法, 一排东西)` 的规矩和 `map` 不一样：它**不换内容**，只做「留还是扔」的决定。每一样都传入那一个方法，**那一个方法点头（答「对」）的留下，摇头的扔掉**。

所以传给 `filter` 的那一个方法，得当个**判官**：只回答「是」或「不是」。上面那个 `lambda x: x % 2 == 0` 问的就是「你除得尽 2 吗」—— 2 和 4 答「是」，1、3、5 答「不是」，于是只剩下 `[2, 4]`。

## 排排坐的规矩：`key=`

```python
数据 = ["哈哈哈", "哈", "哈哈"]
print(sorted(数据, key=len))
```

```text
['哈', '哈哈', '哈哈哈']
```

- `sorted(一排东西)` 就是**排排坐**：默认照着东西本身的大小排。
- `key=` 后面要填的是**一个方法**：排之前，先把每一样传入那一个方法，**拿返回值当排队的依据**。这里填的是 `len`（量长度的那一个方法），于是按「几个字」排。
- 注意 `key=len` 里**没有括号**。写 `key=len()` 是「先把 `len` 调用一遍」——`len` 缺了参数，当场报错；而且就算不报错，塞进去的也成了函数的结果，不是函数本身。**要递函数，不是递函数调用结束的结果。**

`key` 配上 `lambda` 就更厉害了 —— 按「每个对象的岁数」排：

```python
对象 = [("计算机", 3), ("咪爱", 7), ("小狸", 5)]
print(sorted(对象, key=lambda 每个: 每个[1]))
```

```text
[('计算机', 3), ('小狸', 5), ('咪爱', 7)]
```

`每个[1]` 是「这一对的第二样」（编号从 0 起），也就是岁数。`sorted` 拿着岁数去排队，排好之后**整对一起搬**——名字跟着岁数走，不会被拆散。

## 串起来：一边挑一边变

```python
数据 = [1, 2, 3, 4]
结果 = map(lambda x: x * 10, filter(lambda x: x > 2, 数据))
print(list(结果))
```

```text
[30, 40]
```

读法**从里往外**：先让 `filter` 挑出比 2 大的（3、4），再让 `map` 把每个都乘 10。两个都是懒懒的「会下一条的手」，**一直到最后的 `list` 继续调用，它们才一层层动起来**。

**盯住这个次序**：一条数据是**先把两层都走完**，才轮到下一条 —— 不是「先让 `filter` 把四条全挑完，再让 `map` 挨个乘」。所以别拿一把会改变结果的函数塞进 `filter` 那一层，两层是**咬着走**的；而这一切的开关只有一个：最后那个 `list`（或者绕圈）调用不调用。不调用，它们一步都不动。

::: tip 提示
- **`lambda 传入名: 式子`** —— 就地写一个方法、不起名字。式子算出来的就是它返回的东西，**不写 `return`**。
- **`map(一个方法, 一排)`** —— 每一样都喂一遍，返回的排成新的一排。
- **`filter(一个方法, 一排)`** —— 那招点头的留下，摇头的扔掉；所以传入的那招得当判官。
- **`sorted(一排, key=一个方法)`** —— 先传入 `key` 那招，**拿结果当排队依据**；`key=` 后面填函数本身，别加括号。
- `map` 和 `filter` 返回的都是**「会下一条的手」**：要看结果就套 `list(...)`，而且**走过就空了**。
:::

::: warn 注意
- **把 `map` 的结果直接 `print` 出来** —— 屏幕上出现的是一串地址样的东西，不是你要的结果。要 `list(...)` 收一下。
- **在 `lambda` 里写 `return`** —— 当场报错。它只认冒号后面那**一个式子**，写不下第二行。
- **`key=len()` 多加了括号** —— 报错。递的是函数本身，不是函数调用结束的结果。
- **传给 `filter` 的那招忘了当判官** —— 比如写成 `filter(lambda x: x * 2, ...)`，那招返回的是 `4` 这样的数。`filter` 会拿它硬当「对/不对」用：**`0` 算「不对」，别的数一律算「对」**。所以它既不报错、也不是「全凭运气」—— 是**每次都错得一模一样**：我们量过，`[0, 1, 2, 3]` 进去出来的是 `[1, 2, 3]`（只有那个 `0`，因为 `0 * 2 == 0` 被扔掉了），连跑三遍一字不差；`[-1, 0, 1]` 进去出来 `[-1, 1]`。看着像在干活，其实跟你要的「挑出符合条件的」毫无关系。老老实实写 `== 0`、`>` 这种能答「是/不是」的判语才稳。
:::

## 一句话对照表

| 写下的这一句 | 它干了什么 |
|---|---|
| `lambda x: x + 1` | 就地写一个方法，不起名字、不写 `return` |
| `map(一个方法, 一排)` | 每一样都喂一遍，返回「会下一条的手」 |
| `filter(一个方法, 一排)` | 那招点头的留下，摇头的扔掉 |
| `list(map(...))` | 把手上的东西收进储物柜，才看得见 |
| `sorted(一排, key=一个方法)` | 拿那招返回值当排队依据 |
| `key=len` | 递的是函数本身（不加括号） |

## 小任务

我们把会派上用场的一小段先摆好：

```python
数据 = [5, 2, 9, 1]
结果 = sorted(filter(lambda x: x > 2, 数据), key=lambda x: -x)
print(结果)
```

```text
[9, 5]
```

**试着改一改**：

1. 把 `key=lambda x: -x` 整个删掉，只写 `sorted(filter(...))`，跑一遍 —— 结果变成什么样？为什么？
2. 把 `filter` 换成 `map`，看看这一排会变成什么（记得在外面套 `list(...)` ）。
3. 自己写一个 `lambda`，把 `[5, 2, 9, 1]` 里每个数都变成它的两倍，再用 `sorted` 排排坐。

以后我们要教的这类「把函数当数据递来递去」的写法，书上给它起了个名字叫函数式编程（函数传来传去）—— 名字听着唬人，其实就是你今天看到的这几个方法。往后我们要带你去学一套**「按花纹挑东西」**的本事：给我们一个花纹，我们就能从一大串字里把所有对得上的都读取
