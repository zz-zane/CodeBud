## 学习目标

本课学习函数的定义与调用。重点包括函数概念、定义、调用、参数、返回值。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 函数：打包好的一套本领

先把这件事说透。**函数就是一个打包好的动作包**：我们把「做这件事要走的每一步」装进包里，给包起个名字；往后需要它的时候引用名称，包里的动作就按顺序走一遍。

函数替我们省下三样东西：

1. **少写字**：一套动作只写一遍，调用多少次都不用重抄。
2. **改得动**：规矩变了只改包里那一处，所有称呼它的地方一起跟着变。
3. **名字就是说明**：调用 `feed_cat`（处理数据）一看就知道是处理，比一堆散装代码好读多啦。

不过有一件事必须掰清楚，这是零基础最容易含混的地方：**「教」和「调用」是两件事。**

- **教**（定义）：把这一个方法的动作记下来。教的时候，动作**一次都不会执行**。
- **调用**（调用）：真正让这一个方法动起来。

顺序不能反 —— **先教、后调用**。没教过的招，调用了电脑也不认识。

## 教一个方法：`def`

教一个方法的写法长这样（我们先用 Python 给你看，等下四门语言并排对照）：

```python
def greet():
    print("处理完成")
```

一行一行拆开看，每一样都有讲究：

- **`def`** —— 「我们要教一个方法」的起手式。它是英文 define（定义）的前三个字母，写完它，电脑就知道接下来跟着的是一个函数。
- **`greet`** —— 函数名，我们自己起。名字随便起，但得起得让人一看就懂（`greet` 是「打招呼」的意思）。
- **`( )`** —— 输入接口。这一个方法要传入什么，写在里面；现在先空着，表示「这一个方法什么都不用喂」。
- **`:`** —— 冒号，意思是「**接下来缩进里的那几行，全是这一个方法的动作**」。
- **缩进的那一行** —— 函数真正做的动作。缩进一旦取消，函数就结束了；后面顶格写的代码，跟这一个方法再没关系。

现在留意一个现象：**把上面这段敲进去、跑一下，屏幕上一个字都不会出现。**

不是我们敲错了 —— 这段只是「教」，还没「调用」。函数教完就安安静静待在那儿，**不会自己动**。

## 调用一个方法：`greet()`

教完就该调用了。引用的写法简单到不像话：**函数名 + 一对小括号**。

```python
def greet():
    print("处理完成")

greet()
greet()
```

```text
处理完成
处理完成
```

我们调用了两声，屏幕上就出现两行。调用几下就发创建几次 —— 这正是「打包」的意义：`print("处理完成")` 我们**只写了一遍**，却让它发生了两次。

顺带看一眼函数下面那个**空行**：它是给眼睛用的，让「教」和「调用」两段分得清清楚楚。电脑不在乎空行，但读你代码的对象在乎。

::: warn 注意
两个坑，零基础几乎人人踩过：

1. **只教不调用**：写完 `def greet():` 那一段就跑，屏幕上什么都没有 —— 因为函数不会自己动，得另写一行 `greet()` 去称呼它。
2. **引用的时候忘了小括号**：写成 `greet` 只是「提了一句这个名字」，写成 `greet()` 才是「真的称呼它干活」。少了这对小括号，什么都不会发生，而且**它不会报错**——这是最气对象的一种错。
:::

## 传入：把数据传入函数里

上面这一个方法，每次输出的都一样。可我们想让它对不同的对象打招呼 —— 那就在**输入接口**里开个口子：

```python
def greet(name):
    print(name, "处理完成")

greet("学生甲")
greet("计算机")
```

```text
学生甲 处理完成
计算机 处理完成
```

- `def greet(name):` 括号里的 `name`，是**输入接口上的一个占位**。它其实就是函数内部的一个小变量（跟前面学过的「变量」是一个东西）：函数每被调用一次，传入的东西就装进它里面一次。
- 引用的时候，`greet("学生甲")` 括号里的 `"学生甲"` 就是**传入进来的那条数据** —— 术语表里叫它**参数（参数）**。
- 所以第一次调用，`name` 里保存 `"学生甲"`；第二声调用，`name` 里换成了 `"计算机"`。**同一个方法，喂什么就说什么。**

`name` 这个名字也是我们自己起的，叫 `who`、叫 `x` 都行 —— 它只是函数**内部**的叫法，出了这一个方法就没人认得了。

还可以开两个口子，传入两条数据：

```python
def add(a, b):
    print(a + b)

add(3, 4)
```

```text
7
```

`def add(a, b):` 开了两个口子，引用的时候 `add(3, 4)` 就按**顺序对号入座**：第一个传入的 `3` 装进 `a`，第二个 `4` 装进 `b`。顺序要是反了，赋值的东西也就反了，这一条往后要留神。

顺带记一句：`print` 会把逗号隔开的几样东西，**中间垫上一个空格**再印出来。所以 `print(name, "处理完成")` 印出来是 `学生甲 处理完成`，中间那个空格是 `print` 垫的，不是我们打的。

## 返回：`return` 与结果

到目前为止，我们的函数都是「在函数里念一句，念完就完事」。可有些函数的本事不在念，而在**算出一个结果交给我们**。

比如我们要一个方法「把一个数变成两倍」：

```python
def double(n):
    return n * 2

result = double(5)
print(result)
```

```text
10
```

逐行看：

- `return n * 2` —— `return` 是「**把结果返回**」的动作。电脑先算出 `n * 2` 是 10，然后 `return` 把这个 10 **返回出函数**，交回给称呼它的那一行。
- `result = double(5)` —— 调用结束以后，`double(5)` 这个位置**已经变成 10 了**，10 被装进 `result` 这个变量。所以 `print(result)` 印出来是 10。

术语表里管「返回的东西」叫**返回值（返回值）**。记住这个画面：`return` 就是对象把猎物返回你脚边放下 —— **放下的那件东西，就是这一个方法的全部成果**。

### 没有 `return` 会怎样？

这是本课最值得多看两眼的地方。要是把 `return` 换成 `print`：

```python
def double(n):
    print(n * 2)

result = double(5)
print(result)
```

```text
10
None
```

第一行还是 10，因为它真的念了一遍。可第二行冒出来一个 `None` —— 这是 Python 在说「**我们什么也没返回**」。

差别在这儿：

- **`print` 是「在函数里念给屏幕听」**：念完就没了，函数**外面**什么也接不到。
- **`return` 是「把东西返回出函数」**：交给外面那一行，外面接得到。

`result = double(5)` 是想接东西的，可这一个方法从头到尾没返回任何东西，`result` 里就只能是 `None`。

一句话：**想让函数外面拿到东西，用 `return`；只想让屏幕看到，用 `print`。** 两个都想要，就两句都写。

### `return` 还有个脾气

`return` 一执行，**这一个方法就当场结束**，后面就算还排着动作也不做了：

```python
def check(n):
    if n > 0:
        return "还有数据"
    return "处理完成啦"

print(check(3))
print(check(0))
```

```text
还有数据
处理完成啦
```

先认一眼 `if`：它是前面学过的**条件判断** —— 眼色答「真」就走缩进里那条路，答「假」就跳过它。

`check(3)` 进来，眼色 `n > 0` 答「真」，走缩进里那条路，返回 `"还有数据"` —— **这一个方法到此结束**，下面那句 `return "处理完成啦"` 根本没轮到。而 `check(0)` 进来，眼色答「假」，跳过缩进里那句，才轮到下面那句。

这脾气用好了很省事：**把最特殊的情况用 `return` 提前送走，剩下的路就不用再操心了。**

这一趟「跳出去、再跳回来」到底怎么走，我们拆成一步一步给你看：

## 四种语言一起教一个方法

同一个任务：教一个方法 `twice`（传入一个数，把它的两倍返回），再称呼它一次打印出来。四门语言写出来是这样：

```compare
c::
#include <stdio.h>

int twice(int n) {
    return n * 2;
}

int main() {
    printf("%d\n", twice(5));
    return 0;
}

cpp::
#include <iostream>

int twice(int n) {
    return n * 2;
}

int main() {
    std::cout << twice(5) << std::endl;
    return 0;
}

java::
public class Main {
    static int twice(int n) {
        return n * 2;
    }

    public static void main(String[] args) {
        System.out.println(twice(5));
    }
}

python::
def twice(n):
    return n * 2

print(twice(5))
```

```text
10
```

四段骨架一模一样：**起手式 + 名字 + 输入接口 → 函数身体 → 称呼它**。差别在这几处：

- **C / C++ / Java 要先说清「传入什么、返回什么」**：`int twice(int n)` 里，括号**前**的 `int` 是「返回的东西是个整数」，括号**里**的 `int n` 是「传入进来的东西是个整数」。Python 这些统统不写，直接 `def twice(n):` 就完事。
- **函数身体怎么圈起来**：C / C++ / Java 用一对大括号 `{ }`，而且函数末尾那一行要写分号；Python 靠**缩进**圈，末尾不写分号。
- **Java 的函数多挂了一块 `static` 的名称**：因为称呼它的 `main` 自己也挂着这块名称，**挂了同一块名称的对象才能互相调用**。这张名称的来龙去脉，等讲到「类」那一课再细说，今天先照抄就行。
- **称呼它的地方**：C 是 `printf("%d\n", twice(5))`，C++ 是 `std::cout << twice(5)`，Java 是 `System.out.println(twice(5))`，Python 是 `print(twice(5))`。四种语言调用函数的方式各不一样，可骨子里都是同一句话 —— **名字 + 一对小括号，括号里放传入的东西**。

::: tip 提示
本课五句口诀，记牢就够用啦：

1. **函数 = 打包好的一套本领**：写一遍，调用很多遍；改只改一处。
2. **`def` 是教，引用名称是调用**：先教后调用；只教不调用，什么都不会发生。
3. **输入接口在括号里**：`def greet(name):` 的 `name` 是占位，引用的时候把数据传入。
4. **`return` 把结果返回**：想让外面接到东西就写 `return`，只想让屏幕看到就写 `print`。
5. **`return` 一执行，这一个方法就当场结束**。
:::

::: warn 注意
再念一遍最容易踩的两个坑：**只教不调用**（跑完一个字都没有），和**引用的时候忘了小括号**（写成 `greet` 而不是 `greet()`）。

还有一个**很安静**的坑：`return` 忘了写，函数不报错、照样跑完，只是**外面永远接不到东西**（Python 会给你一个 `None`）。函数跑得通 ≠ 函数有用！
:::

## 小任务

来，第一次自己教一个方法：

1. 把 `def double(n):` 那一个方法抄下来，调用一次 `double(7)`，看看打印出什么。
2. 再教一个方法 `add(a, b)`：传入**两个**数，把它们的**和**返回，然后 `print(add(3, 4))`。
3. 想一想：如果把第 2 步里的 `return` 改成 `print`，那一行 `print(add(3, 4))` 会打印出什么？（提示：本课那个 `None` 的例子就是答案。）

下一课，我们要教你怎么跟电脑「一问一答」—— 把数据传入、再把结果返回。去「输入与输出」探险
