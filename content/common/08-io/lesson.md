## 学习目标

本课学习输入与输出。重点包括输入输出概念、命令行交互、结果展示。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

```python
name = "学生甲"
print(name, "处理完成")
```

```text
学生甲 处理完成
```

## 输入与输出：程序的两个口子

程序跟外面的世界打交道，靠的是两个方向的口子：

```text
你敲键盘  ——传入——→  【程序】  ——返回——→  屏幕上出现字
```

- **传入**：东西从**外面**进到程序里。
- **返回**：东西从程序里出来，送到屏幕上给你看。

一进一出这两件事合起来，术语表里给它起的原名是**输入输出（输入与输出）** —— 今天的主角。

「返回」你其实早就会了：`print` 就是它。第一课你就让程序念过「你好，」，那是对象把东西返回你脚边放下。今天要学的是**反过来的那一边 —— 传入**。

能传入进来的东西有很多种：你敲键盘打的字、你点鼠标的位置、别人发来的一条消息、文件里躺着的一整本账……今天我们只讲最要紧、也最常用的那一种：**你敲键盘**。

还有一条现在就得记住，它是新手最容易犯迷糊的地方：**程序会停下来等你。** 代码本来是一路从上往下小跑的，可一跑到输入接口，它就像对象蹲在门口那样**一动不动地等**，一直等到你喂了东西、按下回车，才肯接着往下跑。屏幕上半天没动静 ≠ 程序坏了，它是在等你。

## 命令行交互：`input()` 这个输入接口

Python 里给程序装一个耳朵，引用的是 `input`（英文 input 就是「送进去」的意思）。最小的一问一答长这样：

```python
try:
    name = input("你是谁？")
except EOFError:
    name = "计算机"

print(name)
```

```text
你是谁？计算机
```

拆开看，每一步都有讲究：

- **`input("你是谁？")`** —— 括号里那句是**提示词**：程序先把这句话输出，让你知道它在问什么。
- 调用结束它**不换行**，就张着嘴等 —— 你敲的字会紧跟在问号后面。这就是为什么输出里 `你是谁？` 和 `计算机` 挤在同一行，一个换行都没有。
- 你敲完、按下回车，这一行字就被返回进程序，装进 `name` 这个变量。
- **`print(name)`** —— 再把它念回给你看。

**程序问一句、你答一句，这就是命令行交互。**（「命令行」就是那个等着你敲字的地方：你敲一行，它答一行，一来一往。）

程序在这个输入接口上一停一等，到底是怎么走的？我们把它拆成一步一步，走给你看：


**传入这一路的节奏就这四拍**：先调用提示词 → 蹲下来等你 → 你喂的那行被返回进变量 → 才接着往下跑。中间那一拍**等多久全看你** —— 这就是「程序会停下来等你」。

提示词也可以不写：括号里空着、光秃秃一个 `input()`，它就一次不吭地等，屏幕上什么也不先印出来。

::: warn 注意
你大概正盯着上面那个 `try` 和 `except` 发愣 —— 别看它长得凶，我们给你解释。

编译器或解释器有个脾气：**输入接口空着的时候，它什么都读不到，会当场炸毛**，甩给你一段 `EOFError`（EOF 是「输入接口到头了」的意思），程序就断在半路。在练习场里，**输入框空着就点运行**，你也会看到它。

所以我们给课文里这几段代码都系了一条**保险绳**：

- `try:` —— 先试着做下面那件事。
- `except EOFError:` —— 万一它因为没读到东西炸毛了，就改走这一段：我们提前备好一条备用数据（`name = "计算机"`）。

系上保险绳，这段代码**有没有人喂都能平平安安跑完**。这两行的来龙去脉，等我们讲到「调试」那一课再细说，今天照着抄就行。

反过来说：**你自己写的时候不必系它**。在练习场里跑之前先把输入框填好，直接写 `input("你是谁？")` 也是好的。
:::

### 它返回的是一条字符串，不是数

这是零基础最容易摔的一跤，我们单独拎出来讲。

不管你在输入框里敲的是数字还是字，`input()` **一律当成字符串**返回 —— 就是字符串。你敲的 `3`，赋给变量的是 `"3"`：带引号的一串字，**不是整数变量**。

我们试给你看：

```python
try:
    n = input("喂我们一个数？")
except EOFError:
    n = "3"

print(n + n)
```

```text
喂我们一个数？33
```

我们想要的是 `3 + 3 = 6`，屏幕上却冒出来 `33`。为什么？因为 `n` 里保存的是字符串 `"3"`，而**两串字符串用 `+` 是「接起来」**，不是加起来：`"3"` 接上 `"3"`，就成了一串更长的 `"33"`。

想真的算数，得先把字符串上的数字**摘下来、变成整数变量**。干这件事的函数叫 `int`：

```python
try:
    n = input("喂我们一个数？")
except EOFError:
    n = "3"

print(int(n) + int(n))
```

```text
喂我们一个数？6
```

只改了一处：`n` 外面套了一层 `int(...)`。`int` 是英文 integer（整数）的前三个字母，本事就一句话：**把一串写着数字的字符串，变成一个真正的整数变量**。不套这一层，`+` 就会一直给你接字符串。

引号是这件事的照妖镜：`"3"` 是字符串，`3` 是数 —— 讲变量那一课你就见过这条分界线，屏幕上写 `33` 还是 `6`，差别就在这一对引号上。

::: tip 提示
**`input()` 返回的永远是一串字符串。** 想拿去算数，先 `int(...)` 套一层。

这一跤最难的地方在于：**忘了套，程序不会报错。** 它会欢快地印出一个 `33` 交给你，看着像跑通了，其实是我们接错了。这种「不报错的错」往后还有很多，它就是最典型的那一个。
:::

### 一问一答：程序问几次，你就得喂几次

输入接口用起来的节奏是这样：

```text
【程序】你是谁？          ← 先把提示词输出
（然后张着嘴，一动不动地等）
你传入：计算机            ← 你敲一行、按回车
【程序】计算机              ← 它接着往下跑，把东西返回屏幕上
```

**一次 `input()` 只处理一行。** 程序里写了两处 `input()`，它就要问你两遍，你也得准备两行来喂它。要是它问第二遍的时候输入框里已经没有东西了 —— 又是那段 `EOFError` 。所以我们在点运行之前会先数一数：**这段代码要问几句？**

### 四种语言，各读各的输入

同一件事 —— 「从输入接口读一样东西进来」—— 四门语言的调用方式差得很远：

| 语言 | 读进来引用的是 | 大约长这样（看个形状，不用记） |
|---|---|---|
| C | `scanf` | `scanf("%d", &n);` |
| C++ | `std::cin >>` | `std::cin >> n;` |
| Java | 请一位叫 `Scanner` 的帮手 | `int n = sc.nextInt();` |
| Python | `input()` | `n = input()` |

今天你只要认牢最下面那一行：**Python 读一样东西进来，一个 `input()` 就够**。另外三个，等我们带你学具体语言那几课，再一个一个认。

### 在练习场里，输入接口在哪儿？

打开「**▶️ 运行代码**」这一页，工具栏上有一个框，上面写着「**程序要你输入什么吗？（不需要就留空）**」—— 那个框就是输入接口。要喂的东西写在里面，点运行，程序里的 `input()` 就会把那一行取走。它问几句，你就喂几行；多喂的它不处理。

## 结果展示：把返回的东西念得漂亮

「返回」这件事你在第一课就会了：`print`。可一旦有了传入，**展示**就有了新的讲究 —— 我们得把「你说的话」和「我们要说的话」拼成一句，念给你看。拼法有两种，看清楚这两种的差别：

```python
name = "学生甲"
print("你好，", name, "")
print("你好，" + name + "")
```

```text
你好， 学生甲 
你好，学生甲
```

- **逗号拼法**（第一行）：`print` 会把逗号隔开的每样东西**各垫上一个空格**再印出来 —— 这条规矩你在循环那一课就见过。所以屏幕上多出来两个空格：`你好， 学生甲 `。
- **加号拼法**（第二行）：`+` 的本事是「把两串字符串**接**成一串」（刚才那个 `33` 就是它干的）。它只管接，**不管垫空格** —— 缝要留多宽，得你自己把空格写进引号里。写紧了，出来就是 `你好，学生甲`。

另外还有一件小事值得亲眼看看：上面两句 `print` 打出了**两行**字。**一句 `print` 管一行** —— 你想分几行念，就写几句 `print`。

哪种拼法好？看你要什么：**想让东西之间留缝，用逗号；想让它们贴紧，用加号。** 拿不准就先用逗号 —— 它是 `print` 自己带的规矩，不容易写错。

::: tip 提示
「输入与输出」这一课，记住三句话就够用啦：

1. **传入 = 东西进来，返回 = 东西出去**；程序跑到输入接口会**停下来等你**。
2. **`input()` 读一行，返回的永远是一串字符串** —— 要算数，先 `int(...)`。
3. **逗号垫空格，加号贴紧**；一句 `print` 管一行。
:::

## 四种语言一起报菜名

同一个任务：把「学生甲」和它当前记录的 `3` 条数据，拼成一行 `学生甲 当前记录了 3 条数据` 返回屏幕上。

```compare
c::
#include <stdio.h>

int main() {
    printf("%s 当前记录了 %d 条数据\n", "学生甲", 3);
    return 0;
}

cpp::
#include <iostream>
#include <string>

int main() {
    std::string name = "学生甲";
    int fish = 3;
    std::cout << name << " 当前记录了 " << fish << " 条数据" << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        String name = "学生甲";
        int fish = 3;
        System.out.println(name + " 当前记录了 " + fish + " 条数据");
    }
}

python::
name = "学生甲"
fish = 3
print(name, "当前记录了", fish, "条数据")
```

```text
学生甲 当前记录了 3 条数据
```

同一句话，四种语言调用方式各不相同：

- **C**：`printf` 靠**占位符** —— `%s` 的位置留给字符串，`%d` 的位置留给一个整数，后面的东西**按顺序对号入座**。行尾的 `\n` 是「换行」，C 得自己写上，不写就全挤在一行里。
- **C++**：`std::cout << 一样 << 另一样` —— 顺着一个个丢到屏幕上。
- **Java**：`System.out.println(name + " 当前记录了 " + fish + " 条数据")` —— Java 靠 `+` 把它们串成一整句再印。
- **Python**：`print(name, "当前记录了", fish, "条数据")` —— 逗号隔开，每个逗号的位置自动垫一个空格。

看出门道了吗？**Python 那句里的空格是逗号垫出来的，另外三个是我们自己写进引号里的** —— 可拼出来的句子一模一样。这就是「气质不同，做的都是同一件事」。
