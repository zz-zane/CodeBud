## 顺序执行：输入、计算、保存与输出

程序按控制流执行语句。下面用四个步骤把输入的整数加一，再输出结果；每一步都依赖前一步产生的值。

```text
1. 读取输入 input_value
2. 计算 input_value + 1
3. 将计算结果保存到 result
4. 输出 result
```

```demo

| 计算 input_value + 1
| 将计算结果保存到 result
| 输出 result

step 执行前
at: 1
say: 程序尚未读取输入。示例假定用户接下来输入整数 3；计算和输出都还没有发生。
meow: 尚未读取输入。
pose: expect

result = 未赋值

at: 1
say: 读取用户输入的整数 3，并保存为 input_value。后续计算使用这个值。
meow: input_value 的值为 3。
pose: busy
input_value = 3
result = 未赋值
标准输出 = 无

step 第 2 步：执行计算

say: 读取 input_value 的值 3，计算 3 + 1，得到临时计算结果 4。此时 result 尚未赋值。
meow: 计算结果为 4。

input_value = 3
计算结果 = 4
result = 未赋值
标准输出 = 无

step 第 3 步：保存结果

input_value = 3
result = 4
标准输出 = 无

at: 4

meow: 四个步骤已执行完成。
pose: proud
input_value = 3
result = 4
标准输出 = 4
```

## 电脑只懂 0 和 1，怎么办？

处理器执行机器指令；程序设计语言提供更便于人编写和阅读的表达方式，工具链负责转换和执行。

于是人类发明了**编程语言**——长得像英语，写起来舒服多啦。可电脑读不懂代码呀！这时候**编译器（编译器或解释器）**出场：你写好代码，它负责翻成电脑能听懂的机器语言。还有一种**解释器（编译器或解释器）**，边读代码边马上执行。

记住分工：**你负责写代码，编译器或解释器负责传话，电脑负责干活。** 以后学 C、C++、Java、Python，天天打交道

## 标准术语与执行路径

变量关联值，函数组织可调用的操作，条件判断和循环控制执行流程。类定义对象的共同状态与行为，对象则是具体实例。后文统一使用这些标准名称。

**编译路径**：编译器把源代码转换为目标代码或其他中间表示。例如 C/C++ 通常经过编译、链接得到可执行程序；Java 的 javac 生成字节码，再由 JVM 执行。

**解释路径**：解释器执行源代码或中间表示。以 CPython 为例，源代码通常先编译为字节码，再由解释器执行；因此“解释执行”不等于每读一行源码就直接翻译一行，也不等于完全没有编译阶段。

不同实现还可能使用即时编译。应分别理解语言语法、编译器、解释器和运行时，而不是把它们当作同一种工具的不同名字。

## 四种语言一起说「你好」

同一个「打印你好」的小任务，四种语言写出来长这样，只需要看个眼熟、感受下气质，不用背

```compare
c::
#include <stdio.h>

int main() {
    printf("你好，世界！\n");
    return 0;
}

cpp::
#include <iostream>

int main() {
    std::cout << "你好，世界！" << std::endl;
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        System.out.println("你好，世界！");
    }
}

python::
print("你好，世界！")
```

瞧，Python 一行就搞定，C 语言需要声明入口函数等结构。气质不同，做的都是同一件事——**打印一句话**。

## 使用 print 输出字符串

Python 的 `print` 函数把传入的值输出到标准输出。下面的调用传入字符串“你好”，并在输出后换行：

```python
print("你好")
```

```text
你好
```

`print` 是函数名，小括号表示调用，括号中的表达式提供实参。双引号界定字符串字面量，引号本身不属于字符串内容，因此输出中没有双引号。

`print("你好")` 与 `print(message)` 的含义不同：前者直接传入字符串，后者读取变量 `message` 的值。后者要求该名称事先已经定义，否则 Python 会报告 `NameError`。

::: tip 提示
编程是用程序设计语言表达可执行的处理步骤。源代码通过相应工具链转换和执行；编译器与解释器承担不同职责。
:::
