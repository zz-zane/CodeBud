## 学习目标

本课学习算法与问题分解。重点包括什么是算法、顺序/选择/循环结构、生活例子。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 什么是算法：三步曲

我们把算法叫「解决一个问题的三步曲」，说穿了就三句话：

1. **看清楚要什么** —— 我们到底要什么结果？「十只元素里，每个都有一条数据」。
2. **把过程拆成一步步** —— 每一步都小到不用动脑子：「走到元素边」「抓一把」「放进元素里」。
3. **照着顺序走一遍** —— 一步接一步，不跳步、不回头。

所以**算法不是代码**。它是「这件事到底该怎么办」的想法。想法可以先在我们脑子里跑一遍，跑通了，再让编译器或解释器把它翻成某门语言写下来。同一张清单，写成 C、C++、Java、Python 都行 —— **清单本身还是同一张**，只是四位编译器或解释器输出的腔调不一样。

## 三种基本身法

天底下千变万化的算法，拆到最细，都逃不出三种身法：**一步接一步**、**条件判断**、**循环**。

### 一、一步接一步（顺序）

最老实的一种：从上往下，一步接一步。我们煮对象饭就是这样：

```python
bowl = "学生甲的元素"
fish = 3
print(bowl, "里放了", fish, "条数据")
```

```text
学生甲的元素 里放了 3 条数据
```

三行代码，三件事，顺序**不能换**：先把元素的名字放进变量，念的时候才调用得出来它；`print` 里逗号的位置会各垫一个空格，所以中间那几个空格是 `print` 自己加的，不是我们手滑。要是把最后那句提到最前面，编译器或解释器就会当场犯难 —— 因为那时候 `bowl` 这个变量还没建起来。

### 二、条件判断（选择）

有时候一件事得**先看一眼情况**再决定做不做：元素里的数据够不够处理？

```python
fish = 2
if fish >= 3:
    print("够处理啦")
else:
    print("再添一点")
```

```text
再添一点
```

`if` 后面跟一句「条件」，读作「**如果**……」。条件成立，走它下面那条路；不成立，走 `else`（否则）那条路。术语表里给这种「看一眼再决定」的身法起的原名是**条件判断**：条件满足了才动手，不满足就换一条路走。

### 三、循环（重复）

十个对象的元素，我们总不能把处理数据那句话抄十遍 —— 那就让同一套动作**绕着数据跑圈**，一遍又一遍：

```python
fish = [3, 1, 4]
total = 0
for n in fish:
    total = total + n
print(total)
```

```text
8
```

`for n in fish:` 读作「**把这一排元素里的每一元素，挨个儿交给 `n`**」：第一圈 `n` 是 3，第二圈是 1，第三圈是 4。`total = total + n` 每跑一圈，就把当前这一元素攒进 `total` 这个变量中 —— 三圈跑完，`total` 是 8。

绕圈的好处写在脸上：**这套动作我们只写了一遍，剩下的重复全交给电脑自己去跑。** 这一手在术语表里的原名是**循环**。往后我们说「跑圈」，说的就是它。

## 生活里的三个小算法

算法一点也不神秘，我们一天里能撞见好几个：

- **穿鞋**：先穿袜子、再穿鞋、最后站起来 —— 这是**一步接一步**。袜子穿在鞋外面？听着就好笑，谁都知道这一步的顺序换不得。
- **分数据**：走到每个对象的元素边看一眼 —— 元素里还有就不动，空了就添一条。这里既有**条件判断**，也有**循环**（十只元素，挨个儿走一遍）。
- **找最大的一条**：一整排数据里，哪一条最肥？我们先拿起第一条当「目前最肥的」，再挨个儿比过去：比它肥的，就换成新的一条；比它瘦的，放过。整排走完，手里那条就是最肥的。

最后那个「找最大」值得写成代码看一遍：

```python
fish = [3, 1, 4, 1, 5]
biggest = fish[0]
for n in fish:
    if n > biggest:
        biggest = n
print(biggest)
```

```text
5
```

`fish[0]` 是第一元素 —— 编号从 0 起，这是我们在「数组」那一课讲过的规矩。`biggest` 先抱住第一元素当「目前最肥的」，然后绕着整排跑圈：**只有**当 `n` 比手里的还大（`n > biggest`）才换新的。三种身法全在这几行里：顺序、条件判断、循环，一样都不少。

::: tip 提示
拿到一件事，先别急着敲代码，照三步曲问自己三句话：

1. **我们要的结果是什么？**
2. **分几步？每一步都清楚到不用动脑子吗？**
3. **哪一步要看情况？哪一步要重复？**

把这三句答完，代码几乎就自己长出来了。
:::

::: warn 注意
算法对了、代码写歪了，跑出来的不是你要的东西；反过来，代码写得再花哨，算法错了，跑得再顺也是白跑。**先在我们脑子里把清单跑一遍，再动手敲代码** —— 这一条能替你省下一半的返工。

还有一个小地方别栽跟头：`for n in fish:` 是从**第一元素**开始跑的，可编号是从 0 起的。别把「第一圈」和「编号 0」对错了位。
:::

## 四位编译器或解释器，同一张清单

同一个算法：一排三元素数据，**挨个儿看一遍** —— 够 3 条就调用「够处理啦」，不够就调用「再添一点」。四位编译器或解释器写出来长这样，看个眼熟就行：

```compare
c::
#include <stdio.h>

int main() {
    int fish[3] = {3, 1, 4};
    for (int i = 0; i < 3; i++) {
        if (fish[i] >= 3) {
            printf("第 %d 元素：够处理啦\n", i + 1);
        } else {
            printf("第 %d 元素：再添一点\n", i + 1);
        }
    }
    return 0;
}

cpp::
#include <iostream>

int main() {
    int fish[3] = {3, 1, 4};
    for (int i = 0; i < 3; i++) {
        if (fish[i] >= 3) {
            std::cout << "第 " << i + 1 << " 元素：够处理啦" << std::endl;
        } else {
            std::cout << "第 " << i + 1 << " 元素：再添一点" << std::endl;
        }
    }
    return 0;
}

java::
public class Main {
    public static void main(String[] args) {
        int[] fish = {3, 1, 4};
        for (int i = 0; i < 3; i++) {
            if (fish[i] >= 3) {
                System.out.println("第 " + (i + 1) + " 元素：够处理啦");
            } else {
                System.out.println("第 " + (i + 1) + " 元素：再添一点");
            }
        }
    }
}

python::
fish = [3, 1, 4]
for i in range(3):
    if fish[i] >= 3:
        print(f"第 {i + 1} 元素：够处理啦")
    else:
        print(f"第 {i + 1} 元素：再添一点")
```

```text
第 1 元素：够处理啦
第 2 元素：再添一点
第 3 元素：够处理啦
```

一眼就能看出门道：**三位编译器或解释器的「数到第几元素」是靠自己加出来的**（C 和 C++ 写 `i + 1`，Java 写 `(i + 1)`），Python 干脆把算式塞进句子里；可四段跑出来的结果**一个字都不差**。

这就是三步曲最让人安心的地方：**想法是同一张清单，写法各有各的脾气**。往后我们带你学某一门语言的时候，你会发现真正难的不是语法，而是「这件事到底该怎么一步步做」。

## 小任务

今天的小任务，不用碰键盘也能做一半：

1. 挑一件事写一张清单 —— 比如「我们怎么给三个对象分数据」。写的时候数一数：哪几步是**一步接一步**？哪一步在**条件判断**？哪一步在**循环**？
2. 再把课文里那段「找最大」的代码抄进练习场，跑一遍。然后把 `n > biggest` 改成 `n < biggest`，再跑一次 —— 猜猜它现在找的是什么？
3. 最后一问：如果把 `biggest = fish[0]` 改成 `biggest = 0`，那段代码还能找到 5 吗？（提示：想想 `fish` 里全是正数时会怎样。）
