## 学习目标

本课学习构造函数与析构函数。重点包括一个类定义看完整个对象的一生、构造函数：创建对象那刻自动跑、析构函数：走时自动收、三个高频写错当场诊断、最后一块路牌：复刻一个对象。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一个类定义，看完整个对象的一生

先整个看一遍。我们的对象这回身上多带一样东西：一间**现租的零食变量**（上一课的老朋友 —— 搬家时租、走时还的那间）：

```cpp
#include <iostream>
#include <string>
using namespace std;

class Cat {
    string name;      // 名字格
    int* snacks;      // 一张指针，指着那间现租的变量
public:
    Cat(string n, int s) : name(n), snacks(new int(s)) {
        cout << name << " 初始化啦，租好一间零食变量" << endl;
    }
    ~Cat() {
        delete snacks;
        cout << name << " 走啦，变量还回去" << endl;
    }
};

int main() {
    Cat c1("张三", 3);
    return 0;
}
```

```text
张三 初始化啦，租好一间零食变量
张三 走啦，变量还回去
```

**两行字都不是 `main` 里输出的**：第一行是初始化那一个方法自己印的（第 19 行创建对象那一刻），第二行是离开那一个方法自己印的（`main` 走到头那一刻）。类定义上多出来的 `Cat(...)` 和 `~Cat()`，就是上一课我们说的「自己会跑的两招」。

下面把两招拆开，一个方法一个方法看。

## 构造函数：创建对象那一刻自动跑的那一个方法

类定义里那个**跟类定义同名**的函数（类定义叫 `Cat`，它就叫 `Cat`），就是构造函数。它有三条认领暗号：

1. **名字跟类定义一个字都不差。** 这是它唯一的名字 —— 编译器或解释器就靠这一条认出「这个函数是初始化那一刻要跑的规矩」。
2. **脑袋上不写返回什么。** 看它的开头 `Cat(string n, int s)` —— 前面**不写** `void`、不写 `int`，光秃秃一个名字。创建对象不是称呼它去干活，压根没有「返回什么」这回事。
3. **创建对象那一刻自己跑。** `Cat c1("张三", 3);` 这一行里，实例一落地，它**当场跑了一遍** —— 我们一个字都没称呼它。

它脑袋后面还跟着一小段：`: name(n), snacks(new int(s))` —— 这叫**初始化列表（初始化列表）**，念作「用 `n` 装 `name`、用 `new int(s)` 装 `snacks`」。清单干两件事：

- 它在**大括号里那几行之前**就执行：实例落地的瞬间，格子**已经装好了**，不是先进门再收拾；
- 「顺手要办的事」也能在清单里一次办完 —— `snacks(new int(s))` 就是当场现租一个变量、把 `s` 放进去。

同一个类定义上，构造函数还可以**挂好几套**：`Cat()` 不带料、`Cat(string n)` 只带名字、`Cat(string n, int s)` 两样都带。编译器或解释器看你喂了几样料、喂的是什么，挑对得上的那一套跑 —— 这就是行话里的**同名多招（重载）**，这套本事往后语言线会专门讲；今天先认它在类定义上管「怎么初始化」的这一面。

## 析构函数：走的时候自动收的那一趟

给类定义再添一笔 —— 函数名前面多一个小波浪号 `~`：`~Cat()`。它跟构造函数是成对的：

- **名字 = `~` + 类定义名**，脑袋上同样不写返回什么；
- 它干的活是**把借来的东西还回去**：`delete snacks` —— 上一课 `free` 的接班活，就落在这里。

**它什么时候跑？** 两个时刻，全是自动的：

- 对象**走出它所在的那对大括号**时 —— 函数的、`main` 的，凡是括住它的那对括号，说到就到；
- 对 `new` 出来的那个对象，调用 `delete` 的时候。

还有一条不太起眼的规矩：同一段里养了一组对象，收尾的次序是**倒着的** —— 最后创建后的，最先走。像栈，最后放上去的那个，最先被拿走。

对象身上要是没借着东西，这一个方法可以整个不写（编译器或解释器送你一个空的）。可只要像现在这样 —— 对象手里捏着租来的变量，**这一个方法就非写不可**：不写它，编译器或解释器不会报错，变量就静静地漏在外面，账再也收不回来。

## 三个高频写错，当场诊断

**错法一：给构造函数脑袋上写个返回类型。**
有人想：别的函数脑袋上都写个返回什么，我们写一个总没错吧 —— 于是写下 `void Cat(string n)`。编译器或解释器当场拦下：

```text
error: return type specification for constructor invalid
```

念作：**「构造函数头上不许写返回什么。」** 把脑袋上多出来的那一截（`void`、`int`，什么都一样）删掉，它就好了。

**错法二：`name = name;` 原地打转。**
把初始化列表换成状态里那几行，有人会这么写：

```cpp
#include <string>
using namespace std;

class Cat {
    string name;      // 名字格
public:
    Cat(string name) {
        name = name;     // 两边的 name 都指传入的料
    }
};
```

这一句里，**左右两边的 `name` 都指传入的那份料** —— 料自己给自己让了一圈，格子从头到尾没人管，名字格里最后是**空的**。两种解法：

- **走初始化列表**：`Cat(string n) : name(n) {}` —— 本课主推，名字和料分开写，一眼分得清；
- **点名「这一个自己的」格子**：C++ 写 `this->name = name;`，Java 写 `this.name = name;`。

顺带说一个轻的：没有同名冲突的时候，`this.m(5);` 和 `m(5);` 跑的是同一件事 —— 带上 `this.` 只是啰嗦一点。它只在「料和格子同名」这种场合非写不可。

**错法三：忘了析构函数。**
上一课说「`malloc` 租的变量，`free` 不能忘」；这一课接上：变量是在构造函数里租的，就得在析构函数里还。漏了它，变量和账一起飘在外面 —— 编译器或解释器一次不响，这才是最咬人的地方。

## 最后一块路牌：复刻一个对象

临走前我们立一块路牌，先别往前走：

```cpp
Cat a("张三", 3);
Cat b = a;      // 照 a 的样子复刻一个 b：你写的那套构造函数一次都没跑
```

`b` 的名字是复制来的；可那张**指针也被复印了一份** —— 现在张三和它的复刻，保存**同一名称**。走的时候析构函数各跑一次：**同一名称被还回去两遍**，程序当场翻脸（有时直接崩，有时是更隐蔽的坏账）。

这坑只咬「手里捏着租来东西」的对象 —— 两个各自租各自的变量，什么事都没有。复刻这一族的事，往后 **C++ 那一线**有专门一课收它，今天把路牌立在这儿就够了。

## 四位编译器或解释器，同一个对象

同一件事：创建一个对象，传入名字和零食数；**初始化那一刻印一行，再报一报它的零食数**。四段跑下来，屏幕上都是同样两行。

```compare
c::
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    char name[20];
    int* snacks;                    /* 一张指针：指着现租的变量 */
} Cat;

void cat_init(Cat* c, const char* name, int s) {   /* 手写的「初始化那一个方法」 */
    strcpy(c->name, name);
    c->snacks = (int*)malloc(sizeof(int));         /* 现租一个变量 */
    *(c->snacks) = s;
}

void cat_destroy(Cat* c) {                         /* 手写的「收尾那一个方法」 */
    free(c->snacks);                               /* 把变量还回去 */
}

int main(void) {
    Cat c;
    cat_init(&c, "张三", 3);
    printf("%s 初始化啦\n", c.name);                 /* 「初始化啦」这一行也得自己调用 */
    printf("%s 的零食：%d 条\n", c.name, *(c.snacks));
    cat_destroy(&c);                               /* 忘了这一句，变量就漏了 */
    return 0;
}

cpp::
#include <iostream>
#include <string>
using namespace std;

class Cat {
    string name;
    int* snacks;

public:
    Cat(string n, int s) : name(n), snacks(new int(s)) {
        cout << name << " 初始化啦" << endl;
    }
    ~Cat() {
        delete snacks;              // 走的时候自己把变量还回去（这一个方法没印字）
    }
    void show() const {
        cout << name << " 的零食：" << *snacks << " 条" << endl;
    }
};

int main() {
    Cat c("张三", 3);
    c.show();
    return 0;
}

java::
class Cat {
    String name;
    int snacks;

    Cat(String name, int snacks) {          // 构造函数：跟类定义同名、不写返回
        this.name = name;
        this.snacks = snacks;
        System.out.println(this.name + " 初始化啦");
    }

    void show() {
        System.out.println(this.name + " 的零食：" + this.snacks + " 条");
    }
}

public class Main {
    public static void main(String[] args) {
        Cat c = new Cat("张三", 3);
        c.show();
    }
}

python::
class Cat:
    def __init__(self, name, snacks):
        self.name = name
        self.snacks = snacks
        print(f"{self.name} 初始化啦")

cat = Cat("张三", 3)
print(f"{cat.name} 的零食：{cat.snacks} 条")
```

```text
张三 初始化啦
张三 的零食：3 条
```

看出来了吗：**同一件事，四位的手势差得可不小**。

- **C**：构造函数、析构函数，**C 里一样都没有** —— 只好手写两招站在类定义外面：`cat_init` 管初始化（抄名字、现租变量），`cat_destroy` 管收尾（还变量）。要命的一条：这两句**都得自己记得调用**，连「初始化啦」那一行也是手写的；漏了 `cat_destroy`，变量就漏在外面。
- **C++**：构造函数跟类定义同名、脑袋上光秃秃，创建对象那一刻自己跑 —— 屏幕第一行就是它印的；析构函数多个 `~`，走的时候自己把变量还了。这段还多一手 C 没有的本事：构造函数能挂好几套、看料挑一套。
- **Java**：Java 管它叫**构造方法**，照样跟类定义同名、不写返回，`new` 那一刻自己跑；`this` 就是「这一个」（写 `this.name = name` 用的）。收尾那一个方法 Java **没有** —— 走的时候交给垃圾回收器（GC），不用谁写「还变量」。
- **Python**：初始化那一刻自动跑的是 `__init__`（前后各两条下划线，一共四个）；收尾同样不写，也归垃圾回收器管。

一句话总结：**初始化那一个方法 —— C 手写，另外三位都画在类定义上；收尾那一个方法 —— 只有 C++ 会自己跑**，C 靠你记性，Java/Python 交给清理官。

今天记住三句话：

1. **构造函数（构造函数）**：跟类定义同名、脑袋上不写返回什么，创建对象那一刻**自己跑**；初始化列表在大括号之前把格子装好，顺手要办的事（比如租变量）也能在清单里一次办完。
2. **析构函数（析构函数）**：名字是 `~` + 类定义名，走出大括号、或在 `delete` 那一刻**自己跑**，把借来的还回去；同一段里几个对象，倒着收。
3. **一句话分家**：初始化那一个方法 —— C 手写、另外三位画在类定义上；收尾那一个方法 —— 只有 C++ 会自己跑，C 靠你记性，Java/Python 有垃圾回收器。
:::

::: warn 注意
三个坑，我们标出来：

- **构造函数头上别写返回类型**：`void Cat(...)` 会被编译器或解释器当场拦下，把脑袋上多出来的那截删掉就好。
- **`name = name;` 是原地打转**：料和格子同名时，要么走初始化列表，要么点名「这一个」（`this->` / `this.`）。
- **复刻一个带变量的对象会出事**：名称被复印一份，两个对象保存同一名称，还的时候还两遍 —— 本课只立了路牌，别急着往里走。
:::

| `name = name;` | 写坏的构造函数：两边都指传入的料，格子原地打转 |
| `Cat b = a;` | 复刻一个：名称被复印，两个对象保存同一名称（C++ 线专门一课收它） |
