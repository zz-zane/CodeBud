## 学习目标

本课学习指针、引用与输出参数。重点包括老手艺：递名称改外面的元素、接班人上台：名字挂上、一个元素挂两个名字、拿四个问题量一量、老手艺还有用吗。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 老手艺：递名称进去，改外面那个元素

要办的活叫「对调」：两个元素，一个保存 3、另一个保存 8，让它们换个位置住。老手艺在 C 里长这样：

```c
#include <stdio.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main(void) {
    int x = 3;
    int y = 8;
    swap(&x, &y);
    printf("%d %d\n", x, y);
    return 0;
}
```

```text
8 3
```

屏幕上是 `8 3` —— 外面的两个元素**真的换过位置**。凭什么？我们把三处关键动作拆开看：

- **引用的地方写 `swap(&x, &y)`** —— 递进去的不是 3 和 8 这两个数，是这两个元素的**地址**，写在一张「指针」上；
- **函数头上写 `int *a, int *b`** —— 收下两块名称，`a`、`b` 是两块名称的名字；
- **函数里写 `*a`、`*b`** —— 星号读作「顺着名称走」：跑到名称指着的那个元素跟前去。

于是 `*a = *b;` 这一句，就是把 `b` 指着的那个元素里的数，倒进 `a` 指着的那个元素 —— 两块名称都指着**外面**的元素。函数关上门、名称还回去，外面的数已经换了地方。老手艺的本事，一句话：**我们不搬元素，我们隔着名称摸到你的元素**。

`swap` 的 `a`、`b` 就是这样的料：递进去，专门把结果**写回外面** —— 这类料，书上有名字叫**输出参数（写回外面的料）**。今天接班人要接的，就是这类活。

## 接班人上台：名称撤了，名字挂上

同样两个元素、同一件活。接班人写成这样：

```cpp
#include <iostream>
using namespace std;

void swap(int& a, int& b) {
    int t = a;
    a = b;
    b = t;
}

int main() {
    int x = 3;
    int y = 8;
    swap(x, y);
    cout << x << " " << y << endl;
    return 0;
}
```

```text
8 3
```

屏幕上一模一样，也是 `8 3`。可你数一数记号 —— 三处全变了：

- **引用的地方**：`swap(x, y)` —— 光写名字，`&` 没了；
- **函数头上**：`int& a` —— 多出来一个 `&`，粘在**类型**后面、不在名字前面（`int&` 读作「int 元素的又一个名字」）；
- **函数里**：`a = b;` —— 星号没了。

它不是把名称换个写法 —— 它是**把名称整个撤了**。`int& a` 的意思：不摆新元素、不记地址 —— **外面那个元素，进了这招函数就叫 `a`**。

这门本事，术语表里跟老手艺挤在同一行，我们就照它的大名称呼它：**引用（指针的温柔版）** —— 给同一个元素**再挂一个名字**。

名字挂上去，有三条规矩，今天就得背下来：

1. **挂名字的时刻，是函数开张那一刻**：`swap(x, y)` 一调用，`a` 当场挂到 `x` 上、`b` 挂到 `y` 上；
2. **挂上就不换**：这条函数里，`a` 永远指 `x` —— 术语里叫「从一而终」；
3. **函数关上门，名字当场消失**：`a`、`b` 是函数里的名字；元素还是那两个元素，数留在元素里。

老手艺递的是名称，接班人挂的是名字 —— 一条「指过去」，一条「叫它一次」。差别看着小，用起来差得远，往下看。

## 先在平地上走两步：给一个元素挂两个名字

先别忙着用它接活。我们在平地上走两步给你看 —— 数数看：这段代码一共摆了几个元素？

```cpp
#include <iostream>
using namespace std;

int main() {
    int fish = 3;
    int& other = fish;      // other 是 fish 的另一个名字
    other = 10;             // 改 other，就是改 fish
    cout << fish << endl;
    cout << other << endl;

    int cat = 7;
    other = cat;
    cout << fish << endl;
    cout << cat << endl;
    return 0;
}
```

```text
10
10
7
7
```

逐行过一遍：

- **`int fish = 3;`** —— 摆一个元素 `fish`，装 3；
- **`int& other = fish;`** —— 给 `fish` **再挂一个名字** `other`。没有新元素 —— 到这儿一共还是**一个**元素；
- **`other = 10;`** —— 往 `other` 里倒 10，倒的**就是** `fish`。两条 `cout` 全印 10 —— 不是巧合，是同一个元素；
- **`int cat = 7;`** —— 这时候才摆出**第二只**元素；
- **`other = cat;`** —— 这一句最容易看走眼：它**不是**让 `other` 改挂到 `cat` 上，而是把 `cat` 里的 7 **抄进** `other`（也就是 `fish`）。收工一数：`fish` 变成 7；`cat` 自己的 7，一动没动；
- 所以后两行印出来是 `7` 和 `7`。

`other = cat;` 这一句的教训记好：**名字挂上就摘不下来**。`=` 用在名字身上只有一个意思：把右边的数，倒进它挂着的那个元素。

## 像不像？拿四个问题量一量

接班人和老手艺，到底是像还是不像？我们拿四个问题挨个量：

| 我们问的 | 老手艺（指针） | 温柔版（引用） |
|---|---|---|
| 能不能先空着，回头再挂 | 能。名称可以先不指任何元素（`int *p = NULL;`），找着元素再说 | 不能。名字挂不上就开不了张 —— `int& r;` 编译器或解释器当场拦下 |
| 能不能半路改挂别的元素 | 能。名称上的地址，说换就换 | 不能。从一而终，挂上就锁死 |
| 平时用着要记号吗 | 要。引用的地方写 `&`，函数头上、函数里写 `*` —— 缺一处都不行 | 不要。调用 `swap(x, y)`，函数里照常写名字 |
| 能不能沿着一排元素走过去 | 能。名称加一，往后再跨**一整只元素**的身位 | 不能。名字只认挂上的那一个元素，挪不动 |

四个问题问完，接班人像不像，心里就有数了。

## 四位编译器或解释器，同一件活

3 和 8 对调，四位编译器或解释器各交一份答卷，摆一桌 —— 重点看**每段是怎么改到外面的**：

```compare

    a = b;
    b = t;
}

    int x = 3;
    int y = 8;

    cout << x << " " << y << endl;

java::
public class Main {
    static void swap(int[] pair) {
        int t = pair[0];
        pair[0] = pair[1];
        pair[1] = t;
    }

    public static void main(String[] args) {
        int[] pair = {3, 8};
        swap(pair);
        System.out.println(pair[0] + " " + pair[1]);
    }
}

python::

    pair[0], pair[1] = pair[1], pair[0]

pair = [3, 8]
swap(pair)
print(pair[0], pair[1])
```

```text
8 3
```

四段屏幕上的数一模一样，都是 `8 3`  —— 可「改到外面」的手法，四家四样：

- **C**：老手艺全套。递名称（`&x`）、收名称（`int *a`）、顺着走（`*a`）—— 三处记号，一处都不能少；
- **C++**：接班人上场。`int& a` 直接挂名字，引用的时候光写 `swap(x, y)` —— 记号一个不剩。顺带说一句：老手艺 C++ 也没扔，两套写法它都认；
- **Java**：**没有接班人**。Java 的函数收料，收的永远是**抄件** —— 递 `int x` 进去，函数里改的是抄件，外面那个元素纹丝不动。想改到外面，得递一份**本身就是一整排**的东西：这里递的是一排元素（数组），函数里改 `pair[0]`、`pair[1]`，改的是外面那一整排；
- **Python**：跟 Java 一个心思。名字递进去也是**转手一份**，函数里改名字本身，外面不动；递一排元素（数组）进去才改得动外面。Python 还备了一句现成的换元素写法：`x, y = y, x` —— 一行，两个元素就换过来了。

## 接班人这么顺手，老手艺还有用吗

有用，而且有大用。有三个场合，只有名称办得到：

1. **先空着**：`int *p = NULL;` —— 名称可以先不指任何元素，等找着目标再挂。名字办不到：挂不上就开不了张。往后的链子里，末尾上那张名称谁都不指 —— 空名称是它的常态；
2. **半路换目标**：名称上的地址说换就换 —— 在一排元素里找最大的那个，就得让名称一个一个挪过去；
3. **沿着一排走**：名称加一，往后再跨**一整只元素**的身位。走一排元素全靠这一手，往后会专门有一课数它。

接班人这边也常穿一件外套：**常引用（const int&）**。在料上写 `const int& x`，读作「只看、不碰」：函数拿着它，看得见外面那个元素、不复印（省事），可**不许改**（安全）—— 编译器或解释器在一旁盯着呢。以后递大件东西的时候，你会天天用它。

::: tip 提示
今天三句话，装兜里带走：

1. **老手艺（指针）** —— 递**名称**进去：引用的地方 `swap(&x, &y)`，函数里顺着走 `*a = *b;`。能空着、能换目标、能沿排走；
2. **接班人（引用）** —— 给同一个元素**再挂一个名字**：调用 `swap(x, y)`，函数里照常写名字。挂上不换（从一而终），挂不上就开不了张；
3. **两家都别丢**：`const int&` 只看不碰，递大件用它；要空、要换目标、要沿排走，还得请老手艺。
:::

::: warn 注意
两个坑，提前钉在墙上：

- **`&` 一枚词，两种地方两种读法。** 递料的地方（`swap(&x, &y)`）读作「取地址」；登记料的地方（`int& a`）读作「不复印，就是它本身」。撞见 `&` 先问一句：它站在**递**的地方，还是**登记**的地方？
- **名字挂上就摘不下来。** 别忘了那个 `other = cat;`：它抄的是**值**，不是改挂。要是以为挂上的名字还能换元素，你会得到「改了名字、元素却没换」的怪现场，还找不着原因。
:::

## 一句话对照表

| 我们写下的 | 它是谁、在干什么 |
|---|---|
| `void swap(int *a, int *b)` | 老手艺：函数收下两块名称 |
| `swap(&x, &y)` | 老手艺：把两个元素的地址递进去 |
| `*a = *b;` | 老手艺：顺着名称走，改的是外面的元素 |
| `void swap(int& a, int& b)` | 接班人：不摆新元素 —— 外面那个元素，进来就叫 `a` |
| `swap(x, y)` | 接班人：光写名字，`a`、`b` 当场挂到外面的元素上 |
| `int& other = fish;` | 接班人：给 `fish` 再挂一个名字（别名） |
| `int& r;` | 挂不上就开不了张 —— 编译器或解释器当场拦下 |
| `const int& x` | 只看不碰：不复印、不许改，递大件常用它 |
| `x, y = y, x` | Python 的现成写法：一行把两个元素换过来 |
| `int[] pair` + `swap(pair)` | Java：函数收的永远是抄件 —— 得递**一整排**才改得动外面 |
