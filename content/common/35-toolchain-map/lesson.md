## 学习目标

本课学习编译与运行工具链。重点包括工具链五站路、四种语言的家伙什、「环境」是什么、本机工具链地图。请结合示例观察程序状态、执行顺序和结果，并通过练习检查理解。

## 一行代码，五站路

先看最小的一件事。这样一行字，你在前面几课里早就写过：

```python
print("计算机开始逛工具链")
```

```text
计算机开始逛工具链
```

从它被你敲下，到屏幕上冒出这句话，中间要过五道站：

1. **写**——这一行是在写代码的软件里成形的（编辑器、IDE 都算）。此时的它，对电脑来说只是一串没读过的字；
2. **翻**——按下运行，源代码先送到**编译器或解释器**手里。Python 这位是边翻边跑的急性子；C、Java 那边习惯整本翻好再跑，各语言线会细讲；
3. **跑**——电脑照翻好的话一句句干活；
4. **看**——干活的结果回到屏幕上：`计算机开始逛工具链`；
5. **修**——结果不对、或者先冒了错误信息，就回这一站：调试改稿。这门手艺术语叫**调试（调试）**——改完，从「写」站重新出发。

写 → 翻 → 跑 → 看 → 修。以后程序出任何毛病，你都先问自己一句：**它是在哪一站崴的脚？**

## 先认脸：编译器或解释器与它们的家伙什

你不必现在就记住谁是谁——先认脸。下表是四门语言在你手边最常露面的家伙什：

| 语言 | 编译的 | 常打照面的 |
|---|---|---|
| C | `gcc` | 调试的 `gdb` |
| C++ | `g++` | 同上，`gdb` |
| Java | `javac` 先翻、`java` 再念 | 一整套家伙什合称 JDK（本机是 Temurin 21.0.12.1） |
| Python | `python`（边翻边跑） | 去工具窝取件的跑腿对象 `pip` |

项目一大，还要请**管家**：

- C 系项目的管家叫 `mingw32-make`（本机的路牌上，它就叫这个名字——没有 `make` 这个调用方式），再往上一层的规划师叫 `cmake`；
- Java 大项目的管家是 Maven、Gradle，通常住在大宅子 IDEA 里；
- Python 的来料采买，靠 `pip` 照单办事。

管家们今天只点名、不拆解——第 38 课专门讲它们。语言线那边，《编译器或解释器怎么工作——编译与运行流程》《一个箱子三个名字——JDK、JRE 与 JVM》这些课里，你早晚会跟其中几位一位位打招呼——这里先认脸。

## 验收一下：四位编译器或解释器，同一句话

同一句任务，交给四位编译器或解释器。各自的写法不同，可干出来的活是同一件：

```compare
c::
#include <stdio.h>

int main(void) {
    printf("五个站点，一条流水线\n");
    return 0;
}

cpp::
#include <iostream>
using namespace std;

int main() {
    cout << "五个站点，一条流水线" << endl;
    return 0;
}

java::
class Main {
    public static void main(String[] args) {
        System.out.println("五个站点，一条流水线");
    }
}

python::
print("五个站点，一条流水线")
```

```text
五个站点，一条流水线
```

四份源代码、四位编译器或解释器，屏幕上的回话一字不差——**「写」站你用什么纸笔，跟后面四站无关**。这是工具链的第一条安心话。

## 「环境」这个词，到底指什么

工具链听多了，你会反复撞见一个词：**环境**。它听着玄，其实就是两个具体问题、外加半件事：

1. **工具住在哪？**——是保存了、装在哪一个变量？
2. **电脑怎么找到它？**——你敲一个名字，电脑去哪找人？答案靠一张**路牌清单**（它的英文名叫 PATH）：敲名字，它拿着清单一家一家问过去。
3. 半件事：**哪一位上场？**——家伙什也分版本，老编译器或解释器和新编译器或解释器认的规矩可能不一样；换一位上场，同一份源代码的结局可能就变了。第 37 课有一位「老编译器或解释器」的真实故事等着。

环境这个词，以后就按这两问一半来理解：**住哪、怎么找到、谁上场。**

## 本机地图：沙箱与它的小伙伴们

先摊开一张常见的门牌地图（版本号、盘符以你自己的电脑为准；路径里的「你的用户名」换成你登录 Windows 的名字）：

| 住址 | 住着谁 |
|---|---|
| `C:\Program Files\Eclipse Adoptium\jdk-21.0.12.101-hotspot` | Java 的全套家伙什（Temurin 21；你装的那版版本号可能不同） |
| `C:\Users\你的用户名\AppData\Local\Programs\Python\Python312` | Python 3.12 的窝（`pip` 也住这条街） |
| `C:\Users\你的用户名\AppData\Local\MiAiBianCheng\toolchain\winlibs\mingw64\bin` | **CodeBud自带的工具链**：`gcc` 16.1.0、`g++`、`gdb`、`mingw32-make` 4.4.1 |
| `<你安装 IDEA 的目录>\IntelliJ IDEA 2024.1` | IDEA 大宅子（Java 课用它） |

重点看第三行——那是练习场的**自带货**。练习场里「真跑题型」那种一按就跑的题，永远只用这一套固定班底去翻、去跑：不看别处保存了几个版本、装得多新。你换一台电脑做同一道题，结论一字不差——工程里管这个叫**环境隔离**，说穿了就一句话：**说好谁上场，就永远是谁上场。**

补一句实况：装好CodeBud的电脑上，应用会顺手给自带这套挂路牌——所以在外面窗口敲 `gcc`，叫到的就是它（16.1.0 那位）。给它挂路牌的学问，就是下一课的正题。

## 走一遍：一行代码的五站路

```demo
title: 一行代码的五站路
code:
| print("计算机开始逛工具链")
| # 第二站「翻」：编译器或解释器把它翻成电脑听得懂的话
| # 第三站「跑」：电脑照着翻好的话干活
| # 第四站「看」：屏幕上冒出这句话

step 第一站「写」：源代码落笔
at: 1
say: 一切从这张源代码开始。计算机坐在写代码的软件里，把想说的话敲成这一行——此刻它只是一串字，电脑一个字都还没看见。
meow: 源代码写好了，还没运行。
pose: guide
稿子 = 刚写完第 1 行
编译器或解释器 = 还没上场
电脑 = 还没见过这行字
标准输出 = 还没印

step 第二站「翻」：交给编译器或解释器
at: 2
say: 按下运行，源代码被送到编译器或解释器手里。Python 这位是边翻边跑的急性子，翻一句、跑一句；C 和 Java 那边习惯整本翻好再跑，各语言线会细讲。
meow: 交给编译器或解释器。
pose: busy
稿子 = 已交到编译器或解释器手里
编译器或解释器 = 上场（边翻边跑）
电脑 = 快听见了
标准输出 = 还没印

step 第三站「跑」：电脑动手
at: 3
say: 翻好的话进了电脑的耳朵，它照着一句一句干——这一行的意思只有一个动作：印出一句话。
meow: 电脑执行这一行：输出一句话。
pose: busy
稿子 = 已交到编译器或解释器手里
编译器或解释器 = 干活中
电脑 = 正在印这句话
标准输出 = 马上见

step 第四站「看」：结果回屏幕
at: 4
say: 干完的动静回到屏幕上：计算机开始逛工具链。要印出来的不是这句、或者先冒了错误信息，就该走第五站「修」——调试改稿，从「写」站再来一遍。
meow: 结果回到屏幕，可以检查了。
pose: yay
稿子 = 已跑完一轮
编译器或解释器 = 交差了
电脑 = 干完了
标准输出 = 计算机开始逛工具链
```

::: tip 提示
今天的地图，收好这三句话：

1. **五站路**：写（编辑器、IDE）→ 翻（编译器或解释器）→ 跑 → 看（输出）→ 修（调试）。程序出毛病，先问它在哪一站崴的脚；
2. **「环境」= 两问一半**：工具住哪、电脑怎么找到、哪一位上场；
3. **沙箱的规矩**：练习场的真跑题型，永远用自带那套固定班底——说好谁上场，就永远是谁上场。
:::

::: warn 注意
两个坑，我们标出来：

- **「学编程只要学语言」是上了半句就下车**：语言管「写」，可翻、跑、看、修这四站的天天打交道，才是另一半功夫。工具不是高手的深水区——你每跑一次程序，就已经在用它了；
- **别急着去装一堆工具**：地图先收好，各站都排着专课。手痒乱装一气，容易把路牌弄乱——路牌怎么养、怎么改才安全，下一课有正题。
:::

## 一句话对照表

| 我们写下的 | 它的意思 |
|---|---|
| 写 → 翻 → 跑 → 看 → 修 | 一行代码的五站路 |
| 编译器或解释器 | 把源代码翻给电脑听的那位——`gcc`、`g++`、`javac`、`python` 都是它家的 |
| 路牌清单（`PATH`） | 敲名字时，电脑拿着它一家一家找 |
| 环境 | 住哪 + 怎么找到 + 谁上场 |
| 环境隔离（沙箱） | 说好谁上场就永远谁上场——练习场自带那套固定班底 |
| 管家 | 让几百个文件的「怎么造」写成一份文件的工具（第 38 课） |

## 这条线会跟你走多远

工具链这门课是一条线：今天认路，下一课认「路牌」，再下一课拆「运行按钮」，最后一课请「管家」。你在语言线里早晚会跟它们再碰面：

- C 语言线会有一整课讲「翻」站的第一步——《编译器或解释器怎么工作——编译与运行流程》；
- Java 线的《一个箱子三个名字——JDK、JRE 与 JVM》会把一整套箱子的来龙去脉摆清楚，第 37 课我们再把那个运行按钮整个拆开看；
- 你在《程序的基本结构——程序的组成》里写下的每一行，其实都已经走过了这五站。

到那时候你会发现：**今天这张地图，是你后面每一门语言课的第一页。**
