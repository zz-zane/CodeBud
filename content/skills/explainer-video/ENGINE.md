# 讲解动画引擎契约（给引擎实现者，不给 AI 看）

> 配套 `SKILL.md`（AI 写 spec 的规则）。这里规定引擎**必须**怎么解释 spec。
> 2026-11-21 起：引擎**不得**为某一支片写死内容（地址、坐标、按幕 id 分支、按记号写死的正则上色）。
> 判断标准：把 `examples/c-pointer.spec.json` 里的类比换成「车厢」、地址换成别的值，引擎照样画对。

## 1. 入口

- `validate(spec) → { ok: true, spec } | { ok: false, errors: string[] }`：纯函数。错误信息写成**可以原样回给 AI 让它改**的中文短句，如「第 3 幕第 2 步 morph 的 id "cell-x" 之前没有 enter」。
- `timeline(spec) → { duration, steps: [{ act, index, start, end, ops: [{ op, start, end }] }] }`：纯函数。
- `drawFrame(ctx, spec, t)`：纯函数，同一 `t` 逐像素一致；不读 `Date.now()` / `Math.random()`（需要随机用 spec 派生的种子）/ 跨帧可变状态。状态一律从 `timeline` 按 `t` 重放得到。

## 2. 时间轴

- 步内 op **依次**播放，时长：`enter 0.45` `exit 0.2` `set 0.6` `morph 1.6` `arrow 0.5` `unarrow 0.2` `fly 1.0` `focus 0.3` `write 0.5` `line 0.3` `print 0.4` `break 0.7` `row 0.45` `title 0.6`（秒）。
- 步时长 = `max(spec 给的 hold, 字数/6 + 1, op 总时长 + 0.8)`。字幕在步开始时出现。
- 缓动：`smooth(t) = 6t⁵ − 15t⁴ + 10t³`；入场用它，退场用 ease-in 且更快（见上表）。
- 幕切换：除 `analogy → reveal` 外，新幕开始时把上一幕元素 0.2s 淡出清场（这 0.2s 计入新幕第一步）。

## 3. 版面（自动，不读坐标）

- 画布 1920×1080；上 72px 是幕名胶囊（左）+ 角色图例（右，来自 `roles`）+ 顶部进度细条；下 180px 是字幕带；元素只能出现在 `y ∈ [72, 900]`。
- 区域：
  - `hook`：代码面板居中（`write` 逐行出现）；`output` 在代码面板右侧。
  - `trace`：代码面板左 45%，舞台右 55%；`output` 在舞台底部。
  - `reveal`：对照表在左侧固定 420px 宽，舞台在右。
  - `recap`：对照表居中占满，`title` 在表下方。
  - 其他：舞台占满。
- 舞台排布：`group` 从左到右平均分列；组内 `box` 按 `layout`（`row` / `column`）和 `enter` 顺序排。不在组里的 `box` 排成居中一行。`zone` 放在舞台最右。尺寸按同屏数量缩放，最小也要保证 `value` 字号 ≥ 44px、`tag` / `name` ≥ 28px。
- **相对位置只看 `place`**（`below:<id>` / `above:<id>`）：放到目标正下 / 正上方，水平居中对齐目标。**不再**根据「是不是箭头起点」猜位置（2026-11-21 递归片实测：调用链 `fact(3) → fact(2)` 被这条猜测挤到第二行，版面错乱）。`place` 的目标必须在场，否则 `validate` 报错。
- 箭头路由：同一行相邻格子之间的箭头走直线，格子间距在有箭头时至少 72px，箭头可见长度 ≥ 48px；同一列上下相邻的走直线；其他情况走绕开格子的弧线。箭头不得压在文字上，终点停在目标格子的边框上（不指向 `name` 标签）。
- `exit` 后同组剩余元素用 0.45s 平滑补位（出栈时上面的帧不能瞬移）。
- 放不下时：先缩小、再换行，最后才在 `validate` 阶段报错。不允许重叠或出画。

## 4. 绘制规则

- **形变（`morph`）**：同一元素的外形参数（宽高、圆角、底色、描边色、装饰物透明度如把手/折角/刻度）在 1.6s 内连续插值，位置若因版面变化而变也一起插值。**文字替换必须先旧后新**：旧文字在前 40% 淡出 + 上移 8px，新文字在后 40% 淡入 + 从下方 8px 上移到位；任一时刻新旧文字不会同时以 > 0.3 透明度出现（不许出现两串字叠在一起）。
- `fly`：小标签从 from 的 `value` 位置沿弧线飞到 to 的 `value` 位置，落地时 to 的 `value` 换成该文字。
- `focus`：未聚焦元素透明度降到 0.4，0.3s 过渡。
- `break`：裂纹折线 + 红色 ✕ 标签，标签骑在格子下边框上，不盖住 `value`（`danger` 色只在 `break` / `zone tone=danger` 里出现）。
- `recap` 表：有顶层 `recapHeads` 时用它做表头且不画栏间「↔」（对比型主题两栏是对立不是等价）；行高随行数收缩，任何行数都不出表。
- 上色：字幕里的 `{role:text}`、代码面板里命中 `tokens` 的记号、对照表格子里命中 `tokens` 的记号，全部用同一张 `tokens → roles → color` 表。代码按「最长匹配」切记号（`*p` 优先于 `p`），只匹配完整标识符（`p` 不会匹配到 `printf` 里的 p）。
- 颜色名映射：`blue #2f6fd6`、`orange #c96a2b`、`teal #1f9d8b`、`purple #7a5af0`；底色 `#f5f4ef`、卡面 `#ffffff`、正文 `#1a1a18`、次要 `#66645e`、描边 `#dcd9d0`、危险 `#d64545`。
- 每步除落定后的停顿外都要有变化；停顿期允许极轻的呼吸（聚焦元素描边透明度 ±10%，周期 2s），不加漂浮、不加粒子。
- **画面上不出现任何调试信息**（进度百分比、t 值、帧号、元素 id）。

## 5. 皮肤参数（类比 ↔ 真实之间都能 morph）

每种皮肤是同一组参数的取值：`w h radius fill stroke strokeWidth headerH headerFill tilt foldCorner handle slots ticks`。例：`locker`（木色底、深描边、圆角 18、把手 1、通风槽 3）→ `memory`（白底、细描边、圆角 6、无把手、底部字节刻度 4）；`note`（米黄、倾斜 −2.4°、折角 30px）→ `var`（浅青底、无倾斜、无折角）。新增皮肤只加一组参数，不加分支。

## 6. 验收

- `examples/c-pointer.spec.json` 用本契约重写后渲出的片，与 2026-11-21 样板片在 6 幕结构、配色、形变效果上一致，且修掉三处问题：形变中段文字叠字、右上「类比 → 内存 50%」调试标签、`*p` 在字幕 / 代码 / 对照表里颜色不一致。
- 引擎源码里搜不到 `0x7ffd`、`cell-a`、`renderAct`、`pointer` 这类与具体内容绑定的字面量（测试数据除外）。
- 色彩：类比皮肤的抬头 / 标签文字用中性色（正文 / 次要色），只有命中 `tokens` 或写了 `role` 的内容才上角色色（2026-11-21：「纸条」抬头被画成了地址蓝）。
- `validate` 另外拦截（2026-11-21 分段/分页片实测补充）：同屏不在任何 `group` 里的 `box` 超过 4 个（错误提示要叫 AI「用 group 组织成表 / 栈 / 数组 / 左右对比」）；`recap` 的 `row` 少于 3 行。
- `validate` 对 10 个故意写坏的 spec（未 enter 的 id、超过 8 个 box、字幕 30 字、缺 reveal、morph 的 id 不在 analogy 里、`tokens` 一个记号两个角色……）全部给出可读错误。

## 7. v1.5 新增（2026-11-21，用户反馈：太快、段和页太像、要用对话讲「怎么分清」）

- **`pace`**（顶层，`"normal"` 默认 / `"slow"`）：slow 时步时长 = `max(hold, 字数/4 + 1.8, op 总时长×1.4 + 1.4)`，所有 op 时长 ×1.4。`validate` 拒绝其他取值。
- **`box.size`**（0.4–2.5，默认 1）：在 `row` 组里按比例改宽度、在 `column` 组里改高度，组内其余格子按剩余空间排；文字最小字号不变（`value` ≥ 44px），放不下先缩字到下限再报 `validate` 错。`morph` 时 size 也连续插值。`page` 皮肤写了 size → `validate` 报「页大小固定，page 不能写 size」。
- **新真实皮肤**：
  - `segment`：横向长条，圆角 14，左侧一条 8px 的角色色竖带（像书脊），抬头左对齐；天生适合配 `size` 画长短。
  - `page`：正方形块（宽 = 高），内部淡淡的 4×4 网格线暗示「固定格数」，右上角一个小折角；所有 page 永远等大。
  - 两者与类比皮肤之间都能 `morph`（参数插值，不加分支）。
- **`box.role` 上色**：写了 `role` 的格子，描边与抬头底色用该角色色（抬头底色取角色色 12% 透明度），`focus` 时描边加粗到 3.5。目的：对比型主题里 A、B 两边一眼看出颜色不同。
- **`say`**（只在 `clarify` 幕）：`who: "student" | "teacher"`、`text ≤ 30 字`。舞台右侧留 560px 对话栏，左侧剩余区域照常排元素。气泡：学生靠左（浅灰底、左侧圆形头像写「学」），老师靠右（中性墨色浅底、右侧头像写「师」；**不借任何角色色**，角色色只代表概念，借蓝色会让人以为老师在说分段）；新气泡从下方 16px 滑入 + 淡入（0.45s，pace 系数照乘），旧气泡整体上推；同屏最多 4 条，更早的淡出。
- **`clarify` 幕**：可选，只能出现在 `pitfall` 与 `recap` 之间；2–4 步；进入时与普通幕一样清场；`validate` 校验：第一个 `say` 必须是 `student`，最后一个 `say` 必须是 `student`，至少一个 `teacher`。有 clarify 时全片步数上限放宽到 30。
- 回归：`c-pointer`、`python-stage1-16`、`os-segmentation-paging*` 范例 spec 必须仍然通过 `validate`，并且画面不变（未写 pace/size/role 的元素外观与 v1.4 一致）。
