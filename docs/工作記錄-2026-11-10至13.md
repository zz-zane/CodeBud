## 0. 工作方式（長期規則）

| 規則 | 內容 |
|---|---|
| 模型分工 | 主對話負責設計架構、寫規格、驗收；實作一律交給 Sonnet（effort medium）子代理；Opus（effort medium）只在 Sonnet 對同一個問題修兩次仍失敗時才接手 |
| 交付子代理的任務 | 必須有具體方案（尺寸、字級、間距、顏色令牌、資料來源、行為），不能只給「完成 UI 優化」這種籠統指令 |
| 前端設計 | 先在 Figma 出設計稿，再寫成帶數值的規格文件，子代理照規格實作 |
| 測試 | 型別檢查、單元測試、建置、桌面視窗實機驗證都要跑；**唯一不跑的是「連接手機端」的測試**，由使用者自己在真機上測 |
| 網路 | **不得查看或修改任何網路設定**（不跑 `ipconfig`、`netsh` 等，不動防火牆、代理、DNS、組網工具）；實機驗證只用 `127.0.0.1` |
| 電腦端與手機端 | 兩者介面不同；優化手機端時電腦端不得有任何變動 |
| 憑證 | API Key 由使用者自己在設定頁輸入，助理不讀取、不輸入 |
| 實機啟動 | 測試一律用 `--user-data-dir=<暫存目錄>`，不碰使用者的真實資料目錄 `local-data` |
| Antigravity 額度 | 實測只用 `gemini-3.8-flash-*`（其他模型額度可能已滿），發問數要節制 |

模型分工規則已存入長期記憶（`model-role-delegation`）。

### 1.4 手機連接（11-11 至 11-12）

規格：[docs/29-手机连接.md](29-手机连接.md)

- **做法**：電腦端在本機開一個 HTTP 服務，手機瀏覽器載入同一套介面；外出連線靠使用者自己裝的免費組網工具（Tailscale、ZeroTier 這類），應用程式不做內網穿透。
- **安全**：服務預設關閉；6 位配對碼，輸錯 5 次鎖 10 分鐘；裝置令牌只存雜湊；每個請求都驗令牌；手機可用通道採白名單（`src/shared/remote-channels.ts`），執行程式碼、改設定、選資料夾、管理連線一律拒絕；送往手機的資料會清掉本機路徑（`src/shared/remote-redact.ts`）。
- **一份介面定義兩種傳輸**：`src/shared/miai-api.ts` 的 `createMiaiApi(transport)`，preload 與手機端共用。
- **設定頁「手機連接」**：開關、連接埠（預設 17600）、位址清單、配對碼、已配對裝置與撤銷。
- **手機版面**：規則集中在 `src/renderer/src/styles/phone.css`（全部在 `@media (max-width: 768px)` 內，有測試把關）。
- **手機操作體驗**：底部分頁列、清單進詳情的左右滑動轉場、返回手勢先關閉彈層、返回時恢復捲動位置；鍵盤彈出時版面不重排，只有正在輸入的區塊移動。

### 1.5 Antigravity 接入與 Provider 切換（11-12）

規格：[docs/30-界面节奏与Provider切换.md](30-界面节奏与Provider切换.md) 第 1 節、[docs/study-companion-architecture.md](study-companion-architecture.md)

### 1.8 複習間隔排程（11-13）

規格：[docs/32-复习间隔排程.md](32-复习间隔排程.md)

- **起因**：原本的「複習到期」是「學過但今天還沒練的課」，課越多數字越大，不反映哪些真的該複習。
- **做法**：以課為單位，完全從現有資料推算（每課的學習時間加練習紀錄），不新增資料檔、不改資料結構。純函式在 `src/shared/review-schedule.ts`。
- **間隔階梯**：1、3、7、14、30、60 天。到期當天或之後複習，當天該課正確率 80% 以上升一檔、50%–80% 維持、低於 50% 降一檔；提前練對了不變，提前練錯了照樣降檔。
- **每天上限 15 課**：依逾期天數排序，其餘順延。
- **介面**：「今天」頁、側欄與手機分頁列的徽標顯示今天要複習的課數；複習頁顯示「今天到期 N 課」，各模組頁籤顯示該範圍的到期數，有到期時按鈕是「開始複習」且只從到期的課抽題，沒有時是「自由複習」。
- **驗證**：40 課測試資料的手算結果與程式一致；實機上複習完成後數字立即更新；5000 筆練習紀錄重算約 12 毫秒。
- **與規格的差異**：選某個模組頁籤時若該範圍今天沒有到期的課，按鈕是「自由複習」，即使其他模組還有到期的。

## 5. 常用指令

```bash
npm run typecheck      # 型別檢查
npx vitest run         # 單元測試（challenge.test.ts 有一個隨負載波動的用例，單獨重跑會過）
npm run build:app      # 建置
```

實機驗證啟動方式（暫存資料目錄、只綁本機）：

```bash
MIAI_REMOTE_HOST=127.0.0.1 MIAI_DEBUG_PORT=9333 ./node_modules/.bin/electron . --user-data-dir="<暫存目錄>" --disable-features=CalculateNativeWinOcclusion --disable-renderer-backgrounding
```

用 CDP 操作視窗前要先送 `Page.bringToFront`、`Emulation.setFocusEmulationEnabled`、`Page.setWebLifecycleState {state:'active'}`，否則視窗被判定為不可見時換頁動畫不會完成。
