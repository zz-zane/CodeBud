# 六级真题模块（CET-6）设计规格

把已验收的独立模块 `D:\project\coding_2\cet6_p`（源：`D:\project\coding_2\cet6_a\cet6-isolated`）并入咪爱编程。交互逻辑以 `cet6_p/app.js` 为行为基准，视觉完全服从本项目。

## 1. 产品原则（不可变更）

1. **方便做题优先**：不做答题卡。文章和题目同屏、各自滚动，选完自动往下，全程可用键盘。
2. **交卷前只呈现试卷**：答案、解析、听力原文/译文、参考范文、资料说明，一律 `submitted` 后才渲染（不是 CSS 隐藏，是不进 DOM）。
3. **离线可用**：试卷数据随应用打包。听力音频 1.7GB 不打包，读用户本地目录；目录缺失时其余部分照常可用。
4. **内容不改写**：`content/cet6` 由 `cet6_p/data` 原样搬入，只调整路径字段。

### 2.1 数据与音频：`miai-cet6://` 协议

**不要用 fetch 读 public 目录**（生产环境是 file://，且 9MB 不能进 content-bundle）。新增特权协议：

- `miai-cet6://data/<相对路径>` → `join(app.getAppPath(), 'content/cet6', 路径)`
- `miai-cet6://media/<相对路径>` → 用户设置的音频目录，支持 Range（拖动进度条）

要点：
- scheme 加到 `wallpaper/protocol.ts` 现有的 `registerSchemesAsPrivileged` 数组里（整个进程只能注册一次），权限同 miai-wall。
- 复用该文件已导出的 `parseRange`、`pathFence`，以及它的 CORS、流式响应写法；相对路径必须拒绝 `..`，并校验解析结果仍在根目录内。
- `src/renderer/index.html` 的 CSP：`img-src`、`media-src`、`connect-src` 追加 `miai-cet6:`。
- `package.json` 的 `build.files` 追加 `content/cet6/**/*`。
- 试卷 JSON 里 `audio.src` 是 `source-media/<相对路径>`，渲染层换成 `miai-cet6://media/<按段 encodeURIComponent>`；`figure.src` 换成 `miai-cet6://data/...`。

### 2.2 持久化：`cet6.json`

用 `store/json-store.ts` 的 `createJsonStore`，放在 `storageDir()`。新文件，不动现有 schema。

```ts
interface Cet6Record { answers: Record<string, string>; marks: string[]; submitted: boolean; seconds: number }
interface Cet6File { version: 1; mediaRoot: string | null; records: Record<string, Cet6Record> }
```

- IPC 进 `ipc-channels.ts`，预加载暴露 `window.miai.cet6`（同步更新 `preload/index.d.ts`）：`getState()`、`saveRecord(examId, record)`、`resetRecord(examId)`、`pickMediaRoot()`、`mediaStatus()`。
- 主进程入口校验：`examId` 匹配 `^\d{4}-\d{2}-\d$`；`sanitizeRecord` 限制键数、字符串长度（作文上限 20000 字符）、`seconds` 为非负整数。解析失败要留日志，不可静默清空。
- `mediaRoot` 为 null 时不使用作者本机目录，用户需在页面中选择自己的音频目录；已保存的目录仍直接使用。
- 渲染层保存防抖 400ms，并在离开路由、`beforeunload` 时立即写。保存失败用 toast 提示，内存内容不丢。

## 8. 练习 / 考试模式、选词问 AI、生词本（2026-11-10 增补，优先于上文冲突处）

目标：把项目已有的能力（AI 助教、错题、备忘）**按六级的做题场景重新设计**后接进来，不照搬编程课的交互。

### 8.1 两种模式

`Cet6Record` 加 `mode: 'practice' | 'exam'`（旧记录读入时补 `'practice'`）。一份记录一旦开始作答，模式不可改；「重新作答」时重选。

| | 练习模式 | 考试模式 | 交卷后（两种模式相同） |
|---|---|---|---|
| 计时 | 正计时，可暂停（现状） | **倒计时 130:00**（写作 30 + 听力 30 + 阅读 40 + 翻译 30），不可暂停，归零自动交卷 | 停止 |
| 选词工具条（§8.2） | 可用 | **不可用** | 可用 |
| 右侧 AI 栏、右键「问 AI」菜单、Ctrl+K 搜索、侧栏导航、设置入口 | 可用 | **全部不可用**（见下「考试锁」） | 可用 |
| 答案 / 解析 / 原文 | 不进 DOM（§1 原则 2 不变） | 不进 DOM | 显示 |
| 「只看错题」 | — | — | 题号条旁一个开关，开后题号条与 ←→ 只在答错的题之间走 |

**考试锁**：`stores/cet6.ts` 导出一个计算属性 `examLock`（当前卷 `mode === 'exam'` 且未交卷且做题页挂载中）。`App.vue` 是唯一消费方：锁定时不渲染左侧栏与右侧 AI 栏、顶条上除窗口按钮外的入口不可点、`onGlobalKey` 直接返回、`AiContextMenu` 不弹。离开做题页走路由守卫：`MiModal` 确认「退出考试？进度已保存，回来后继续计时」，确认才放行（应用关闭不拦）。锁只是界面层的专注约束，不做防作弊。

**模式入口**：目录页 `pg-head` 下加一个两段式切换「练习 | 考试」（选择记在 `cet6.json` 的 `lastMode`，默认练习），其下一行灰字说明当前模式的规则。点一套没做过的卷 = 按当前选择开始；点作答中的卷 = 按它自己的模式继续（小片上考试模式带一个 `clock` 图标）；已交卷 = 进入解析。「重新作答」弹窗给两个按钮：「练习模式重做」「考试模式重做」。

做题页顶栏：标题后一个不可点的模式徽标（`.pg-chip` 样式、`aria-disabled`）；考试模式计时器显示剩余时间，最后 5 分钟用 `--mi-error-deep` 字色。成绩弹窗在总分下加一行各 Part 的「正确/总数」（听力、阅读分开），方便看弱项。

### 8.2 选词工具条（练习模式 + 交卷后）

在做题页的文章、题干、选项、解析、原文、参考范文里**选中英文文本**（1 ~ 300 字符，去首尾空白后含至少一个字母）松开鼠标，在选区上方浮出一条小工具条（`Cet6SelectionBar.vue`，`position: fixed`，跟随选区矩形，滚动/点别处/Esc 消失，不抢焦点、不清选区）：

```
[ 释义 ]  [ + 生词本 ]
```

- 选中靠鼠标拖选：做题页根元素在考试锁关闭时带 `sel-ok` 类，`.cet6-left` 与右栏滚动区内的文字 `user-select: text`（全局 `body` 是 `none`，考试锁开着时保持不可选）；拖选落在按钮（选项、陈述、词库、空格、段落字母）上时，根元素的捕获阶段 click 守卫在选区与该按钮相交时吞掉这次 click，选词不会改答案或跳题，无选区的普通点击照常作答。
- **释义**（= 问 AI）：工具条原地展开成一张卡片（最宽 360px，最高 50vh 可滚）。先显示「正在查询…」，结果回来后：
  - 单词 / 短语（≤ 4 个词）：音标、词性、**在本句中的意思**、常见搭配 1~2 条。
  - 句子：中文翻译 + 「句子结构」（主干、从句各一行）—— 六级长难句是阅读与翻译的主要失分点，这是针对六级的设计，编程课没有对应物。
  - 卡片底部：「追问」（打开右侧 AI 栏，把选中文本和所在句作为引用带过去，用 `aiAssistant.openWithSelection`）。
  - **查询成功即自动加入生词本**（已存在则更新释义），卡片角落显示「已加入生词本」+「撤销」。
  - 失败（没配 Key / 断网 / 超时）：卡片显示一句原因 + 「去设置」（没配 Key 时），**不**自动加入；「+ 生词本」仍可用。离线优先铁律：失败不弹窗、不阻塞做题。
- **+ 生词本**：不调 AI，直接加入（无释义，生词本里可以再点「释义」补）。已在生词本里则按钮显示「已在生词本」。
- 所在句（`context`）：从选区所在的块级元素文本里取包含选区的那一句（按 `.?!` 切），最长 600 字符。
- 写作 / 翻译的输入框内不出工具条。键盘作答的快捷键与它互不影响（选区存在时字母键照常作答）。

### 8.3 生词本

数据：`<数据目录>/cet6-vocab.json`（`createJsonStore`，与 `cet6.json` 同级，带 `version: 1`，读口归一化；解析失败留日志不清空）。**主进程是唯一写方**。

```ts
interface Cet6VocabEntry {
  id: string
  text: string                    // 原样（保留大小写），≤ 300
  kind: 'word' | 'sentence'       // ≤ 4 个词 = word
  context: string                 // 所在句，≤ 600，可为空
  source: { examId: string; sectionType: string } | null
  addedAt: string                 // ISO
  mastered: boolean
  gloss: Cet6Gloss | null         // AI 释义；没查过是 null
}
interface Cet6Gloss { phonetic: string; pos: string; meaning: string; collocations: string[]; translation: string; structure: string[]; at: string }
```

去重键 = `text` 去首尾空白、压缩空白、转小写。上限 5000 条（超出时拒绝新增并提示）。

IPC（`features/cet6.ts`，预加载挂在 `window.miai.cet6.vocab`）：`list()`、`add(input)`、`update(id, patch)`（只允许改 `mastered`）、`remove(ids)`、`lookup(input)`（调 AI → 解析 → 写入/更新条目 → 返回 `{ ok: true, entry } | { ok: false, reason }`）。前四个返回最新列表。

AI 调用：主进程用现有的 `NativeHarness.runTurn`（`ctx.study.harness`，一次性会话、超时 30s），提示词与响应解析是 `src/shared/cet6-vocab.ts` 的纯函数：要求模型只回一个 JSON 对象；解析要宽容（剥 ```json 围栏、缺字段补空串/空数组、非 JSON 时把全文当 `meaning` / `translation`）。不新增网络通道、不新增依赖。

页面 `/cet6/vocab`（`Cet6VocabView.vue`，普通页，路由必须排在 `/cet6/:id` 之前）：
- `pg-head`：标题「生词本」+ 计数；右侧「遮住释义」开关（自测用：释义行变成「点击显示」，逐条点开）。
- 筛选 `.pg-chip`：全部 / 单词 / 句子 / 未掌握；一个搜索框（按原文与释义过滤）。
- 列表 `.pg-rows`，每条：原文（serif）＋音标词性；释义或翻译；所在句（原文在句中加粗）；来源「2025年6月 第1套 · 阅读」可点回到那套卷；右侧图标按钮：释义（没有 gloss 时）/ 已掌握 / 删除（删除走 toast 撤销，不弹确认）。
- 空状态说明怎么加词。
- 入口：目录页 `pg-head` 右侧图标按钮「生词本」（带条数）；做题页顶栏同一图标（考试锁时不渲染）。

### 8.4 写作 / 翻译作答区

现状输入框无框线，看不出哪里能写。改为明确的作答面：1px `--mi-border-control` 边框、`--mi-card` 底、`--radius-lg`、内边距 16px、撑满右栏剩余高度（最小 320px），聚焦时边框 `--mi-blue-deep`；上方一行小标题「作答区」，下方左侧词数、右侧建议（写作「建议 150–200 词」，翻译不显示建议）；空的时候有占位文字（写作「在这里写作文…」、翻译「在这里写译文…」）。交卷后输入框只读、边框变虚线，参考范文接在下面。不加阴影和渐变。

### 8.5 明确不做

逐题即时对答案（与 §1 原则 2 冲突）、AI 批改作文与译文、文章内对已收生词加下划线、生词本导出、间隔重复排程。需要时另开一轮。

### 8.6 实现补充（与上文的出入）

- 目录页点卷时把当前模式放进路由 `?mode=exam|practice`；做题页只在该卷**没有记录**时采用它，有记录则沿用记录自己的模式。没有 query 一律按练习模式开始（生词本里的来源链接、听力共用跳转都不带 query）。
- `lastMode` 经新增通道 `cet6:set-last-mode` 写入，读回走 `getState()`（返回值多一个 `lastMode`）。
- `lookup` 的成功返回多一个 `added: boolean`（false = 条目已存在、只更新了释义），工具条据此决定是否显示「撤销」。
- 失败原因码：没配 Key、Key 无效（401/403）、额度不足/限流（402/429）→ `no-key`；超时 → `timeout`；断网、5xx 及其他 → `network`；返回解析不出任何有用字段 → `bad-response`；生词本满 → `full`。
- 释义查询是一次性会话：随机会话 id，30 秒超时，结束即 `clearSession`；不传用量回调，因此**不写用量记录**，也不进聊天会话列表。
- 生词本删除没有「恢复」通道：界面先隐藏条目，5 秒撤销窗口过后（或离开页面时）才真正调用 `remove`。
- 「只看错题」只过滤题号条与 ←→ 的走法，当前题所在的文章与右栏内容不变。
