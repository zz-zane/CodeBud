指针变量里存的是什么

指针变量里存的不是一个普通的数，而是另一个变量的地址。顺着这个地址，就能找到并修改那个变量。

int a = 5;
int *p = &a;
*p = 9;

p 里存的是 a 的地址，*p 表示「到那个地址去」。
