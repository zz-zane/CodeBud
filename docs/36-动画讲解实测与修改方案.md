# 36 动画讲解：实测结论与修改方案

> 实测对象：`codebud` @ `42210ef`（`docs/35` 六个里程碑合流后）。实测日期 2026-11-17。
> 实测方式：重新 `build:content` + `build`，用隔离资料目录启动，脚本逐步操作并截图；聊天生成用真实模型（Antigravity · Gemini 4 Hydrogen Medium）各跑一次。
> 证据截图在 `docs/36-shots/`，实测脚本在 `docs/36-qa/`（依赖本机 playwright-core 路径，换机器需改第 4 行）。
> **结论：功能骨架都通了，但离「用动画把抽象原理演明白」还差一截，界面有多处没有按设计稿做。不能算验收通过。**

## 一、实测结论

### 1.1 已达到要求的

| 要求 | 实测结果 |
|---|---|
| 不让学员先看思路再确认 | 发送后直接生成，没有任何确认思路的步骤 ✓ |
| 在聊天里生成、过程可见 | 聊天里出现进度卡，结束后变成可播放的卡片 ✓（样式不合格，见 F7） |
| 代码和内存同屏 | 第二幕左代码、右内存，行高亮与内存同步 ✓（`e7-code-memory.png`） |
| 关键一步先猜 | 播到带题的一步自动停下，答完再揭晓 ✓ |
| 「这一步没懂」不遮挡发送键 | 悬浮的「返回视频」已删除；输入框只预填一次 ✓ |
| 不是每一课都有 | 只有 9 课有行内动画卡；`c-stage1-03` 等课没有任何入口；底栏「视频讲解」已删 ✓ |
| 原生下拉 | 设置、资料库各页签、六级页 `<select>` 数量均为 0；教学模式改成了弹出菜单 ✓ |
| 真实生成可用 | 3 问全部成功：二级指针 60 秒、`p` 与 `*p` 48 秒，代码均已核对；`#include` 一问正确改用文字回答 ✓ |
| 不合格不展示 / 代码真跑 | `check:animations` 10 幕全过；生成的 5 支 `codeVerified: true` ✓ |

### 1.2 没达到要求的（按严重程度）

**F1 画面太小，舞台九成是空的。**（`e1-stage-small.png`）
舞台 1160×535，实际用到的区域只有 256×100 到 577×142，占舞台面积 4%–13%。格子 120×65，值的字号约 20px，名字 12px。学员看到的是一大片空白里几个小方块。

**F2 类比没有画出来。**
`locker` 皮只是把格子边框加粗；「纸条」是一个淡黄色方块；`sheet` 皮是几个淡黄色的组并排放（`e2-recursion-horizontal.png`），不是「叠起来的草稿纸」。柜子、纸条、草稿纸都只存在于字幕里 —— 这正是上一版「类比只是一段话」的老问题，换了个位置。

**F3 动得太少、太快，看起来仍是换页。**
一步里所有变化同时发生，200–600ms 就结束，之后静止 4–6 秒等字幕。最关键的动作「顺着纸条 / 地址找过去」完全没有演：箭头画出来后就不动了，值直接出现在目标格子上方。解引用这个概念本身就是「顺着走过去」，这一下不演，动画就没讲到点上。

**F4 箭头绕远路。**（`e1-stage-small.png`）
纸条组排在柜子组右边，箭头从纸条底部出发、绕到两个柜子下方、再向上扎进 100 号柜。设计稿是纸条在左、一条短箭头直接指向柜门。

**F5 递归 / 调用栈是横着排的，还多了错误的箭头。**（`e2-recursion-horizontal.png`）
三个栈帧左右并排，`sub` 格子各有一条箭头指向下一帧的 `n`。「栈」的要点是往上叠、从上面弹，横排加箭头看起来像链表。

**F6 播放器控件没按设计稿做。**
上一步、播放、下一步是文字符号 `◀ ▶ ▶`（播放和下一步长得一样）；暂停是 `Ⅱ`；「旁白」「动效」是纯文字；关闭是很小的 `×`；标题用了特粗字重；没有「代码已核对」标记；倍速在最左。设计稿（`docs/35-ui/v04.png`–`v06.png`）要求用项目图标与按钮组件。

**F7 聊天里的进度卡与完成卡没做样式。**（`e3-chat-progress.png`、`e4-chat-card.png`）
- 进度卡：四个圆点一行（判题 / 写分镜 / 跑代码 / 完成），没有当前阶段的转圈与已用秒数，没有判断结论；「取消」是一个撑满整行的系统原生灰按钮。
- 完成卡：「▶ 播放」「换一种讲法」是带黑边的系统原生按钮；缩略图里多出一截悬空的箭头；没有时长、没有「代码已核对」；只写「2 幕」；标题特粗。

**F8 续播条是原生按钮。**（`e5-resume-bar.png`）
「▶ 继续播放 · 标题 · 4/11」和旁边的 `×` 都是黑边原生按钮，没有设计稿里的浅色底条。

**F9 内置动画不会被命中，白花一次生成。**
问「我分不清 `p` 和 `*p`，指针里到底存的是什么？」（正是 `c-pointer-basics` 讲的内容），结果花 48 秒新生成了一支。查代码：`src/main/video/generator.ts` 与 `prompts.ts` 里没有任何 `builtin` 分支，`docs/35` §5 第 1 步的「命中内置」没有实现。

**F10 名称不统一。** 教学模式菜单、输入框按钮仍叫「视频讲解」，进度卡叫「动画讲解」，资料库页签叫「动画」。`copy.ts:4075` 还留着「本课视频」「生成新视频」。

**F11 课文行内卡与资料库的缩略图。**（`e6-lesson-card.png`）
一大块灰底里只有两个很小的格子，还被播放按钮盖住；标题特粗。

**F12 猜一猜要点三次。** 选项 →「提交答案」→「揭晓」。答错后的原因挤在同一行里。

**F13 旧代码没删。** `StageArray.vue`、`StageCard.vue`、`StageMemory.vue`、`StageTrace.vue` 仍在仓库里。

**F14 课程页底栏在 AI 面板打开时折成两行。**（`e5-resume-bar.png`）课名和「下一课」掉到第二行。

### 1.3 这次没测到的

手机宽度下的播放器与入口；旁白实际发声；「改用文字」时开头那行说明是否显示（只确认了确实改用文字回答）；运行代码的确认卡（三次生成都没有弹出确认）。

## 二、修改方案

总原则不变（`docs/35` §1）。这一轮只做三件事：**把画面放大并画出类比、把关键动作演出来、把界面按设计稿补齐**。数据模型只加两个可选字段，不改版本号。

### R1 画面自适应放大（解决 F1）

文件：`components/domain/video/VideoStage.vue`，新纯函数放 `lib/video-fit.ts`。

- 基础尺寸上调：格子最小 168×92；值 28px / 行高 1.25；名字与地址 14px；组标题 14px；组内间距 16px、组间距 56px；数组组的格子最小 96×92。
- 自适应：每次步骤变化、窗口尺寸变化后，量出所有组的外接矩形 `content`，按 `scale = clamp(min(stageW × 0.86 / contentW, stageH × 0.80 / contentH), 0.6, 2.2)` 用 `transform: scale()` 缩放并居中。`fitScale(content, stage): number` 是纯函数，带单测（内容很小 → 2.2；内容超宽 → < 1；零尺寸 → 1）。
- 同一幕内取**该幕所有步骤里最大的内容尺寸**算一次比例，整幕固定，避免每一步忽大忽小。换幕时比例用 400ms 过渡。
- 箭头坐标在缩放后的坐标系里计算（现在用 `getBoundingClientRect`，缩放后要除以比例，或把 SVG 放进被缩放的容器内）。
- 字幕字号 20px，最多两行；猜一猜的题干 20px。
- 验收数字：任一步，格子外接矩形的宽 ≥ 舞台宽的 45% **或** 高 ≥ 舞台高的 45%。

### R2 把类比画出来（解决 F2）

文件：`VideoStage.vue` 的样式与少量模板。每种皮给出确定的画法，全部用 CSS / 内联 SVG，不加图片。

| 皮 | 画法 |
|---|---|
| `locker` 柜子（箭头目标、普通格子） | 圆角 10px 的柜体，2px 边框 `--mi-border-control`；顶部居中一块深色门牌（`addr` 写在门牌上，白字 14px）；右侧一个 8px 圆形把手；左侧一条 2px 竖线当门轴；名字（如 `a`）写在门牌下方左侧，强调色。**默认柜门关着、值正常显示**；被读写的那一步（见 R3「开门」）门向左转开 55°、露出里面的值，600ms 后合上 |
| `locker` 纸条（作为箭头源头的格子） | 米黄色纸片 `#fffdf3`，1.5px 虚线边，右上角折角（一个小三角），整体旋转 -3°，轻微投影；上面写名字与「柜号」 |
| `sheet` 草稿纸（`frame` 组） | 每个 `frame` 组是一张白纸：左侧一列装订孔（3 个小圆）、底边一条细横线纹理；**纵向叠放**，新的一张在最上面，下面每张露出标题栏 28px（见 R4） |
| `train` 车厢 | 圆角矩形车身，底部两个小圆当车轮，车厢之间的箭头画成粗 4px 的车钩；`null` / `None` 画成一个缓冲器（短竖线） |
| `memory` | 现状不变，只跟随 R1 放大 |

换皮过渡保持现有的「同 `id` 原地变」，时长 500ms；柜体的门牌淡出为地址标签、纸条摆正变成普通格子。

### R3 把关键动作演出来（解决 F3）

文件：`src/shared/video.ts`（加字段与校验）、`VideoStage.vue`（动作）、`lib/video-engine.ts`（时长）。

**新增两个可选字段**（不改 `VIDEO_FILE_VERSION`，旧数据没有这两个字段照常播放）：

```ts
interface VideoStep {
  // …原有字段
  follow?: string            // 一个箭头源头格子的 id：先让小圆点沿这条箭头走到目标，再发生后面的变化
  open?: string[]            // locker 皮下，这一步要开门的柜子 id
}
```

**引擎自动补全**（内容没写也能动起来）：这一步有 `fly`，且 `fly.from` 或 `fly.to` 是某条箭头的目标格子、该箭头的源头存在 → 自动 `follow` 那条箭头；`locker` 皮下 `fly` 的源头 / 目标柜子自动 `open`。

**一步之内按顺序播放，不再同时发生**：

| 顺序 | 动作 | 时长 |
|---|---|---|
| 1 | 代码行高亮滑动 | 250ms |
| 2 | 新增 / 移除格子与组、新箭头画出 | 450ms |
| 3 | `follow`：一个 10px 强调色圆点从源头格子出发，沿箭头路径匀速走到目标，身后留一段渐隐的轨迹；到达时目标格子闪一下 | 900ms |
| 4 | `open`：柜门转开 | 350ms |
| 5 | `fly`：值的小标签沿弧线飞行，起飞时从 0.8 放大到 1，落地时目标格子轻弹一下 | 900ms |
| 6 | 值改变：旧值划掉并上滑淡出，新值下滑淡入 | 450ms |
| 7 | 柜门合上、标注气泡出现 | 300ms |

- 旁白与第 1 项同时开始；一步的最短时长 = max(动作总时长, 字幕时长) + 350ms。
- 字幕等待期间，`focus` 的格子做 2 秒一次的轻微呼吸（缩放 1 → 1.03），避免画面完全静止。
- 减弱动效（系统设置或播放器里的「动效」开关）时：全部直接到位，`follow` 改为把那条箭头加粗 600ms。
- 校验器补一条：`follow` 必须是当前步某条箭头的 `from`；`open` 里的 id 必须存在。

### R4 布局规则（解决 F4、F5）

文件：`VideoStage.vue`、`src/shared/video.ts`、`content/animations/*.json`、`src/main/video/prompts.ts`。

- **箭头源头在左、目标在右**：渲染时如果两个组之间所有箭头都是从靠右的组指向靠左的组，自动交换这两个组的显示顺序（纯函数 `orderGroups(groups, cells, arrows)`，带单测）。
- **箭头走线**：不同组之间优先「源头右边缘中点 → 目标左边缘中点」的短弧；只有中间确实挡着格子时才绕行。同组上下的格子沿用现有的右侧外弧。
- **`frame` 组纵向叠放**：所有 `kind: 'frame'` 的组放进同一列「调用栈」，后出现的在上；`sheet` 皮下相邻两张错开 12px 并露出下面那张的标题栏。`heap` / `array` / `plain` 组排在这一列的右边。
- **调用关系不画箭头**：校验器新增规则 —— 箭头的两端不得分别属于两个 `frame` 组（引用 / 指针跨帧除外的情况用 `heap` 组表达）。返回值用 `fly` 从上面那一帧飞到下面那一帧。
- 生成提示词同步写明以上三条。

### R5 内置动画重做画面（解决 F2–F5 在内容上的部分）

### R9 命中内置动画（解决 F9）

文件：`src/main/video/generator.ts`、`prompts.ts`、`content/animations/*.json`（每个加 `keywords: string[]` 与 `lessonIds: string[]`）、`scripts/content-validate.mjs`。

1. **先不调模型**：`matchBuiltin(question, lessonId, catalog)` 纯函数 —— 当前课在某个内置动画的 `lessonIds` 里，且问题命中它至少 1 个关键词；或不看课程、命中至少 2 个关键词 → 直接返回 `{ kind: 'builtin', id }`，零等待、零花费。带单测。
