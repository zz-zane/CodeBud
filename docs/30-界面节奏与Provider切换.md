# 30 · 界面节奏与 Provider 切换

> 2026-11-12 定稿。两件事：① AI 的「谁来回答」统一成 Provider，并能在聊天框里切换；② 全站字号、间距、文字量收敛成一套节奏。视觉身份（暖色画布 + 赭色主操作 + 衬线阅读体）不变，本文只收紧它。与 `docs/04-设计规范.md` 冲突处以本文为准。

## 1. Provider

### 1.1 概念

**Provider = 一个能回答问题的后端。** 现有两类，界面上并列成一张表：

| 类型 | 来源 | 可调选项 |
|---|---|---|
| 内置 API | 设置里的 协议 / 地址 / 模型 / Key（`config.ai`，仍是唯一的一份） | 模型名（只读，点开去设置）；该模型支持时显示推理强度 |
| ACP 连接 | 学习空间已有的外部连接（`StudyConnection`：Antigravity / Claude Code / Codex / 自定义） | Antigravity：模型 + 强度；其余：无 |

「当前 Provider」就是现有的 `activeConnectionId`（`null` = 内置 API）。不新增数据结构，不做多套 API Key（需要时另开一轮）。

### 1.2 设置 → AI 助教 →「Provider」

一张列表，放在 API 配置表单**上方**：

```
Provider
● 内置 API        deepseek-chat                         [使用中]
○ Antigravity     通过 ACP 连接                  ( 开关 )
                                                         [ + ]
```

- **Antigravity 一行是固定的**，右侧是开关：打开 = 自动检测 `agy` → 建连接（`acp`）→ 连接；关闭 = 断开（保留配置）。检测不到时开关下方一行说明 + 路径输入框。状态用圆点（灰 未连接 / 绿 就绪 / 红 失败，失败原因作 `title` 并在行下显示一行）。
- `[+]` 添加其他 ACP 连接（Claude Code / Codex / 自定义），表单沿用现有连接表单。
- 点一行左侧的单选圆点 = 设为当前 Provider（未连接的先连接）。
- 学习空间的「模型」页签渲染**同一个组件**，不维护第二份界面。

### 1.3 聊天框

输入框底栏右侧（发送键左边）原来那枚只读的模型文字，换成 **Provider 选择器**：

```
[📎] [解答方式 ▾]                 [◆ Antigravity ▾] [Gemini 3.8 Flash ▾] [▂▄▆]  (↑)
```

- **Provider 芯片**：图标 + 短名。可用 Provider ≥ 2 个时可点，弹出小菜单（每项：状态点 + 名称；当前项打勾；末项「管理…」去设置）；只有 1 个时是静态标签，不带箭头。生成中禁用。
- **随 Provider 变化的选项**紧跟其后：
  - 内置 API：模型名芯片（点击去设置）；模型支持时再跟推理强度（现有逻辑）。
  - Antigravity：**模型芯片** + **强度**。`agy` 给出的模型 id 形如 `gemini-3.8-flash-high`，按末段 `-low|-medium|-high` 拆成「模型族」与「强度」：模型芯片的菜单列模型族；强度是三格音量条图标按钮（低 / 中 / 高，`title` 写明），点击循环或弹出三项。某个族没有强度变体时不显示强度。选择即时生效（`session/set_model`）并记在该连接上。
  - 其他 ACP：无选项。
- 手机端（`isRemote`）：芯片只读，显示当前 Provider 与模型；切换与连接管理仍只在电脑上做（通道白名单不变）。

### 1.4 重试警告

`agy` 在重试时会把一行 `⚠ API error (attempt N): …`（含内部地址）当作回答文本推过来。ACP 客户端丢弃这类「重试通知」行，不进回答；若剥掉后整段回答为空，按网络错误报给用户。只过滤能明确识别为重试通知的行，不动正文。

### 1.5 实现记录与偏差（2026-11-12）

代码：`shared/provider-list.ts`（列表视图模型、芯片形态、选项集）、`shared/agy-models.ts`（模型 id ⇄ 模型族 + 强度）、`shared/acp-retry-notice.ts`（重试通知过滤）、`components/domain/ProviderList.vue`（设置与「模型」页签共用）、`components/domain/ComposerProviderBar.vue` + `components/base/MiPopMenu.vue`（聊天框选择器与弹出菜单）、`stores/study.ts`（切换 Provider、Antigravity 开关、模型缓存）。

与上文不同或补充的地方：

1. **学习空间「模型」页签原本没有编辑 / 删除**，只有添加、连接、断开、登录、使用。这次补上编辑（沿用表单，`saveConnection` 带 id）与删除（两步确认），删除需要新通道 `studyRemoveConnection`。
2. **新通道**：`studySetModel`（落到连接上并对已连接的会话即时 `session/set_model`）、`studyRemoveConnection`，两者都在手机拒绝名单里。手机端的「当前 Provider / 模型」只读标签来自已放行的 `studyGetState`（`command` / `args` 仍被抹掉），所以没有给手机加「列出模型」通道。
3. **推理强度原本在界面上没有控件**（只有 store 里的 `reasoningEffort`），所以内置 API 的「推理强度」芯片是这次新加的，且只在 `showEffortForModel` 为真时出现；全站仍只有这一处。文字为「思考程度 中」，弹出 低 / 中 / 高 / 最高。
4. **强度**用弹出三项（低 / 中 / 高，只列该模型族真实存在的档位），不做点击循环。当前模型 id 不在列表里或列表拉取失败时，模型芯片退成纯文字（显示已存的模型 id），不带菜单。未保存模型时显示「默认模型」。
5. **Provider 菜单列出所有已配置的连接**（含未连接的，带状态点），选未连接的会先连接；连接失败则选择不变，toast + 状态点 + 行下错误同时出现。
6. 聊天框底栏在窄栏（课文侧栏）放不下时自动折成两行（`.input-bottom` 加了 `flex-wrap`），`.input-trail` 靠右。
7. 重试通知只在**块首**识别（块首以 `⚠` 开头会等到该块第一个换行再判定）；若通知出现在一个块的中段则不处理（真机样本未见）。剥完整轮无正文时报「网络连接失败…」（`ACP_NETWORK`），通知文字里带额度 / 限流关键词时仍报额度 / 限流。
8. 设置里的 Antigravity 行固定取**第一个** `antigravity` 类型连接；再手动添加的第二个 Antigravity 连接作为普通行显示。

## 2. 界面节奏

问题不在某个控件，而在**没有刻度**：字号散落在 12–26px 之间近十档、粗细三档混用、块与块的间距各写各的，于是每一屏都「差一点」。统一成下面两把尺，所有页面只许用刻度上的值（令牌进 `tokens.css`）。

### 2.1 字号（桌面，CSS px）

| 令牌 | 值 / 行高 / 字重 | 用途 |
|---|---|---|
| `--mi-fs-caption` | 12 / 1.4 / 400 | 计数、时间、状态、表头 |
| `--mi-fs-label` | 13 / 1.45 / 400 | 次要文字、芯片、表单标签、右栏列表 |
| `--mi-fs-body` | 14 / 1.5 / 400 | 界面基准：导航、按钮、列表行、输入 |
| `--mi-fs-read` | 16 / 1.75 / 400 | 课文、六级文章、聊天消息（衬线阅读体保持） |
| `--mi-fs-section` | 16 / 1.4 / 500 | 区块标题 |
| `--mi-fs-title` | 22 / 1.3 / 500 | 页面标题（每页一个） |
| `--mi-fs-hero` | 28 / 1.25 / 600 | 只给 AI 助教空状态那一句 |

- 字重只用 400 / 500；600 只出现在 hero。强调靠字重 500 或颜色深一档，不靠加大字号。
- 颜色三档：`--mi-text` 正文、`--mi-text-2` 次要、`--mi-text-3` 辅助；不再出现第四种灰。

### 2.2 间距（4 的倍数）

`--mi-sp-1: 4` `-2: 8` `-3: 12` `-4: 16` `-6: 24` `-8: 32` `-12: 48`

| 位置 | 值 |
|---|---|
| 页面内容区左右内边距 / 顶部 | 32 / 24；内容最大宽 960（阅读类 760），居中 |
| 页面标题到首块 | 24 |
| 区块之间 | 32；区块标题到内容 12 |
| 列表行 | 高 44，行内左右 12，行间用 1px 分隔线不留缝 |
| 表单行之间 / 标签到控件 | 16 / 6 |
| 控件高度 | 小 28、标准 32、主操作 36；图标按钮 32×32（图标 16） |
| 卡片 / 面板内边距 | 16 |
| 圆角 | 控件 6、容器 10、输入框大卡 14 |
| 左侧栏 | 宽 232；导航项高 36、图标 18、图标到文字 10、组间距 16 |
| 右侧栏 | 宽 320；内边距 16 |

### 2.3 文字换符号、删提示

1. **通用动作只用图标**（必须带 `title` + `aria-label`）：返回、关闭、添加、删除、编辑、复制、搜索、刷新、设置、收藏、标记、导出、展开/收起、发送、停止、更多。同一动作全站同一个图标。
2. **保留文字的**：导航项名称、页面标题、主操作里带业务含义的（交卷、保存并连接、开始练习）、数据本身。
3. **状态用形不用字**：连接状态 = 圆点；对错 = 颜色 + ✓ / ✗；进度 = `3/30` 这种数字，不写「已完成 3 题，共 30 题」。
4. **删掉的提示文字**：复述界面本身的句子（「选一节课边学边问，或者直接在下方提问」这类）、同一件事说两遍的（提示条 + 占位符各说一遍「先配置 Key」时只留一处）、不影响操作的说明段。必要的解释改成控件的 `title`，或一个 ⓘ 图标悬停显示。
5. 空状态最多一行字 + 一个动作。错误提示不删，仍然说清原因和下一步。

### 2.4 逐屏要点

- **AI 助教空状态**：一句 hero + 三个入口，hero 下那行说明删掉；未配置 Key 时只保留输入框上方那条带「去配置」的提示，占位符恢复普通文案。右栏「学习对象」字号降到 label / body 档，画像区块压成两行。
- **课程目录**：标题 22；语言页签改成紧凑的内容宽度（不拉满整行）；课行高 44。
- **课文 / 六级**：阅读体 16/1.75，行宽不超过约 40 个汉字；顶栏控件统一 32 高、间距 8。
- **练习 / 复习 / 收藏 / 备忘 / 我的学习**：同一套页面骨架（标题 → 可选的筛选行 → 内容），统计卡的数字 22、标签 12。
- **设置**：左列分类 36 高；表单行 16 间距；说明文字收进 ⓘ。
- **手机端**（≤ 768px）沿用同一刻度，页面左右内边距改 16，标题 20；`phone.css` 里与新令牌冲突的硬编码值改引用令牌。

### 2.5 约束

不换配色、不换字体、不加阴影渐变；改的是数值和文字量。电脑端与手机端各自验证；六级考试锁、答案交卷前不进 DOM 等行为规则不动。

### 2.6 实现记录与偏差（2026-11-13）

令牌：`tokens.css` 新增 `--mi-fs-*` / `--mi-lh-*` / `--mi-fw-*` / `--mi-sp-*` / `--mi-page-*` / `--mi-row-h` / `--mi-ctl*` / `--mi-icon-btn` / `--mi-radius-*` / `--mi-rightpanel-w`；`--mi-sidebar-w` 264 → 232，`--mi-nav-row-h` 30 → 36，`--mi-group-gap-top` 14 → 16，新增 `--mi-nav-icon-gap` 10。手机端在 `phone.css` 里只改 `--mi-page-pad-x/-top`（16）、`--mi-fs-title`（20）、`--mi-row-h`（48）、`--mi-icon-btn`（44），其余沿用同一刻度。

与 §2.2 不同的地方：

1. 列表行 `.pg-row` 行内左右内边距取 **0** 而不是 12：行内文字要与页面标题左缘对齐，分隔线与文字同宽；行高 44（`--mi-row-h`）不变。
2. 页面容器统一 `max-width: var(--mi-page-max)`（960）并居中；`.content` 加 `scrollbar-gutter: stable`，有无滚动条左缘都不跳。设置页与备忘主栏用阅读宽 760。
3. 间距按 4 的倍数批量吸附：margin / padding / gap 里的 5→4、6/7/9→8、10/11/13→12、14/15/17/18→16、20→24（margin、gap）或 16（padding）、22/26→24、28→32（margin、gap）或 24（padding）、30→32。含 `calc()` / `env()` 的声明不动。
4. 小控件仍有 2/3px 的微间距（图标与角标之间），不属于排版节奏，保留。
5. 说明文字收进 ⓘ：新增 `components/base/MiHint.vue`（悬停显示 `title`，可聚焦，带 `aria-label`）。

### 2.7 例外（刻度之外仍保留的值）

- `Cet6Paper.vue` / `MiRichText.vue` 的 `em` 字号：六级卷面与富文本里相对用户可调阅读字号的层级（0.8–1.15em）。
- `Cet6ExamView.vue` 的 `fontSize: 16 + fontDelta`：用户用 A-/A+ 调整的阅读字号，基准是 `--mi-fs-read`。
- 六级卷面小节标题 `.cet6-part-title`（1.1em，约 17.6px）同属上一条的相对单位。
- 课文标题 `h2` = `calc(--mi-fs-read * 1.25)`（20px）：课文内部标题层级，随阅读缩放。
- 代码字体（CodeMirror、`pre`、`code`）取 `--mi-fs-body`（经 `--mi-zoom` 缩放），字体族为 Consolas，不属于界面字号。
- `vendor/` 里的 CDS 样式与图表库（ECharts 轴标签 12）不改。
- 字重 600 只给 `--mi-fw-hero`（AI 助教空状态那一句）。
- 课文 `<strong>` 字重由 600 降为 500。
