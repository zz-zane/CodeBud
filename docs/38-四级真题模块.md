# 38 · 四级真题模块

格式、界面、判分、作答存档、AI 批改等一律与六级相同，见 `docs/27-六级真题模块.md`，此处只记差异。

## 1. 数据来源与转换

- 来源：`<本地四级真题目录>/`，56 个目录，每目录含 `真题解析听力.md` / `真题.pdf` / `解析.pdf` / `听力.mp3` 或 `听力说明.txt`。
- 转换脚本：`scripts/cet4-import.mjs`，产出 `content/cet4/`，不手改产物，改动走脚本重跑。
- `content/cet4/index.json` + `content/cet4/exams/<id>.json`，schema 与 `content/cet6` 完全相同；id 为 `YYYY-MM-N`。
- 写作附图放 `content/cet4/assets/figures/`（若有）。

## 2. 与六级的差异

| 项目 | 六级 | 四级 |
|---|---|---|
| 听力 | 见 docs/27 | Section A 三篇 News Report 题 1–7；B 两段 Conversation 题 8–15；C 三篇 Passage 题 16–25（共 25 题） |
| 阅读 | 26–55 | 同六级 |
| 写作 / 翻译 | | 题 56 / 57 |
| 考试时长 | 见 docs/27 | 125 分钟倒计时 |
| 存档 | `cet6.json` | 独立 `cet4.json` |
| 听力音频根目录 | 六级音频目录 | 独立的四级音频目录；`audio.src = source-media/<G 盘目录名>/听力.mp3` |
| 路由 | `/cet6` | `/cet4` |

## 3. 特殊卷

- 合卷：2022.09、2023.03 的第 2–3 套只有写作、翻译，拆成两套。
- 共用听力：靠 `听力说明.txt` 指明，目标卷用 `sharedWithExamId` 引用（与六级机制一致）。

## 4. 校验

- `npm run validate:content`：`content-validate.mjs` 内的 `checkCet4()` 对 `content/cet4` 跑与六级同一套证据校验（`cet6-evidence.mjs` 的 `checkExam`）并断言听力 25 题；目录不存在时略过。
- `node scripts/cet6-evidence.mjs --check cet4`：单独跑四级证据校验（默认仍是六级）。
- `src/shared/__tests__/cet4-content.test.ts`：完整性断言（可解析、清单对应、答案在选项内、词库 15 项不重复、匹配题 10 题、听力 25 题）；`content/cet4` 不存在时跳过。
