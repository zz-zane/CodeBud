## 二、分工

两人都从 `codebud`（`0fc60da`）开新分支。只在本机提交，不 push，不动对方的文件。每完成一个阶段：三条命令（`typecheck` / `test` / `validate:content`）+ `check:animations` + `build` 全过，提交，向总指挥终端发一句话通知：
`orca terminal send --terminal term_05ebca3f-fbcf-4809-ab07-d86f5a5b21cc --text "工人X回报：<一句话>，详见 <报告绝对路径>" --enter`

负责文件：`components/domain/video/VideoStage.vue`、`lib/video-fit.ts`、`lib/video-engine.ts`、`src/shared/video.ts`、`content/animations/`、`src/main/video/`。
